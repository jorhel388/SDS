Job Submission Console overview

The Job Submission Console is used to display the status and history of batch process jobs that have been submitted or scheduled for execution. Job tasks that are submitted to the Job Submission Console include jobs created by batch tester, import/export, content management, and label deployment.

From the Job Submission Console, the user can see the list of the submitted batch process flows, which jobs are currently running, which jobs are queued for running at a later time and whether a job has completed successfully or has failed or has been cancelled.

From the Job Submission Console the user can:

Display the history of a job

From the Job Submission Console editor the user can display the history of a job.

To display job history

  1. Display the Job Submission Console editor
  2. Right click on any row in the console table within the Jobs tab and select Show history
    or
    click on the Show history button in the Job Submission Console Jobs tool bar.
  3. The history for that job is displayed in the Output window:

The job history is stored for display at any point in the future.

Display and save any job output files

The job produces output files, these can be viewed and saved from the console.

To display and save output files

  1. To see if there are any output files associated with the job, check under the Outputfiles column in the Job Submission Console editor.
  2. If output files exist, they can be displayed below the table by clicking on the appropriate job:

  3. To save an output file, right click on the file name and select Save selected file.
    4.   Right click on the Output file within the Job Submission Console and select Open to directly open these files.

The Save dialog is displayed, allowing you to select a folder in which to save the output file.

  Up to two Output .ser files are created, the Reason Code file and the Deployment file (which may be renamed). It is important that users do not use either of these as a means to bypass formal the deployment and sanction of components.
Display scheduled jobs

From the Job Submission Console editor the user can display a list of scheduled jobs.

To display the list of scheduled jobs

  1. From the Job Submission Console editor, click on the Schedules tab:

  2. Select the appropriate Job Server from the Job server filter drop down list.

The schedule list is displayed in the schedule table.

The schedule expression is set up as part of the Batch Process Scheduling wizard.

From the Job Submission Console editor the user can display a list of scheduled jobs and remove and pause one from the list if required. Removing a job from the schedule will stop the execution.

Remove a scheduled job submission

From the Job Submission Console editor the user can display a list of scheduled jobs and remove one from the list if required. Removing a job from the schedule will stop the execution.

To remove a scheduled job

  1. From the Job Submission Console editor, click on the Schedules tab:

  2. Select the appropriate Job Server from the Job server filter drop down list.
  3. To remove a scheduled job from the list, either select the scheduled job to remove and click on the Remove selected schedule button , or right click in the appropriate scheduled job row and select Remove schedule.
  4. The scheduled job will be removed from the Schedules table.

Removing a job from the schedule will stop the job from executing in the future.

Obtaining information on errors using the Job ID

Although the consolidated_logs file, that contains all Job related errors, cannot be accessed directly from the Job Submission Console, using the Job ID that is displayed in the Job Submission Console as a reference point, information on any Job related error can be found.

All Job related errors are saved to the consolidated_logs file found in \Job Server <version>\logs folder.

For the Batch Process Flow submit/schedule jobs, for each job, the username, Job ID, solution, domain and Batch Process name will be logged. For all other jobs, the username, Job ID and Job type will be logged.
