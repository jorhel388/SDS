Batch Process Flow editor

The Batch Process Flow editor enables the user to define a Batch Process Flow by constructing a sequence of server side batch processes to be executed at runtime. Building a Batch Process Flow is similar to building a Decision Process Flow: batch processes are available in the palette to drag and drop into the batch flow.

The Batch Process Flow editor consists of:

  • Batch Process Flow toolbar

    The Batch Process Flow toolbar is designed to assist the user in editing the Batch Process Flow.

    Copy component image to clipboard - select to copy the complete flow contained in the editor as an image to the clipboard from where you can paste this image into any appropriate application.

    Zoom in and Zoom out - select to enlarge or reduce the size of the image seen in the editor

    Zoom To Fit - resizes the image to fit the editor the user has open

    Zoom Reset - resizes the image back to how it was displayed when the editor was first opened

    Delete all selected nodes - removes all the selected objects from the image

    Show Grid - the editor will display a grid which will help the user to align an image

    Snap to Grid - when selected the editor will align an object the user is placing on the panel in line with the grid

    Align Middle - will align all objects using the horizontal middle point for alignment

    Align Vertical - will align all objects vertical middle point for alignment

    Default Horizontal - will re-align all the objects using the default alignment setting of the editor

    Show all node annotation - will display any annotations that the user has applied

    Hide all node annotations - will hide any annotations that the user has applied

  • Batch Process Flow definition area

The Batch Process Flow is made up of the following elements:

Start Node - the point in the Batch Process Flow where processing starts. A Batch Process Flow must always have a start node.

Process Node - a point in the flow where no processes have been applied.

End Node - the point in the Batch Process Flow where processing ends. A Batch Process Flow must have an end node.

The process nodes have two levels of configuration that help the user know the current definition state of the process node. Using these the user can sketch and paint their Batch Process Flow:

Sketch

- depicts a process node that has been added to the flow, but no processes have been assigned to it. Any fully defined process can be applied to a sketch node.

Paint

- an icon, unique for every job process, depicts that a fully defined process has been assigned to the process node. The icon in this example is specific for the Deployment Job.
