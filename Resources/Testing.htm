Testing

The studio is made up of a number of testing capabilities.

Once the user has successfully defined a component the user will be able to test it using one of the following:

  • Interactive Tester - uses manually typed or entered data into relevant fields for the input characteristics.
  • Test Project - uses data from a .csv file to perform a batch test.

A Test Group Set is a method by which a user can use a sample population to which a 'control' test or an alternative treatment is applied. The 'control' test group is referred to as the Champion and any alternative test groups that are evaluated against the Champion are referred to as the Challengers. Hence the term Champion/Challenger - the ability to test against different test groups.

When a solution is made up of one or more Decision Process Flows that are linked together and passed to the Decision Agent in one single execution, the Test Chains functionality can be used to test these linked Decision Process Flows in their entirety from the first executed Decision Process Flow right through to the last.

Supplementary testing component

The Input Data Connection component is used as input to other components that require access to a Physical Data Source. In the case of the Test Project, the Input Data Connection can be configured for use with a database table and can be used as the source of the test case data.
