Strategy Viewer

Overview

Strategy Viewer allows the contents of deployed Decision Process Flow, the strategy files (.ser) and deployment resource bundles (.jar) to be viewed, to aid in troubleshooting.

Users can also use Strategy Viewer to generate code (i.e., external interface generation) from any strategy with a physical definition. Depending on the type of strategy file selected, the user can generate JavaBeans, JSON, XML, C or COBOL code using a simple wizard.

  Strategy viewer does not generate characteristics for dynamic arrays. Dynamic arrays are not supported by Strategy Viewer.
Strategy Viewer window

The Strategy Viewer window is housed in the Explorer area of the user interface. By default on opening the software the Strategy Viewer window will not be displayed. It can be opened from the Main menu bar. Once opened, it will display on the left hand side of the interface.

The Strategy Viewer is initially empty; the user must open a deployment file to display it in the viewer.

When a deployment file is opened and selected in the Strategy Viewer, the contents of the file appear in the Navigator window:

If the Strategy Viewer window is not visible in the User Interface, it can be opened at any time.

Open the Strategy Viewer window

Strategy Viewer allows the contents of deployed strategy files (.ser) and deployment resource bundles (.jar) to be viewed, to aid in troubleshooting.

The Strategy Viewer window can be accessed from the Main tool bar.

To open the Strategy Viewer window

  1. In the main system view, click on Window in the Main menu bar.
  2. Select Strategy Viewer.
  3. The Strategy Viewer window is displayed.

The Strategy Viewer window can be dragged to any preferred location. Please see the Customise the User Interface help page for more information on this.

 

View the contents of a component

The user can display the contents of the components listed for selected deployed strategy files (.ser) and deployment resource bundles (.jar) in the Strategy Viewer window.

To view contents of a component

  1. From the Strategy Viewer window, select a deployment file to view the components contained in that file.
  2. Double click on a component to display its contents in the right hand pane.

Contents of Logical Data components are displayed in tabular format:

Click Source View to display the same contents textually.

All other components are displayed textually, in Source View:

View a deployment file

The user can display the contents of deployed strategy files (.ser) and deployment resource bundles (.jar) in the Strategy Viewer.

To view a deployment file

  1. From the Strategy Viewer window, right click in the window and select Open Files. The Open Files dialog is displayed.
  2. From the Files of type drop-down list, select the type of file to browse for (.ser or .jar):

  3. Locate and select the file to open, and click Open. The Enter strategy signature dialog is displayed:

  4. Type the strategy signature in the Signature field and click on the OK button. The selected file is displayed in the Strategy Viewer window.
    The Properties window will also display the following information on the deployment file:
  • Alias - unique 32 characters name that identifies the Decision Process Flow
  • Signature - unique identity given to a solution used at runtime as an 'internal' password to ensure that the Decision Process Flow being executed is for the correct client solution
  • Edition Number - studio generated number that is updated after each deployment
  • Decision Process Flow - name of the Decision Process Flow
  • Software Version - PowerCurve software used
  • Status - the deployment status (Pending, Sanctioned, Archived, Rejected)
  1. Click on the file to display the contents of the deployed file in the Navigator window.

You can now view the contents of the various components within the deployed file.
