Measures editor - Derived Measure

The Measure editor enables the user to create measures. When a 'Derived Measure' is selected from the Measure type drop down box, the editor will change allowing the user to define a derived measure using measures listed in the Resources window and the Operators listed in the Palette window.

  Derived Measures are only supported in Strategy Monitoring for use on reports, they cannot be tested or used in Assisted Strategy Design.

A derived measure must reference a minimum of two other measures (which can also be derived measures). Derived measures are calculated at the result level (similar to combining cells in a spreadsheet), each individual measure is calculated first (at the transaction level), and then the results are combined at the segment level.

  If any of the referenced measure in a derived measure returns NoData, then the derived measure will also return NoData.

The user will be able to create a derived measure that will be treated as either:

  • Count
  • Ratio
  • Sum

This will control how the measure is calculated (see measure selection tab) on a report and provides guidance to the user on the type of measure that has been derived. For example the addition of two count measures would probably represent a count measure whilst, adding the two sum measures would probably represent a sum measure whilst adding two sum measures and then dividing by a count measure minus a count measure would probably represent a ratio measure.

Modifying the ‘treat as measure type’ will not impact the actual calculation but will influence validation checks or calculation type options when used on a report (for example a report that only expects a count measure will also accept a derived-count but not a derived-sum.

  A typical use of derived measures might be to define a measure that includes either open bad accounts or written-off accounts as a Bad measure. This would combine an Outcome-open measure with an Outcome-Written Off measure.

The user will be able to use the standard scripting toolbar to:

Compile Script - checks the script for syntax errors

Format Script - formats the script in the editor making it easier to read and correct syntax errors

Last Edit - takes the user to the line of the script where editing last took place

Find Selection - select to locate a highlighted section of script. Find Selection can be used in conjunction with Ctrl + F to search within a script

Find Previous Occurrence - select to locate the previous occurrence of a highlighted section of script

Find Next Occurrence - select to locate the next occurrence of a highlighted section of script

Toggle Highlight Search - select to highlight all the occurrences of the highlighted section of script

Toggle Rectangular Selection - click to enable your cursor to select a rectangular selection. A useful tool for copying areas of script.

Shift Line Left - moves the whole line to the left by one tab stop

Shift Line Right - moves the whole line to the right by one tab stop

Parenthesis matching - to provide visual assistance for parenthesis matching (brackets), matching parenthesis in the script editor will be displayed using the same colour. Those brackets that match will be highlighted in yellow, those that have no match will be highlighted in red.
 The Bracket Highlighting feature can be switched off by deselecting the Enabled check box that is found in the Brackets Highlighting tab (accessed from the Miscellaneous area of the Options dialog in the Tools menu).
