Measures

Measures enable the user to specify simple calculations that can be used to evaluate decision strategies. Measures can be created as one of the following types:

  • Average
  • Count
  • Derived Measure (Strategy Monitoring only)
  • Max
  • Min
  • Ratio
  • Std Deviation (Assisted Strategy Design only)
  • Sum
Overview

Measures can be simple, for example COUNT of all cases, or more complex, for example RATIO of Total Balance for Bad Accounts to Total Balance for Good Accounts.

For use within Reports, Measures can be combined to create a derived measure by using the Measure's script editor.

Measures are defined in terms of Logical Data Source characteristics and can optionally include Filters, which can be embedded or referenced within the measure.

The user can create and edit Measures and make them available to relevant user(s) and/or reports and analysis, where they are then calculated against the chosen data set/population.

Edit a non-ratio measure

Editing a measure involves selecting a measure type; then, for a non-ratio measure, selecting a characteristic to measure and specifying a filter (if desired).

Create a measure

A measure can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a measure

  1. From the Explorer window, right click at the required folder level and select Add component.
  2. Select Measure.
  3. In the Create component dialog enter the name of the measure.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.

    The Measure editor will open allowing you to edit a measure.
    The measure name will be listed in the Explorer window. The component is identified by the icon.

  6. If you do not wish the editor to open, keep the check box de-selected.
  7. From the Explorer window, select the measure and select Open.

To edit a non-ratio measure

  1. From the Measure editor, select the measure type.
Add a characteristic to a measure

Measures enable the user to specify simple calculations that can be used to evaluate decision strategies. A user can specify the characteristic for the selected measure (for all measure types except ratio).

  All characteristics required in measures should be added to a new or existing logical data source (measure characteristics may not be present on the operational logical data sources).

To add a characteristic to a measure

  1. In the Resources window, click on the Expand (+) button to display the contents of the logical data source. Drag the required logical data source and drop it onto the Characteristic field.

    OR click on the Browse button.

  2. The Select Characteristic dialog opens.
  3. In the Search field type the word or part of a word that makes up the name of the characteristic.
    The Select Characteristic dialog will focus in on a particular characteristic or set of characteristics that match this word.
    4.   If the Select Characteristic dialog is displaying the characteristics in a tree view, the logical data source will need to be fully expanded to see all the characteristics that match the word(s).
  4. Select the characteristic you require.
  5. Click on the OK button.

The Select Characteristic dialog closes and the characteristic you have selected is added.

Add a referenced filter to a measure (optional)

Measures enable the user to specify simple calculations that can be used to evaluate decision strategies. A user can specify a filter for the current measure. A filter is optional; the default <All Cases> indicates no filter is being used.

To add a referenced filter to a measure

  1. With the Measure editor open, click on the Resources window. The valid component types will be listed.
  2. Expand the Filter list to display all the available filters.
  3. Drag and drop the required filter onto the "For all cases of" field.

This filter name will be displayed in the field, and will be used to filter the records included in the measure.

Insert an embedded filter into a measure

Measures enable the user to specify simple calculations that can be used to evaluate decision strategies. A user can specify a filter for the current measure. A filter is optional; the default <All Cases> indicates no filter is being used. An embedded filter is one that has been created from within the Measures editor and will be embedded into the measure. This means the component details are only used by this measure and can only be edited from within the measure.

To insert an embedded filter into a measure

  1. With the Measure editor open, right click in the "For all cases of" field, and select Insert Embedded.
  2. The Insert Embedded Component dialog is displayed:

  3. Specify a name for the filter.
  4. Click on the OK button to confirm the selection.

    The dialog will close and display the Embedded Filter scripting editor:

  5. This editor is a standard scripting editor and is very similar to the Boolean Expression editor.
  6. Create the filter script, click on the Compile Script button to validate it, then click on the close button to exit the scripting editor.

The embedded filter is now complete. The filter name will be displayed in the field, and will be used to filter the measure.

Rename an embedded filter

To rename an embedded filter

  1. With the Measures editor open, right click on the name of the embedded filter (in the "For all cases of" field) and select Rename.

    The Rename dialog will be displayed.

  2. In the New Name field enter a unique name (within the component) for the embedded filter.
  3. Click on the OK button to confirm the selection and close the dialog.

The new filter name will be displayed in the editor.

Remove a filter from a measure

To remove a filter from a measure

  1. With the Measures editor open, click on the Clear button next to the "For all cases of" field.

This filter will be removed, and the default filter condition <All Cases> will be restored to the measure.

The measure is now ready for use within the software.

To create a measure

  1. From the Explorer window, right click at the required folder level and select Add component.
  2. Select Measure.

  4. Select the Open new components in component editor check box.

To edit a ratio measure

  1. From the Measure editor, select the measure type Ratio.
  2. Specify the numerator and denominator for the ratio.

To insert an embedded measure into a ratio

  1. With the Measure editor open and the ratio measure type selected, right click in the "Defined as" field or the "As a Ratio of" field, and select Insert Embedded.
  2. The Insert Embedded Component dialog is displayed:

  3. In the Name field, specify a name for the measure.

  3. Click on the OK button to confirm the selection and close the dialog.

Edit a derived measure

When a 'Derived Measure' is selected from the Measure type drop down box, the editor will change allowing the user to define a derived measure using measures listed in the Resources window and the Operators listed in the Palette window.

  Derived Measures are only supported in Strategy Monitoring for use on reports, they cannot be tested or used in Assisted Strategy Design.

A derived measure must reference a minimum of two other measures (which can also be derived measures). Derived measures are calculated at the result level (similar to combining cells in a spreadsheet), each individual measure is calculated first (at the transaction level), and then the results are combined at the segment level.

  If any of the referenced measure in a derived measure returns NoData, then the derived measure will also return NoData.

The user will be able to create a derived measure that will be treated as either:

  • Count
  • Ratio
  • Sum

To edit a derived measure

  1. From the Measure editor, select the derived measure, measure type.
  2. From the treat Derived Measure as Type drop down box, select either Derived - Count, Derived - Ratio or Derived - Sum as required.
  3. Within the measure editors script editor open you can add script freehand or using the required resources from the Resources window you can:
  4. Click on the point in the script that you wish to add or insert the measure.
  5. Click on the Expand (+) button in the Resources window to expand Measure.
  6. Drag the required measure and drop it onto the script at the required position.
  7. Click on the Expand (+) button in the Palette window to expand the Operators.
  8. Drag the required operator and drop it onto the script at the required position.
  9. Repeat steps 6 to 8 as required to define the derived measure.
  10. Click on the Compile Script button to check the script.

The derived measure can now be used within other components.
