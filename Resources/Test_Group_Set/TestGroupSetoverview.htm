Test Group Set

A Test Group is a sample population to which a 'control' or an alternative treatment is applied. The ‘control’ test group is referred to as the Champion, and any alternative test groups that are to be evaluated against the Champion are referred to as the Challengers.

Overview

Test Groups are created within a Test Group Set using the Test Group Set Editor. There may be up to 99 Test Groups in a Test Group Set.

Test Group Sets can be applied within component trees (Scorecard Trees, Value Setter Trees, Derived Data Script Trees etc.) or used to configure Junction nodes in a Decision Process Flow.

Edit
Create a test group set

A test group set can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be created. See the Manage allowed component types help page for more information on this.

To create a test group set

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Test Group Set.
  3. In the Create component dialog enter the name of the test group set.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.
    The Test Group Set Editor will open allowing you to edit a test group set.
    The Test Group Set name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window select right click on the test group set and select Open.

Cases can be allocated to Test Groups by using a numeric characteristic populated from an external source.

  The numeric characteristic must be 3 digits and numeric.

Alternatively by one of the following:

  1. With the Test Group Set editor open, select the Random radio button.
  2. Right click on the Champion test group and select Add Row.

Create a test group set based on a numeric characteristic

A Test Group is a sample population to which a 'control' or alternate treatment or action is applied. Test Groups can be created using a numeric characteristic. Test Groups are defined using percentages in the range 0-100%.

  Any characteristic chosen must be a 3 digit number.

To create a test group set based on a numeric characteristic

  1. With the Test Group Set editor open, select the Characteristic radio button and click Browse.
    The Select Characteristic dialog will be opened.
  2. In the Search field type the word or part of a word that makes up the name of the characteristic.
    The Select Characteristic dialog will focus in on a particular characteristic or set of characteristics that match this word.
    3.   If the Select Characteristic dialog is displaying the characteristics in a tree view, the logical data source will need to be fully expanded to see all the characteristics that match the word(s).
  1. Select the characteristic you require.
  2. Click on the OK button.
  3. The Select Characteristic dialog closes and the characteristics you have selected will be added.
  4. Right click on the Champion test group and select Add Row.
    The system will automatically create the Challenger test group and assign it an ID.
  5. Repeat step 2 until you have created all the challenger test groups that are required.
    6.   To rename a test group, double click on the name displayed in the "Name" cell and overtype with the name you require.
  1. To assign coverage to the Champion and to the Challengers, either drag the bar until the percentage coverage is what you require or type the value for the coverage in the "%" cell.

  1. Click the Validate icon to check the validity of the Test Group Set. The result will display in the Output window.

The Test Group Set can now be used within the Decision Process flow or any tree components.

Delete a row or many rows from a Test Group Set

To delete a row from a Test Group Set

  1. With the Test Group Set editor open, right click on the row and select Delete Row.

The row will be removed from the Test Group Set.

To delete continuous rows from a Test Group Set

  1. With the Test Group Set editor open, with your cursor, select a continuous number of rows.

  2. Right click on any of the selected rows and select Delete Row.

All the rows will be deleted from the Test Group Set.

To delete alternate rows from a Test Group Set

  1. With the Test Group Set editor open, and with the Ctrl key of your keyboard selected, with your cursor, select the green arrow for the rows you wish to delete.

  2. Right click on any of the selected rows and select Delete Row.

All the selected rows will be deleted from the Test Group Set.

Test

Once the user has successfully created a test group set, the user will be able to test it using the Batch or Interactive Tester.

The user can test a test group set either by manually typing in data for the input characteristics referenced in the test group set or by performing a test against a known data source.

To perform an interactive test

To test a test group set manually by entering data into the relevant fields for the input characteristics, use the Interactive Tester.

To perform a batch test

To test a test group set using data from a .csv file, from the Explorer window, right click on the component and select New Test Project to use the Batch Tester.
