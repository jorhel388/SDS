Test Group Set editor

A Test Group is a sample population to which a 'control' or alternative treatment is applied. The Test Group Set editor enables the user to define Test Groups.

The test group set editor consists of:

Test Group Set toolbar

The Test Group Set editor's toolbar is designed to assist the user in testing and validating a test group set.

Test - launches the Tester for the test group set.

Validate - select to check the test group set to ensure that:

  • the percentages of each Test Group add up to a total of 100%
  • a numeric characteristic has been assigned to the Test Group set if the Characteristic mode has been selected

Test Group creation mode - area of the dialog where the creation mode of the Test Group is set. The default mode for a test group set is Random. When this option is selected a random number will be created by the software at runtime. When Characteristic is selected, the values contained in the numeric characteristic that has been selected from the logical data source will be used.

Test Group definition area - area of the editor where test groups are created. Up to 99 challenger test groups can be created using the Test Group Set editor. As each test group is created an ID will be automatically assigned. Using the slider bar percentages of the population can be assigned to each test group. The total must always add up to 100 for the test group set to be valid.
