Select Characteristic Array Element(s) dialog

The Select Characteristic Array Element(s) dialog appears if a static or dynamic array element appears anywhere within the hierarchy of the selected logical characteristic.

The dialog enables the user to enter the index of static and dynamic arrays, to specify the indices for the static or dynamic array. Greyed-out fields cannot be modified.

Characteristic – provides the full logical characteristic name.

Name – provides the name of each element in the hierarchy of the selected logical characteristic. Each array has a default value; for dynamic arrays this is [1], while static arrays are initialized with the index that was selected from within the characteristic chooser. In the above example the name has had [1-5] added to it to illustrate the possible index assigned.

 

When the Index column displays an ’n’ (next to an element), this indicates that this element contains different index values (e.g. Address Details [1], Address Details [3]) and cannot be changed.

Type – provides the characteristic type: either Static Array, Dynamic Array, or Leaf Characteristic. For static arrays, the size of the static array is listed.

Index – type in the index of the dynamic or static array. For static arrays, the value entered must be within the bounds of the size of the static array. In the screen shot above, since the Static Array has a size of 5 a range of 1-5 can be added to the index. For either array type, the value entered must be either a single numeric or a single numeric range, or the cell is locked with a red border until the error is corrected: (combinations of values are not supported).

Apply To All - when selecting the multiple array characteristic, you can select this check box to automatically re-use the entered array index values for the same characteristic(s) on any subsequent dialogs.
