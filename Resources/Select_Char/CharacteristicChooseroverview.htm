Characteristic Chooser

Overview

Characteristic Chooser enables the user to select a characteristic from within a Logical Data Source.

Characteristics are selected using either the Select Characteristic dialog or the embedded characteristic chooser area that can be accessed from the bottom half of editors using the split pane. The following illustrates both of these options that are available when using the Derived Data Script editor.

Both options list the logical data sources within the context of where the characteristic selection is activated. For example, it will only list those logical data sources that are held in the folder that the user is working in or have been published to the folder that the user is currently working in. Similarly, when a logical data source is selected from the Resources window the Select Characteristic dialog will only list the logical data source and the characteristics contained in it.

The characteristic chooser only lists available logical data sources, if a logical data source has not been created for the logical data model it will not be listed.

To help the user locate a characteristic more easily the Characteristic Choosers contains search and filter options.

Search facility

- Type a word or part of a word next to the Search icon and the characteristic chooser will focus in on a particular characteristic or set of characteristics.

Using the * wildcard, will search all the available logical data sources to display any characteristic name and logical data source name that contains the text. Matching is not case sensitive, so you could use * to match Applicant.Scores.Risk Score with Scor*risk for example.

Filter facility

-The Filter for Data Types icon allows the user narrow down the range of the characteristics displayed in the browsing area to a specific characteristic type (e.g. string, integer, float, decimal and date). The Filter for Data Types icon will indicate when the range of characteristic types displayed in the characteristic chooser area have been narrowed down.

The list of available logical data sources is altered by the search and filter selections that have been made.

Display options

The display options allow the user to alter how the characteristics are displayed in the dialog.

- The Column display button allows the user to invoke the characteristic chooser to display the Name, Type, Length and Scale for each characteristic.

- The Show Table View icon allows the user to change the display of characteristics from a tree view to a table view.

- The Select Logical Data Sources icon opens the Logical Data Source Selector dialog from where the user can limit the number of Logical Data Sources displayed. The Select Logical Data Sources icon will indicate when the number of Logical Data Sources displayed has been reduced.

The main area of the screen lists the available logical data sources and the characteristics held in these.

Select a characteristic

Characteristics are held in logical data sources. The browsing area lists the available logical data sources from which you can choose a characteristic.

To select a characteristic

Either:

  1. With the Select Characteristic dialog open, locate the logical data source you require.
  2. Click on the Expand + button to list all the characteristics contained in the logical data source.
  3. Select the characteristic you require.
  4. Click on the OK button.

The Select Characteristic dialog will close and the characteristic(s) you have selected will be added.

  If a dynamic element appears anywhere within the hierarchy of the selected characteristic the Select Characteristic Array Element(s) dialog is displayed, enabling you to specify the indices for a dynamic array.

Or:

  1. With the Select Characteristic dialog open, start typing the word or part of a word.
    The characteristic chooser will focus in on a particular characteristic or set of characteristics that match this word.
    2.   If the Select Characteristic dialog is displaying the characteristics in a tree view, the logical data sources will need to be fully expanded to see all the characteristics that match the word(s).
  1. Select the characteristic you require.
  2. Click on the OK button.

The Select Characteristic dialog will close and the characteristic you have selected is added.

  If a dynamic element appears anywhere within the hierarchy of the selected characteristic the Select Characteristic Array Element(s) dialog is displayed, enabling you to specify the indices for a dynamic array.
