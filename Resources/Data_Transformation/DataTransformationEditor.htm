Data Transformation Editor

The Data Transformation component maps one Logical Data Source (LDS) to another by adding objects from the source to the target (Logical Data Source to Logical Data Source).

  Logical Data Source elements which contain dynamic arrays can be mapped. Refer to the Dynamic array mapping section for more information.

The Data Transformation editor consists of:

Sources

The Sources panel defines the source Logical Data Source(s) and the relevant characteristic(s) of the Logical Data Source to be used.

The Source area of the editor consists of:

Sources area Toolbar

The Sources toolbar is designed to assist with the definition of the Sources for the Data Transformation. When adding a Logical Data Source, all the characteristics that belong to the same Logical Data Source will be added.

Show the action menu - select to access the Add LDS button to add a Logical Data Source and its characteristics to the Sources area.

Add LDS - select to open the available Logical Data Sources area, from where you can select the Logical Data Source(s) that are required.

Edit - select to edit the selected element.

  This option is currently not available.

Remove - select to remove the selected Logical Data Source from the Sources area.

The Logical Data Source and the characteristics that have been added to it are displayed in a table with the following columns:

  • Name - Displays the name of the source Logical Data Source and the characteristics it contains.
  • Value - Displays the user's input value.
  • Data type - Displays the data type of the characteristic.
  • Value type - Displays the data type of the input value.

Source Details

When either the Add LDS button or is selected from the toolbar, the Sources Details area will be displayed. This area displays all the available Logical Data Sources that can be added to the Source.

When a Logical Data Source has been added to the Source and an element is selected, the Source Details will update to display information on the selected element.

  When a Logical Data Source is added, all the characteristics that belong to the same Logical Data Source will be added.

Targets

The right-hand Targets panel defines the target Logical Data Source(s) and the relevant characteristic(s) to be mapped. The percentage number displayed with the Targets indicates the status of the characteristics that have been mapped. 0% means that no columns have been mapped.

The Targets area of the editor consists of:

Targets area Toolbar

The Targets toolbar is designed to assist with the definition of the Targets for the Data Transformation.

Show the action menu - select to access the Add LDS button to add a Logical Data Source and its characteristics to the Targets area.

Add LDS - select to open the available Logical Data Sources area, from where you can select the Logical Data Source(s) that are required.

Transformation - with a Column selected, select to open the canvas to transform or manipulate the data in the Logical Data Source.

Edit - select to edit the selected element.

  This option is currently not available.

Remove - select to remove the selected Logical Data Source from the Targets area.

The Logical Data Source and the characteristics that have been added to it are displayed in a table with the following columns:

  • Name - The name of the target Logical Data Source(s) and the characteristic(s) it contains.
  • Value - The status of the mapping of the characteristic (as a percentage). This column also displays the value added by the user for the characteristic.
  • Data type - Displays the data type of the characteristic.
  • Mapping expression - Displays the mapping expression of the target.

Targets Details

When either the Add LDS button or is selected from the toolbar, the Targets Details area will be displayed. This area displays all the available Logical Data Sources that can be added to the Target.

When a Logical Data Source has been added to the Targets and a column is selected, the Target Details will update to display information on the selected column.

Functions tab

The Functions tab enables a user to specify the function to be used. Users can use the search field to search for the relevant function. Refer to the Function Groups for the Data Transformation component section for more details.

  • Name - Name of the category of functions or the name of the function.
  • Description - Brief summary of the purpose of the function.
  • Operator - This column refers to the function capable of processing each input in hierarchical format (for example, String, List of String, Map of String) and apply the operation to all members. This only applies to functions with 'Yes' indicated in the Operator column.
  • Functions - This column represents the total functions in that category (for example, Special contains five functions). If the filter is specified with a keyword, the Functions displays the total number of functions in that category that have that keyword.
  • Arguments - This column for a specific function (for example, Hash) represents the total fields in the function. If the count has a "+" symbol, it means additional fields can be added based on the user's preferences.

Right click on a function in the list (for example, Special) to display the context menu at the function list.

Scratch Pad

The Scratch Pad of the editor is a visual interface that enables a user to perform mapping of the various elements (Logical Data Source and functions) that have been added to the canvas.

Scratch Pad (draft mode) - The Scratch Pad allows the user to test the Logical Data Source and functions that have been added to the canvas with no mapping performed.

Mapping mode - When a target Logical Data Source is selected, the Scratch Pad background changes to grey that indicates it is in mapping mode. The user can perform an actual Logical Data Source mapping and visualise the mapping in this canvas.

Result tab

The Result tab displays the mapping details of the selected Logical Data Source and functions.

  • Name - The name of the Logical Data Source or function
  • Value - The value obtained as a result of mapping
  • Length - The length of the value
  • Data type - The data type of the value
  • Error information - Displays the details of any error encountered in the mapping
