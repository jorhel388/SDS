Data Transformation Overview

The Data Transformation component provides the user with the ability to perform mapping for Logical Data Source to Logical Data Source (LDS-to-LDS). The Data Transformation component can be used in a Decision Process Flow.

The benefits of this component are summarised below:

  • Provides a single component that handles the data transformation and mapping process.
  • Provides an intuitive visual representation of the data transformation and mapping process.
  • Reduces the scripting and programming knowledge needed to perform data transformation and mapping process.
Edit

The Data Transformation component enables a user to perform data mapping for Logical Data Source to Logical Data Source (LDS-to-LDS). The user can visualise the mapping via a graphical user interface and apply the required function during data mapping.

  • An overview of the Data Transformation functions is available in the Function Groups for the Data Transformation component section.
  • For a more comprehensive description of the functions, refer to the Data Transformation Functions User Guide.
Function Groups for the Data Transformation component

Below are the functions that can be used with the Data Transformation component:

Array

Functions for handling an array.

Function Name Description
As array

Creates an array.

For example, creating an array using the string input "cat" and "dog" results in [cat, dog].
Collate

Sorts the input values so identical values run consecutively.

For example, given the input array is [a, b, z, a, z], this function groups similar values and sorts them in ascending order, which results in [a, a, b, z, z].
Combine

Combines two arrays to make a single one with the values of both duplicated.

For example, combining two arrays with values of [a, b, c, d, e], results in [a, b, c, d, e, a, b, c, d, e].
Count

Counts the values in the input.

For example, given the array has five elements [b, c, a, c, b], this function counts the total elements in the array, results in "5".
Distinct

Extracts the unique values (deduplicates) in an array.

For example, deduplicating the unique values in the input array [b, c, a, c, b], results in [b, c, a].
Distinct count

Counts the unique values in the input array.

For example, given the array has five elements [b, c, a, c, b], this function counts the total unique elements [b, c, a] and returns the result as "3".
Even indexes

Extracts even indexed values.

For example, the even indexed values [b, d] (position 2 and 4) are removed from the array [a, b, c, d, e], which results in [a, c, e].
Filter numbers

Filters an array for numbers only.

For example, if an array has five elements [1, 2, a, b, 3], it returns the numeric elements in the array [1, 2, 3].
First

Returns the first value in the input array.

For example, if the array has five elements [a, b, c, d, e], it returns the first element in the array, "a".
First few

Returns the first "n" values in the input array.

For example, if the array has five elements [a, b, c, d, e], and the user inputs the count as 3, it will return the first three elements in the array and returns the result as [a, b, c].
Flatten

Flattens the input into a single array.

Example 1:

If the input is a Logical Data Model (LDM) containing 3 characteristics with values "Line1=A", "Line2=B" and "Line3=C", the function will return an array containing only value when "Include Keys" is disabled, which results in [A, B, C].

Example 2:

If the input is a Logical Data Model (LDM) containing 3 characteristics with values "Line1=A", "Line2=B" and "Line3=C", the function will return an array containing both key and value when "Include Keys" is enabled, which results in [value, Line1, A, Line2, B, Line3, C].
Frequency

Converts array values into an object of unique values with frequencies.

For example, if the array has five elements [a, b, b, c, c], this function returns an object containing unique values as a key, and each key is paired with a frequency as the value.

"a" has a frequency of 1

"b" has a frequency of 2

"c" has a frequency of 2

The result is {"a":1, "b":2, "c":2})
Get element

Gets an element from an array based on its position.

For example, if an array has five elements [a, b, c, d, e] and the given position is 3, this function returns the element "c".

If the array has five elements [a, b, c, d, e] and the given position is 6 (out of bounds), this function returns the default value set by the user, for example "z".
Get truths

Converts each element of an array into a Boolean truth value.

For example, if an array has five elements [0, 1, -1, y, n], this function converts "y" and "1" to true, and "0", "-1" and "n" to false, which results in [false, true, false, true, false].
Highest number

Returns the highest number in the input.

For example, if an array has five values [1, 2, 3, 4, 5], this functions returns "5".
Highest string

Returns the value in the input which comes last when the values are place in alphabetical order (following the order in a dictionary).

For example, if an array has five elements [d, b, c, e, a], this function returns "e".
Intersect

Creates a single array based on the common values from two arrays.

For example, this function combines the values from two arrays ([a, b, c, d, e] and [a, c, d]), and extracts the common values, which results in [a, c, d].
Last

Extracts the last value in the input.

For example, this function extracts the last value from the array [a, b, c, d, e], and returns the result as "e".
Last few

Extracts the last "n" values in the input.

For example, if the array has five elements [a, b, c, d, e], and the user inputs the value as 2, this function returns the last two value in the array which results in [d, e].
Least common

Returns a map of the least frequent value in the array and their frequencies.

For example, if the input array is [a, a, b, b, b], this function maps "a" and its frequency, 2, which results in {"a":2}.
Lowest number

Extracts the lowest number in the input.

For example, from the input [5, 2, 1, 3, 4], this function extracts the lowest number in the input which results in "1".
Lowest string

Returns the value in the input which comes first when the values are placed in alphabetical order (following the order in a dictionary).

For example, if an array has five elements [c, b, a, d, e], this function results in "a".
Most common

Returns a map of the most frequent values in the array and their frequencies.

For example, if the input array is [c, c, a, b, d], this function maps "c" and its frequency, 2, which results in {"c":2}.
Object to keys

Flattens an input into a single array of keys.

For example, given the input value {"country":"Ireland","street":"Main Street","zipcode":"A0001"}, the function flattens the input array into a single array and returns the keys. This results in [country, street, postcode].
Object to values

Flattens an input into a single array of values.

For example, for an input of {str=abcd, int=8}, this function extracts "abcd" and "8" and places them in an array, results in [abcd, 8].
Odd indexes

Removes the odd indexed values.

For example, from the array [a, b, c, d, e], this function removes the values in positions 1, 3 and 5, [a, c, e], which will results in [b, d].
Order

Sorts the input values in ascending order with numerals preceding alphabetic characters.

For example, for an input array, [2, c, a, b, 1], this function results in [1, 2, a, b, c].
Order numbers

Removes non-numeric values and sorts the remaining numeric values in ascending order.

For example, for the array [3, 2, a, 4, 5], this function removes [a] and sorts [3, 2, 4, 5], which results in [2, 3, 4, 5].
Parse

Splits a string using the criteria from a regular expression to create a single array.

For example, if the string input is "a b c a b c" and the criteria of the regular expression is "space" and distinct is disabled, this function results in [a, b, c, a, b, c].

Using the example above, if distinct is enabled, the function results in [a, b, c].
Process Array

Process an array based on the specified action that matches one or more search values.

For example, given the input value ["Cindy","Adam","John","Peter","Yani"], with the action "Contains all" and search values are "Cindy","Adam", the process output results in "True", because both the search values are found in the array.
Reverse array

Reverses the order of values in an array.

For example, if an array has five elements [a, b, c, d, e], this function returns the result as [e, d, c, b, a].
Reverse collate

Sorts input values so identical values run consecutively (collated) and then reverses the order.

For example, given the input array is [a, b, z, a, z], this function groups similar values and sorts the values in descending order, which is [z, z, b, a, a].
Reverse order

Combines the input values together where the sequence is taken as is, then reverses the order and stores the result in an array.

For example, the input string is taken as is (a, b, c), the function then reverses the order of the input that results in (c, b, a) and stored them into an array [c, b, a].
Reverse order numbers

Removes non-numeric values and sorts the remaining numeric values in descending order.

For example, for the array [3, 2, a, 4, 5], this function removes [a] and sorts [3, 2, 4, 5], which results in [5, 4, 3, 2].
Sub array

Creates an array based on a start and end position in the input array.

For example, if the input array is [a, b, c, d, e], the Start value is 2 and the End value is 4, this function will extract "b" (second position) through to "d" (fourth position) and place them in an array, which results in [b, c, d].

Text

Functions for manipulating text strings.

Function Name Description
After

The After function returns a value after a prefix.

For example, given the value [aZa, bzb, Zcc, zdd, ee] with prefix "Z" and case-sensitive is disabled, this function returns [a, b, cc, dd, ee]. It first get the values matching the prefix regardless of case-sensitive, [aZa, bzb, Zcc, zdd] and return the values after the prefix, which is "a", "b", "cc", and "dd". The remaining ones that are not matching the prefix case-sensitive, its value is preserved because "Preserve If Absent" is enabled.
Before

The Before function returns a value before a suffix.

For example, given the value [aZa, bzb, ccZ, ddz, ee] with suffix "Z" and case-sensitive is disabled, this function returns [a, b, cc, dd, ee]. It first get the values matching the suffix regardless of case-sensitive [aZa, bzb, Zcc, zdd] and return the values after the suffix, which is "a", "b", "cc", and "dd". The remaining ones that are not matching the suffix case-sensitive, its value is preserved because "Preserve If Absent" is enabled.
Between

The Between function returns a value after a prefix and before a suffix.

For example, the function extracts the value between "A" (start position) and "C" (end position) with case-sensitive disabled from these values "a1c, A2C, c3a, C4A, 5", results in "1, 2, , , 5". The input value that does not have "A" and "C" character with case-sensitive disabled will remain as original in the final result with "Preserve If Absent" enabled.
Bracket

The Bracket function brace a value with a start and a close bracket if not present.

For example, encapsulate the value "some place" with an opening bracket "(" and a closing bracket ")", will results in "(some value)".

  The open brace and close brace must not be empty, otherwise an error will be displayed.
Concatenate

The Concatenate function concatenates a list of values.

Example 1: Concatenate the value "cat" and "dog" with " & " as the delimiter, the function return the result as "cat & dog".

Example 2: Given an array of values [cat, dog, bird, fish, ant], this function returns the value by concatenating all of them with "space" as the delimiter, which is "cat dog bird fish ant".
Delimit

The Delimit function adds a delimiter to an array of values.

For example, given an array of values [a, b, c, d, e] and "z", this function combines all the input values into a string. Each input value is encapsulated with quote as "Always Quote" is enabled, and delimited by comma ",". The result is "a","b","c","d","e","z".
Denoise

The Denoise function removes noise from an input.

For example, given the value is "a 1 b 2 c 3 e 4 ?", this function removes noises based on the options enabled which are "Spaces" and "Punctuation", which results in "A1B2C3E4".
Edit Distance

The Edit Distance function calculates the edit distance between two strings. See the examples below.

Example 1: This function returns the total unedited characters when the comparison value is use to modify the input. Given the value "0123456789" as the input and value to compare is "0123", the total characters found in "0123" that matches the input to be editable is 4, hence the result of unedited character is 6 (10 - 4 = 6).

Example 2: This function displays the percentage of characters that is covered by the comparison value against the input when "As Percentage Difference" is enabled.
Insert

The Insert function inserts one value into another at a given position.

For example, given the input "abde" with value to insert "c" and position to insert the value is 2 to insert between "ab" and "de", the result is "abcde".
Length

The Length function returns the length of the input.

For example, given the input "abcde", this function calculates the total characters in the string, which is 5.
Lower Case

The Lower Case function converts a string to lower case.

For example, given the input "AbCdE", this function converts all characters in the string to lower case, which is "abcde".
Pad

The Pad function pads an input to a length with pre or post value.

Example 1: Pad the input "Help" with "!" for 3 times ("Help" is 4 characters, Total Characters is 7, Padding is 7-4=3), results in "!!!Help" with "Post Fill" disabled.

Example 2: Pad the input "Help" with "!" for 3 times ("Help" is 4 characters, Total Characters is 7, Padding is 7-4=3), results in "Help!!!" with "Post Fill" enabled.
Position Of

The Position Of function finds the first or last position of a search value in an input value. It returns zero if the search value is not found.

Example 1: Find the first occurrence of the value "c" (case-sensitive disabled) in the input "abcdeC", which is 3.

Example 2: Finds the last position of the value "c" in the input "abcdeC", which is 6.

Example 3: Finds the last position of the value "c" (case-sensitive enabled) in the input "abcdeC", which is 3.
Position Of All

The Position Of All function finds the first or the last position of any set of values in the first value. It returns zero if a matching value is not found.

For example, the function finds the matching value of "c" and "i" in the input value "Cecilia", which is [3,6] (position of "c" and "i" as the last occurrence).
Position Of Any

The Position Of Any function finds the first or the last position of any set of values in the first value. It returns zero if a matching value is not found.

For example, finds the matching value from the set "x", "y" and "z" in the input "abcdez", which is 6 (position of "z")
Proper Case

The Proper Case function converts a value to proper case (upper case for the first letter of a word).

For example, change the first letter of each word in "eat tea ate" to upper case will results in "Eat Tea Ate".
Remove Control Chars

The Remove Control Chars function removes the control characters from the input.
Repeat Value

The Repeat Value function repeats the input for a number of times.

For example, repeat the input "test" for three times will results in "testtesttest".
Replace Pattern

The Replace Pattern function replaces the occurrences of the regular expression in the input with the replacement pattern.

Example 1: Replace the letter "s" with "p" using regular expression in the input "set send", results in "pet pend" with "Replace First Match" disabled.

Example 2: Replace the letter "s" with "p" using regular expression in the input "set send", results in "pet send" with "Replace First Match" enabled.
Replace Value

The Replace Value function replaces all the occurrences of the search value in the input with a replacement value.

For example, replace the value "e" with "a" in the input "set send", results in "sat sand" with case-sensitive disabled.
Reverse Text

The Reverse Text function reverses the order of the text.

For example, reverse the input "abcde" will results in "edcba".
Substring

The Substring function extracts a substring from an input based on the position specified.

For example, extracts the characters between the position "2" (refers to "b") and position "4" (refers to "d") in the input, results in "bcd".
Title Case

The Title Case function converts a string to title case, where the first letter of the first word is capitalised.

For example, given the string "vegetable fruit meat", this function sets the first letter of the first word to upper case, which is "Vegetable fruit meat".
Translate

Translates a value from a translation map.

For example, given the input value is "vegetable", this function finds the matching key from the map (fruit, vegetable and meat), and returns the matching key's value, which is 2.

  Additional key-value pair can be added into this function. There must be at least one key-value pair in this function, otherwise an error is displayed.
Translate Number Sign

The Translate Number Sign function translates the sign of a number to text.

Example 1: Given the input value is "1" which is a positive integer, the function returns the text value "positiveValue" as defined by the user in the "Positive Text" parameter of the function.

Example 2: Given the input value is "0" which is a zero integer, the function returns the text value "zeroValue" as defined by the user in the "Zero Text" parameter of the function.
Trim Space

During a bulk mapping, fuzzy mapping is triggered when one of the following indicators are shown.

In the example above, the user is bulk mapping the parent node 'Customers' with the 'FMTargetLDS' node and this action triggered the fuzzy mapping feature.

  • A blue top bar with the message 'There are multiple mapping options' is shown indicating that fuzzy mapping is triggered. Clicking 'x' at the top bar will display a pop-up dialogue with options for user to accept or reject the fuzzy mapping recommendations.

  • The characteristics in the data source has either the or the icons. The numbers in the icon could be 1, 2 or 3, which indicates the number of possible matches available for the characteristic.

Choose Alternate Mapping window, Match quality and Field match quality

The fuzzy mapping process also provides two additional mapping suggestions indicated by the number (2) in the mapping icon. When you select 'Choose Alternate Mapping' option, the following Choose Alternate Mapping window is displayed showing the alternative characteristics that can be mapped.

Field match quality refers to the degree of similarities between the source characteristic name and the target characteristic name. There are four categories of field match quality as listed below.

  • Equality
  • Close edit distance
  • Near edit distance
  • Loose edit distance

Edit distance is a way of quantifying how dissimilar two strings (for example, words) are to one another by counting the minimum number of operations required to transform one string into the other. For more information, refer to https://en.wikipedia.org/wiki/Edit_distance.

Match quality refers to the matching or compatibility percentage between the source and the target characteristic names. The compatibility percentage is calculated based on two main factors:

  1. Field match quality
  2. The distance between the location of the source characteristic and target characteristic.

In the example below, there are two 'Surname' field in the Source LDS that can be map to the Target LDS 'Surname'.

Source LDS Target LDS

First option: Applicant → Surname

Second option: Applicant → Employer → Address → Surname

 Applicants → Surname

In the Choose Alternate Mapping window as shown below, you will notice that the second option (Applicant → Employer → Address → Surname) has a lower match quality percentage (40%) due to the location of the characteristic which is more nested as compared to the other characteristic.

Although the match quality is calculated, the higher percentage does not necessarily mean that source characteristic is the most suitable for that particular target characteristic. Fuzzy mapping helps you to improve the accuracy of the mapping by providing alternative mapping suggestions. However, user have the liberty to choose the source that they think is the most suitable characteristic to map to that target characteristic.

For example, you can select 'Name' characteristic with 46% match quality to map to the 'Surname' target characteristic in the above scenario.
