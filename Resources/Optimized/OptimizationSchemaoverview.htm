Optimization Schema overview

The Optimization Schema component stores optimization schema files generated from Optimize for use within the solution. The Optimization Schema is then used in the Optimized Decision component.

Create

An Optimization Schema can be created from the Explorer window.

 

You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed, it will not be listed.

To allow a component type, right click on the folder and select Manage allowed component types.

To create an Optimization Schema

  1. In the Explorer window, right click on the required folder and select Add component.
  2. Select Optimization Schema. The component is identified by the icon.
  3. In the Create component dialog, enter the name of the Optimization Schema:

    You can select the Open new components in component editor option to automatically open the schema after creating it.

  4. Click on the OK button.

The Optimization Schema name will be listed in the Explorer window under its parent folder.

To open the Optimization Schema in the editor, right click on it and select Open.

Import

The user must import an XML schema file into the Optimization Schema component. The schema will be compressed and held within the Optimization Schema component, which is held within the repository and used in an Optimized Decision. This ensures that the schema remains associated with the Optimized Decision.

To import a schema

  1. In the Optimization Schema editor, click on the Import button:

    The Import dialog is displayed.

  2. Navigate to the Optimization Schema XML file and click on the Import button.
     If the XML file is not a valid XML (i.e. it is not well-formed) or some of the key schema properties such as Schema ID or version are missing, the file will not be imported.

    The General Information and Optimization Schema Information areas of the editor are automatically updated to display information about the attached schema:

  3. Click on the icon to save the attachment.

The Optimization Schema that has been saved to this component can now be associated with an Optimized Decision.

Export

The Optimization Schema that is attached to the Optimization Schema component can be saved to another location.

To export a schema

  1. Open an Optimization Schema component that has a schema attached.

  2. Click on the Export button. The Export dialog is displayed.
  3. Navigate to the location you require and click on the Save button.

The schema will be saved to the selected location.
