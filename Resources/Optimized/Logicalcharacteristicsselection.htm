Logical characteristics selection

Logical Characteristics – the logical characteristics tree/table displays all logical data sources that are present in published to the folder in the system composition where the Optimized Decision component has been created.

Use the Filter functionality to identify the Logical Data Source characteristics to which the schema characteristics will be mapped.

Show Table View – toggles the display of logical characteristics between tree or table view. The table view shows the full characteristic name, including the path name:

Logical characteristics filters

Two sets of filters can be used to help the user find and select characteristics from the set of logical characteristics in the Optimized Decision editor.

Filter for Data Types – allows the user to limit the display of logical data characteristics to one or more types.

Filter by Characteristic Name – type a word or part of a word next to the Search icon and the editor will only display those characteristics whose names match the entered text. Name filtering includes the full logical name of the characteristics. For example, the characteristic Application Risk will be listed if the user enters 'App' or 'app' because it is present in 'Application'.

A wildcard (*) can be used to match any characteristics or sequence of characteristics, usually with other characters. For example, ‘app*risk’ will match ‘Applicant Risk’ or ‘Application Risk’.
