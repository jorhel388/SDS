Optimization Schema editor

The Optimization Schema editor allows the user to store the Optimization Schema file for use within the solution. See Optimization Schema overview for more information.

The Optimization Schema editor consists of:

- select to import an optimization schema exported from Optimize for storing with this component.

- select to export the optimization schema file that is attached to this component to another location.

- select to remove the attached schema file from this component.

Optimization Schema Information - provides details about the Optimization Schema component:

  • Supported Extension(s) - the file types that can be attached to this component. Optimization Schema supports .xml files.
  • Description - a description of the component provided by the business user for context.

General Information - provides details about the name and size of the attached XML file.

Optimization Schema Information - provides details about the optimization schema file.

  • Schema ID - the schema ID as described in the XML file.
  • Schema Version - the schema version as described in the XML file.

These attributes are set inside the Optimize software.

  • Compressed Size - the size of the schema after it is compressed by the Optimization Schema component and saved in the repository.
