Working with Optimization schemas

Select a schema

The user must select an Optimization Schema for use in the Optimized Decision component.

To select an Optimization Schema

  1. With the Optimized Decision editor open, in the Resources window, click on the expand (+) button to display the contents of the Optimization Schema:

  2. Drag and drop the Optimization Schema into the Optimization Schema field:

The Schema Characteristics table is automatically populated with the schema characteristics. They must now be mapped to the logical characteristics either manually or automatically.

Select characteristics

Schema Characteristics – the schema characteristics table displays all characteristics in the optimization schema. Once mapped to logical characteristics, they will appear in the Mapped Characteristics table.

Use the Filter functionality to identify the schema characteristics that will be mapped.

Filter

A filter can be used to help the user find and select characteristics from the set of schema characteristics in the Optimized Decision editor.

Filter by Characteristic Name – type a word or part of a word next to the Search icon and the Select Characteristic dialog will only display those characteristics whose names match the entered text. Name filtering includes the full logical name of the characteristics. For example, the characteristic Application Risk will be listed if the user enters 'App' or 'app' because it is present in 'Application'.

A wildcard (*) can be used to match any characteristics or sequence of characteristics, usually with other characters. For example, ‘app*risk’ will match ‘Applicant Risk’ or ‘Application Risk’.

Clear

The Optimization Schema that is attached to the Optimization Schema component can be removed from the Solution Repository.

To clear a schema

  1. Open a Optimization Schema component that has a schema attached.
  2. Click on the Clear button. The General Information and Optimization Schema Information areas of the editor are cleared as well:

  3. Click on the icon to save your changes.

The schema will be removed from the Optimization Schema component and will no longer be available within the solution.

  If you associate an Optimized Decision with an empty Optimization Schema, no Schema Decisions or Decision Metrics will be displayed.
Map Arrays

Users can map schema characteristics by specifying the indices for the array characteristics. This feature is enabled whenever an array element appears anywhere within the hierarchy of the selected characteristic.

  An Optimized Decision only supports static arrays for input characteristic mappings.

To map an array

  1. In the Marketswitch Optimized Decision editor, within the Optimization Inputs tab identify and click on the schema characteristic you want to map.
  2. Identify and click on an array logical characteristic, or a characteristic that has an array element within its hierarchy. Use the Filters functionality, if necessary. For example:

  3. Click on the button to map the characteristics. The Select Characteristic Array Element(s) dialog is displayed, identifying the array characteristics that appear in the hierarchy:

  4. Specify the index of the array element by typing a value in the Index field. You must enter a number within the bounds of the array (as defined in the Type field).
  5. Click on the OK button to complete the characteristics mapping.

The mapped characteristic is displayed with the appropriate index:
