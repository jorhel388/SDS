Optimization overview

The business user can deploy and execute an Optimization strategy in PowerCurve via the Decision Process Flow. This is achieved using the Optimized Decision and Optimization Schema components.

Once the user has exported a selected scenario from Optimize to an XML schema file, they can import it in the PowerCurve Design Studio and incorporate it in a Decision Process Flow. When the Decision Process Flow is deployed and invoked within the Decision Agent, the Real-Time Optimization Engine is invoked to make an optimized decision in real time as shown in the diagram below:

Within the PowerCurve Design Studio, the business user can:

  • Import a real-time schema generated by Optimize to create a Optimization Schema component in the PowerCurve solution.
  • Configure the Optimized Decision component to refer to the selected schema and test it interactively.
  • Deploy the Optimized Decision in a Decision Process Flow.
    •   A Decision Process Flow may contain more than one Optimized Decision component.

    When the Decision Process Flow is deployed, the Decision Agent calls the Real-Time Optimization Engine - a module that executes the optimization schema in real time. It evaluates a single record and returns the optimal decision or a set of decisions for the particular strategy based on the input data provided in real-time.

    The Optimization Schema is a serialized representation (XML) of an optimization scenario created in Optimize, and includes all inputs, decisions and metrics required by the Real-Time Optimization Engine to process a call in a production environment. The inputs from the schema are referred to as schema characteristics in the PowerCurve Design Studio, while the actions are referred to as Schema Decisions, in accordance with the Optimize naming conventions.

    The integration of Optimize in the PowerCurve Design Studio is achieved via two components:

    • Optimization Schema - stores the schema file that is generated from Optimize.
    • Optimized Decision - used to configure the mapping of input Logical Data Sources to Schema Characteristics and the mapping of Decision Metrics to a selected output Logical Data Source using a system generated embedded Logical Data Model, and to incorporate the Optimization Schema into a Decision Process Flow.

    Within the studio, a typical workflow includes the following steps:

    1. Create an Optimization Schema and import the schema file exported from Optimize. The file is saved in the Solution Repository as a Optimization Schema component.
    2. Create an Optimized Decision and associate the Optimization Schema component with it.
    3. Map the Schema Characteristics to the corresponding Logical characteristics defined in the available Logical Data Source within the Optimization Inputs tab.
    4. Enter a value for the maximum selected decision into the Max Selected Decision field in the Optimization Results tab.
    5. Map the Decision Metrics to the corresponding Logical characteristics defined in the embedded Logical Data Model within the Optimization Results tab. This should correspond to the Maximum Decision Options allowed per customer as defined in the Optimize scenario.
    6. Validate the Optimized Decision.
    7. Test the execution of the Optimized Decision either with the Interactive Tester or, in batch, with a Test Project.
    8. Incorporate the Optimized Decision in a Decision Process Flow
    9. Test the execution in the context of the flow, again using the Interactive Tester or a Test Project.
    10. Deploy the Decision Process Flow to the operational environment where it will be invoked via the Decision Agent, which in turn invokes the Real-Time Optimization Engine.

    After the Optimized Decision is executed, the Real-Time Optimization Engine will return a decision or set of decisions and the corresponding metrics associated with assigning these decisions. PowerCurve Design Studio then executes these decisions, assigning the results characteristics as specified.

      PowerCurve Design Studio works with schemas deployed from Optimize 8.0 and later.

    For more information about Optimize and the Real-Time Engine, see the Optimize User Guide. For information on how to configure the integration between PowerCurve and Optimize see the Real-Time Optimize Engine Installation and Configuration Guide.
