Tree Growing Profile

From the Tree Growing Parameters sub editor, the user must select a tree growing profile from the drop down menu. The tree growing profile contains the various settings used to create segmentation that best conforms to the user's requirements.

Overview

All profiles use a CHAID (Chi-square Automatic Interaction Detector) algorithm for growing the tree. CHAID is a tree-based exploratory method used to study the relationship between a target characteristic and a series of predictors.

The purpose of CHAID is to produce a meaningful set of rules for segmentation of a population. The CHAID algorithm allows splits with any number of child nodes, limited only by the constraints imposed by the profile selected. The pre-configured tree growing profiles in Assisted Design Project allowing splits ranging from "up to 2 intervals" to "up to 10 intervals". "Splits of up to 3 intervals" is the default profile.

The standard Tree Growing profiles are pre-configured with the recommended settings, guidance on which to use can be accessed by viewing the tool tips attached to each profile from within the editor.

Users with advanced statistical expertise can use the button to edit the following settings as shown in the screenshot below:

  • Significance Threshold (p-value)
  • Min records into leaf node
  • Max levels to grow
  • Max leaf nodes to grow

This will further influence certain aspects of the tree growing.

The button will reset the values back to the default for the particular Tree Growing Profile the user has selected.

Significance Threshold (p-value)

P-value shows the level of significance of a given split. It reflects the probability for a given relationship between intervals and target occurring purely by chance. The recommended range of variation for the p-value threshold is from 0 to 0.5. If the threshold is set too close to 0, then no split with a p-value below this threshold may be found; if too close to 0.5, the resulting split may be meaningless. The default value for this parameter varies by profile. This setting modifies the behaviour of Grow only.

Min records into node

The minimum number of records required in the leaf nodes. The minimum number of records for the split to be considered robust is 50. The maximum number will depend on the specific business case. If the purpose of the tree is to create segments on which other statistical models will be developed, then the recommended minimum is 2500. You should also consider the overall sample size and the acceptable proportion of this in any given leaf node.

Max levels to grow

The maximum tree levels to grow from the selected node. Trees with too many levels offer less predictive power. It is recommended that the range for CHAID is set between 3 and 7, although the value specified depends on the requested maximum number of intervals associated with the profile. The lower the number of intervals, the more tree levels will be grown.

Max leaf nodes to grow

The maximum new leaf nodes to generate from the selected node. The recommended value would depend on the specific business case. If the purpose of the tree is to segment a portfolio, then fewer leaf nodes are recommended to create a more compact tree which can be easily visualised and understood. If the purpose of the tree is create finer groupings of customers and rank them with respect to a target variable, then specifying a higher value is recommended. When deciding how large to grow the tree, consider also the different options that are available for assigning outcomes to the resultant leaf nodes.

In addition to these parameters, a number of other factors also influence the result of the tree growing algorithm. The most significant of these is the Splitting Criterion.

Splitting Criterion

The statistic used to determine the optimal split of a node. Chi-Square and GINI are implemented as splitting criterions. GINI is used only for the "Splits of up to 10-intervals" profile, for all other profiles Chi-Square is the default. Chi-Square usually produces splits with a number of child nodes less than the maximum number specified. GINItends to create the maximum number of child nodes allowed, although it also depends on the value of the Significance Threshold (p-value). On "Grow" the split with the highest value of the splitting criterion is selected.

Select Tree Growing Parameters

From the Tree Growing Parameters sub editor, the user can specify, from all the characteristics in the logical data source, which ones to use as predictor characteristics and which to use as the target characteristic. Rounding can also be specified for predictor characteristics; this user defined rounding will be used to create the intervals in tree growing processes. If not specified or invalid, the user can still work with the Assisted Design Project, but can’t perform next best split analysis or tree growing.

To select tree growing parameters

  1. From the Navigator window, right click on Tree Growing Parameters and select Open Editor to display the Tree Growing Parameters sub editor.
  2. In the Tree Growing Parameters sub editor, using the filters if necessary, identify and select the target characteristic from the list of tree growing characteristics, then click on the Add Target button to add the characteristic to the Target Characteristic field. Only mapped characteristics will be shown.
  3. To clear the Target Characteristic field, click on the Clear Target button .
  4. Select the predictor characteristics from the list, and click on the Add Selected Predictor(s) button to add them to the Predictor Characteristics window. Click on the Add All Predictors button to add all the characteristics at once.
  5. To remove characteristics from the list of predictor characteristics, click on the Remove Selected Predictor(s) button or on the Remove All Predictors button to remove all characteristics.
  6. For numeric characteristics, check the Rounding tick box to select rounding.
  7. Right click the rounding icon to choose between: Round to the specified number of decimal places, and Round to the nearest increment as specified (e.g., 100).
  8. On closing the editor, click on the Save button in the Question dialog to save the parameter assignments.
Select a Tree Growing profile

To select a tree growing profile

  1. From the Navigator window double click on the Tree Growing Parameters.
    The Tree Growing Parameters sub editor will open.
  2. Select a Tree Growing Profile from the drop down menu.

    The tree growing profile contains the various settings used to create segmentation that best conforms to the user's requirements.
    All profiles use a CHAID (Chi-square Automatic Interaction Detector) algorithm for growing the tree

The standard Tree Growing profiles are pre-configured with the recommended settings, guidance on which to use can be accessed by viewing the tool tips attached to each profile from within the editor.

Tree Growing Profile default values

The following lists the default values for all the Tree Growing Profiles.

Boolean Splits

This profile is recommended when the classification power of the resulting segmentation is very important. However, if using Grow, the end user may find it difficult to view or understand the detail of a tree that has been grown using this profile due to the large number of segments and nodes that can be generated.
