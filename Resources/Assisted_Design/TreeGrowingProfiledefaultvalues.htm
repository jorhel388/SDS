Tree Growing Profile default values

The following lists the default values for all the Tree Growing Profiles.

Boolean Splits

This profile is recommended when the classification power of the resulting segmentation is very important. However, if using Grow, the end user may find it difficult to view or understand the detail of a tree that has been grown using this profile due to the large number of segments and nodes that can be generated.

Default Settings for Boolean Splits

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.05 in range [0.001 - 0.3]

Min records into leaf node

100 in range [50-2500]

Max levels to grow

10 in range [2-10]

Max leaf nodes to grow

500 in range [2-500]

Maximum Total Nodes

1000

Splits of up to 3 intervals

This profile is recommended for building compact trees with no more than 3 intervals in each split.

Default Settings for Splits of up to 3 intervals

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.05 in range [0.001 - 0.3]

Min records into leaf node

100 in range [50-2500]

Max levels to grow

5 in range [2-7]

Max leaf nodes to grow

50 in range [3-500]

Maximum Total Nodes

2000

Splits of up to 4 intervals

This profile is recommended for building medium sized trees with no more than 4 intervals in each split.

Default Settings for Splits of up to 4 intervals

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.05 in range [0.001 - 0.3]

Min records into leaf node

100 in range [50-2500]

Max levels to grow

5 in range [2-7]

Max leaf nodes to grow

75 in range [4-700]

Maximum Total Nodes

5000

Splits of up to 5 intervals

This profile is recommended for building large sized trees with no more than 5 intervals in each split.

Default Settings for Splits of up to 5 intervals

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.05 in range [0.001 - 0.3]

Min records into leaf node

100 in range [50-1000]

Max levels to grow

5 in range [2-6]

Max leaf nodes to grow

100 in range [5-800]

Maximum Total Nodes

7000

Splits of up to 6 intervals

This profile is recommended for building large trees with no more than 6 intervals in each split. Manual tree adjustment is recommended after using the Tree Growing operation.

Default Settings for Splits of up to 6 intervals

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.05 in range [0.001 - 0.3]

Min records into leaf node

100 in range [50-1000]

Max levels to grow

3 in range [2-6]

Max leaf nodes to grow

125 in range [6-800]

Maximum Total Nodes

9000

Splits of up to 10 intervals

This profile is recommended when the statistical significance is not the key importance and the goal is to quickly create a tree with minimally predictive data. Usually, manual tree adjustment is expected after the Tree Growing operation.

Default Settings for Splits of up to 10 intervals

Default Settings for Boolean Splits

Significance Threshold (p-value)

0.15 in range [0.05, 0.5]

Min records into leaf node

100 in range [50-500]

Max levels to grow

2-5

Max leaf nodes to grow

200 in range [10-1000]

Maximum Total Nodes

10000
