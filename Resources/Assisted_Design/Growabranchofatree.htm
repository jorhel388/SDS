Grow a branch of a tree

The user can allow Assisted Design to grow the tree one or more levels automatically, by allowing the software to choose which characteristics are most predictive, and how best to split them. The branch will grow according to the specified tree growing parameters, without any initial on-screen analysis by the user.

  For tree growing to work, both the client and the server must have access to the data source. Read only access is enough.

The resulting branch displays the automatically identified sub segments that will provide the best segmentation given the tree growing parameters.

  A branch can only be grown from a leaf node of a tree.

Measures can be calculated for new leaf nodes, both before and after making assignments, for both input measures and results measures.

To grow a branch of the tree

  1. From the Assisted Design Project Tree editor, right click on a leaf node of the tree and select Grow.
  2. The branch grows according to the specified tree growing parameters.
  3. Provide leaf node names, outcome assignments, etc., according to the type of tree selected for the Assisted Design Project.
  4. You can continue to prune and grow leaf nodes of the branch until you are satisfied with the results.
  5. On closing the editor, click on the Save button in the Question dialog to save the Assisted Design Project.
  6. You can test the Assisted Design scenario, either manually or using the export scenario test results.
  7. You can compare the measure results for the primary data set and a comparison data set to validate the scenario.

You can reopen and modify the Assisted Design Project whenever you want, however, the tree you have created cannot be used by other components until it has been promoted for use as a new tree or it has been used to replace or merge with an original tree.

  If, while a tree grow job is running, the Assisted Design Project is closed, the job will continue to run in the background. If the job is still running when the Assisted Design Project is reopened, users will not be able to perform any actions in the editor and the tree will be dimmed until the job is complete

To stop a tree grow job

  1. In the Output window, click the stop button.
    2.  

    The stop button will be unavailable if any of the following criteria are met: no job has been submitted, all running jobs have been completed (successfully or with errors), the job failed. Information regarding the progress of a job, as well as success or failure upon completion, can be found in the Output window.

     

    All running jobs can be stopped (this must be done one job at a time), but jobs in the queue cannot be stopped.
