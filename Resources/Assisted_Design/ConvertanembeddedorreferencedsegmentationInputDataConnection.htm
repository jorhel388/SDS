Convert an embedded or referenced segmentation Input Data Connection

An Input Data Connection can be referenced from within the Analysis Data Set. This means it can be changed from outside of the Analysis Data Set and may be shared by other Analysis Data Sets. Alternatively, these Input Data Connection components can be created from within the Analysis Data Set editor and will be embedded into the Analysis Data Set. This means the component details are only used by this Analysis Data Set and can only be edited from within the Analysis Data Set.

Should the user wish to change an embedded input data connection to a referenced input data connection or a referenced input data connection to an embedded input data connection, there is a Convert option in the Analysis Data Set editor.

To convert an Input Data Connection component

  1. Within the Analysis Data Set editor open, right click on an Input Data Connection that has already been assigned to the Analysis Data Set editor and select Convert.
    The system will open the Convert Component dialog:

  2. Type the name you require in the Convert To field.
  3. If you are converting an embedded component to a by reference one, you can select where to locate the new component within the system composition by clicking on the Change button.
  4. Click OK. The system will convert the Input Data Connection.

If you have converted an embedded input data connection to a referenced input data connection the new referenced input data connection will appear in the Resources window and be available for use in other Analysis Data Sets. If you have converted a referenced input data connection, the referenced input data connection will still exist in the Resources window, but a new embedded input data connection will exist in the editor.
