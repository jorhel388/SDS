Add an embedded Input Data Connection

The Analysis Data Set is an embedded or by reference Input Data Connection. The user must specify a primary analysis data set, and an optional comparison data set. The user can add an embedded or by reference filter, or weighting to either data set to limit the number of records that will be included in the analysis.

To add an embedded Input Data Connection and a Filter

  1. With the Analysis Data Set sub editor open.
  2. Where no Input Data Connection has been set, you can right click on the Primary Data Set field, and select Insert Embedded:

  3. Alternatively, you can drag Embedded Input Data Connection from the Palette and drop it into the Primary Data Set field:

  4. The Insert Embedded Component dialog is displayed:

  5. Rename the component and click on the OK button to open the Input Data Connection editor.
  6. Once the embedded Input Data Connection has been created, you can right click on the Input data connection field to open the Input Data Connection editor, convert the embedded Input Data Connection, clear the field, or rename the component.
  7. Repeat steps 2 to 7 to insert an embedded Input Data Connection into the Comparison data set field, if desired.
  8. (Optional) If desired, you can add an embedded or by reference filter to limit the number of records that will be included in the analysis, for either the primary data set or the comparison data set, or both.
  9. To add an existing filter to either data set, expand the Filter list in the Resources window to display the available filters. For example:

  10. Drag and drop the required filter into the Primary filter or Comparison filter field.
  11. To create a new filter, right click in the filter field and select Insert Embedded to display the Insert Embedded Component dialog:

  12. Rename the filter to something meaningful, and click on the OK button to display the filter scripting editor. This editor is a standard scripting editor and is very similar to the Boolean Expression editor.
  13. Create the filter script, click on the Compile Script button to validate it, then click on the close button to exit the scripting editor.
  14. Optionally, you can add a weight attribute or scaling factor in the Data Set Weighting field.

The Analysis Data Set is now configured for use.

 

The Input Data Connection editor includes a feature that is unique to embedded Input Data Connections for Assisted Design Projects.

The list of filters in the Logical Characteristics window includes the ability to limit the display of unmapped characteristics to one or more of the following types: Data Set Filter lists unmapped characteristics required for the specified data set filter; Segmentation filter for all tree segmentation characteristics; Measures filter for all measure input characteristics, including filters; Tree Growing filter for all segmentation input characteristics and characteristics referenced in tree growing parameters; Tree Testing filter for all segmentation and assignment input characteristics; and Impact Analysis filter for all characteristics used in impact scripts.

This list of filters is not included for the by reference Input Data Connections.
