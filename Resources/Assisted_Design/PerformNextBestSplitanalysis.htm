Perform Next Best Split analysis

The user can use Next Best Split to identify and rank a set of predictors for the next level of the tree. The user will assess the proposed splits and choose which one to apply to the tree, based on statistical measures and measures from the Assisted Design Project.

 

Next Best Split analysis can only be performed for a leaf node of a tree.

To include Assisted Design Project measures in the Next Best Split analysis, you must have selected the Include measure results during next best split check box on the Tree Growing Parameters sub editor. The performance of Next Best Split will be slower if you choose to calculate measures, especially if many predictors are included.
  If you define data weighting in the Analysis Data Set, the weighted data will not be used in the calculation of the Next Best Split statistical measures. Therefore statistical measure results will be unweighted. However, any user-defined target and input measures will be based on the weighted data set.

To perform Next Best Split analysis

  1. From the Assisted Design Project Tree editor, right click on a leaf node of the tree and select Next Best Split.

    The software identifies and ranks a set of predictors for the next level of the tree in the Next Best Split dialog, but does not change the structure of the strategy tree.

  2. Click on the Column button to choose from the available measures to assess the strengths of the various predictors. Statistical measures are available by default; you can also choose to display measures from the Assisted Design Project.
  3. Expand each predictor to review the measures for each interval.
  4. Select the predictor that best meets your objectives, and click on the button to apply the selected split to the tree.
  5. The Add Split dialog will be activated allowing you to preserve existing assignments at the leaf node. Click on the Confirm button.
  6. Provide leaf node names, outcome assignments, etc., according to the type of tree selected for the Assisted Design Project.
  7. You can recalculate existing measures for new leaf nodes, to help assess which splits best meet user objectives, or add new measures.
  8. You can continue to prune and grow leaf nodes off the branch until you are satisfied with the results.
  9. On closing the editor, click Save in the Question dialog to save the Assisted Design Project.
  10. You can test the Assisted Design scenario, either manually or using the export scenario test results.
  11. You can compare the measure results for the primary data set and a comparison data set to validate the scenario.

You can reopen and modify the Assisted Design Project whenever you want; however, the tree you have created can not be used by other components until it has been promoted for use as a new tree or it has been used to replace or merge with an original tree.

  If, while a next best split job is running, the Assisted Design Project is closed, the job will continue to run in the background. If the job is still running when the Assisted Design Project is reopened, users will not be able to perform any actions in the editor and the tree will be dimmed until the job is complete.

To stop a next best split job

  1. In the Output window, click the stop button.
    2.  

    The stop button will be unavailable if any of the following criteria are met: no job has been submitted, all running jobs have been completed (successfully or with errors), the job failed. Information regarding the progress of a job, as well as success or failure upon completion, can be found in the Output window.

    All running jobs can be stopped (this must be done one job at a time), but jobs in the queue cannot be stopped.
