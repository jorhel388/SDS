Use Project Characteristics to create measures

Project Characteristics make it simple for the user to create measures at the point they are required during the Assisted Design process - from within the Assisted Design Project Tree editor, the Measures sub editor, or the Outcome Assignment Parameters sub editor.

Project Characteristics are grouped together in the Resources window into folders that reflect how the characteristics are currently used within the Assisted Design Project. The order of the folders reflects the user’s typical workflow order in Assisted Strategy Design: from Review and Analysis, through to Intelligent Tree Growing, and onto Impact Analysis and Propose Best Outcomes.

For example, if the user is growing a tree in the Assisted Design Project Tree editor, they can drag a set of Project Characteristics into the editor and turn them into measures. The user can then calculate these measures in the tree scenario, and decide on the basis of review and analysis and whether to use these characteristics as predictors or not.

Similarly, if the user is working in the Outcome Assignment Parameters sub editor, they may want to select a constraint measure that has not yet been defined. Without leaving the editor, the user can drag and drop a characteristic from the Tree Results or Impact Results into the Constraints Definitions Measure field and the Create Measures dialog will open. The user can then create a measure which will be immediately added to the drop down list of available constraint measures.

Measures can be created from one characteristic at a time; or (within the Assisted Design Project Tree editor and the Measures sub editor) measures can be created from multiple characteristics of the same type. See Create measures using Project Characteristics for details.

Project Characteristics are grouped together in the Resources window by type:

Allows the user to access characteristics that have been mapped, irrespective of whether they are used in the project.

For Decision Process Trees, the Project Characteristics provide the user with access to the input and results characteristics for all of the assigned processes; these can be used to create new measures.

If the sequence includes one or more Scorecard or Decision Setter processes, additional nodes will appear in the Tree Results for each process. These include the typical results characteristics for that process type. For Decision Process Trees they retrieve mapping information for the processes from the Decision Process Sequence, so this information is used inside the Assisted Strategy Design project. This means that if characteristics are mapped then they will appear as mapped results characteristics, and will be removed from the generic results data model section.

Displaying full characteristic names

There are two ways to display the full name of a characteristic:

  • Position the cursor over the characteristic name to display a tool tip.

  • Right click on Project Characteristics, and select Show Path from the context menu.
