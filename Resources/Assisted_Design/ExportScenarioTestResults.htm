Export Scenario Test Results

In Assisted Design, the user can test the tree scenario for a selected node or outcome and export the results data to a CSV file using the Export Scenario Test Results option. Export Scenario Test Results uses the primary analysis data set, and any defined filter and all the defined mappings in the associated Input Data Connection to run the test.

Test results can be specified using a Results Data Definition, which allows the user to define the set of input and results characteristics they want to export. The user can optionally include the results for any assigned impact scripts. Export Scenario Test Results can be selected from one of the following:

  • Assisted Design Project tool bar icon
  • Tree Node
  • Outcome Name

    •   If you define data weighting in the Analysis Data Set, it will not impact the test results.

Assisted Design Project tool bar icon

Selecting the Export Scenario Test Results icon will execute the test for the entire tree and create an output.csv file containing the records that have passed through the full tree.

Tree Node

Selecting Export Scenario Test Results from any node in the tree will create an output.csv file that only contains the number of records that have passed through to a specific node.

In the following example, 1,370 records were passed through to the 901+ node, therefore the output.csv file created using Export Scenario Test Results will contain 1371 records, the first record in the exported results being the row that contains the details of each characteristic in the output file.

Outcome Name

Selecting Export Scenario Test Results from any outcome name in the Outcomes area of the Tree editor will create an output.csv file containing those records that have had the outcome assigned to them.

  This option will only be available when the measures have been calculated for each outcome in the Outcomes area using the Show Measures button.

Where you select Export Scenario Test Results will directly affect the contents of the created output.csv file.

To export scenario test results for a full tree

  1. With the Assisted Design Project Tree editor open, click on the Export Scenario Test Results icon in the Assisted Design Project Tree editor tool bar.

    The Output window opens with a new tab labelled "Batch Test Results from <Assisted Design Project Name><Tree Scenario Name>":



    The information in the output will detail the Job Reference number for this job.

  2. On the Window menu, select Job Submission Console.
  3. In the Job Submission Console, select the Job Reference number (ID) that you require. The Job Submission Console will display the three output files that have been created.

  4. Right click on the output.csv file and select Save selected file.
  5. Save the output.csv file to the location you require.

The output.csv file can be opened in a normal CSV file editor.

To export scenario test results for a node in the tree

  1. With the Assisted Design Project Tree editor open, right click on a node and select Export Scenario Test Results.

    The Output window opens with a new tab providing a summary of the results that have been produced.

  2. Note the Job Submission Console Job Reference number.
  3. From the Window menu, select Job Submission Console.
  4. In the open Job Submission Console, select the Job Reference number (ID) that you require.
  5. Right click on the output.csv file to open it directly or save the selected file.
  6. Save the output.csv file to the location you require.

The output.csv file can be opened in a normal CSV file editor.

To export scenario test results for an outcome

  1. With the Assisted Design Project Tree editor open, right click on an Outcome name and select Export Scenario Test Results.

    The Output window opens with a new tab providing a summary of the results that have been produced.

  2. Note the Job Submission Console Job Reference number.
  3. From the Window menu, select Job Submission Console.
  4. In the open Job Submission Console, select the Job Reference number (ID) that you require.
  5. Right click on the output.csv file to open it directly or save the selected file.
  6. Save the output.csv file to the location you require.

The output.csv file can be opened in a normal CSV file editor.
