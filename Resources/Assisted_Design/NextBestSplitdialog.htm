Next Best Split dialog

Next Best Split analysis automatically identifies and ranks a set of splits for the next level of the tree based on the specified predictors and target characteristic, but will not change the structure of the strategy tree until a split is applied to the tree.

The Next Best Split dialog identifies the splits and measures their strengths relative to one another. It shows the splits suggested by the automatic tree growing procedure in the lower window.

  To include Assisted Design Project measures in the Next Best Split analysis, you must have selected the Include measure results during next best split check box on the Tree Growing Parameters sub editor. Input measures from the project will be calculated and available for display. Input measures based on the Target characteristic, e.g. #Goods, are automatically selected for display.

  If you define data weighting in the Analysis Data Set, the weighted data will not be used in the calculation of the Next Best Split statistical measures. Therefore statistical measure results will be unweighted. However, any user-defined target and input measures will be based on the weighted data set.

Click on the Column Display button to expand the list of available statistical and target-based measures. Selected measures will appear in the Analysis table. Assisted Design Project measures will only appear in the menu if the user has previously selected the Include measure results during next best split check box on the Tree Growing Parameters sub editor:

To apply a selected split to the tree, click Apply.

The selected split will create the next layer of the strategy tree for the selected branch, as an embedded split. Growing a branch in this way creates one level of a branch at a time. When a new split is added to a leaf node, either manually or via Next Best Split, and that leaf node already had an assignment to an outcome configured, the tree editor displays the Add Split repair dialog at the bottom of the editor:

This dialog allows the user to preserve the outcome assignment that was in place prior to using Next Best Split, and propagate it to all or selected intervals on the new split.
