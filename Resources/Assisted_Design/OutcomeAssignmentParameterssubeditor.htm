Outcome Assignment Parameters sub editor

The Outcome Assignment Parameters sub editor allows the user to specify all the parameters that control the behaviour of the Propose Best Outcomes analytical process. This includes defining the configuration for goal, constraints and impact scripts.

Project Characteristics are available in the Resources window to enable the user to create goal measures and constraint definition measures from within the Outcome Assignment Parameters sub editor.

Goal Definition

Specifies the goal to be used for the Propose Best Outcomes algorithm in Assisted Strategy Design.

Goal Name: Specify a label for the goal (e.g., Minimise Expected Bad Debt).

Goal Direction: Specify the goal direction, either Maximise or Minimise.

Goal Measure: Specify the measure on which to base the goal (e.g., 'Total Expected Bad Debt'). This can be any Results measure available to the Assisted Design Project (as generated from tree outcome execution or impact execution script) that is of the type Sum/Total or Count. The drop down menu is empty until Results measures are generated in the Measures sub editor, or a goal measure is created from a Project Characteristic.

To create a goal measure from a Project Characteristic, drag and drop a Project Characteristic from the Resources window into the Goal Measure field. The Create Measure dialog is displayed. The only measure types allowed are Count and Sum. Once the measure has been created, it will appear in the drop down menu. See Create measures using Project Characteristics for more information.

Constraints Definitions

Specifies constraints placed on the goal.

Name: Specify a label for the constraint.

Measure: Specify the measure on which to base the constraint, from the drop down list of measures from Measures sub editor. These include measures of the type Count and Sum, and reflect only Result and Impact characteristics.

To create constraint measures from Project Characteristics, drag and drop one or more Project Characteristics from the Resources window into the Measure field. The Create Measures dialog is displayed. Once the measure(s) have been created, they will appear in the drop down menu. See Create measures using Project Characteristics for more information.

Direction: Specify the constraint direction, either At least or At most.

Outcome Impact Scripts

Impact scripts can be assigned by dragging and dropping from Derived Data Script in the Resources window into the Impact Script field, or by right clicking and selecting Add Embedded Impact Script. By reference impact scripts can use any defined Derived Data Script component available in the Resources window, including those using User Defined Functions.

An impact script can be opened from within the Outcome Impact Scripts table by right clicking on the script and selecting Open Editor. The script will open in the scripting editor.

See Outcome Impact Scripts for details.
