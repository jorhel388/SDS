Create an embedded measure

Measures can be referenced from within the Assisted Design Project. This means they can be changed from outside the project and may be shared by other projects. Alternatively, a measure can be created from within the Measure sub editor and will be embedded into the Assisted Design Project. This means the measure is only used by this project and can only be edited from within this project.

  You can also create embedded measures using Project Characteristics at the point they are required during the Assisted Design process from within the Assisted Design Project Tree editor, the Measures sub editor, or the Outcome Assignment Parameters sub editor. See Create measures using Project Characteristics for details.

To create an embedded measure in an Assisted Design Project

  1. From the Navigator window, right click on Measures and select Open Editor to display the Measures sub editor.
  2. With the Measures sub editor open, right click in the Measures table and select Add Embedded Measure. The Insert Embedded Component dialog is displayed:

  3. Overtype Embedded Measure with a unique name (within the project) for the measure, and click on the OK button. The embedded measure editor is displayed:

    The fields in this editor depend on the measure type chosen.

  4. From the Measure type drop-down list, select the type of measure to create (choices are: Average, Count, Max, Min, Ratio, Std Deviation, and Sum).
  5. Click on the button to select the characteristic to use as the basis for the measure.
    6.   In Assisted Design, the characteristic field is optional for COUNT measures (it will always count the records in the analysis data set).
     
  6. (Optional) you can add an existing filter to the measure to limit the range of values that are used to create the measure, or create a new filter. The default is <All Cases>.
  7. To add an existing filter to the measure, expand the Filter list in the Resources window to display all the available filters. For example:

  8. Drag and drop the required filter into the <All Cases> field.
  9. To create a new filter, right click in the <All Cases> field and select Insert Embedded to display the Insert Embedded Component dialog:

  10. Rename the filter to something meaningful, and click OK to display the filter scripting editor. This editor is a standard scripting editor and is uses the same method of entering constraints as the Boolean Expression editor.
  11. Create the filter script, click on the Compile Script button to validate it, and then click on the Close button to exit the scripting editor.
  12. The embedded measure is now complete:

  13. Click on the Close button to exit the Embedded Measure editor and return to the Measures sub editor.

The embedded measure is listed at the end of the Measures table, and is ready to be used in the Assisted Design Project. Within the Measures table, the user can change an embedded input measure to a referenced input measure or a referenced input measure to an embedded input measure by using the Convert option.
