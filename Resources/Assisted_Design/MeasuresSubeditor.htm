Measures Sub editor

The Measures sub editor allows the user to create referenced and embedded measures based on any characteristic in the Analysis Data Set, or produced by the tree or assigned impact scripts. The user can also create embedded measures using Project Characteristics. These measures can be used to assess the current strategy tree as well as to direct strategy design/tree growing. The measures are calculated and displayed in columns in the Assisted Design Project Tree editor.

Typically, the user would define and configure measures to help assess the population (i.e., the whole tree and the key segments therein) in terms of Key Performance Indicators (Measures) based on known performance outcome characteristics – for example, measures based on known Delinquency Status, Total Outstanding Balance, Current Credit Limit or Credit Limit Utilisation.

These outcome characteristics would typically be related to the Target Characteristic(s) used to grow the tree segmentation and assign strategies to the resultant nodes.

Typical measures could include:

  • # Good Customers in the tree and each of its segments
  • # Bad Customers in the tree and each of its segments
  • Total / Average Outstanding Balance in the tree and each of its segments
  • Average Credit Limit Utilisation in the tree and each of its segments

Most measures inside assisted design will be input measures; i.e., measures based on characteristics in the Analysis Data Set.

To better enable Intelligent Tree Growing and to assist in the identification of Predictor Characteristics, the user can define and configure measures based on candidate predictors – for example, Min, Max, Total, Average, Std Deviation of Disposable Income.

Informed by measures, the user can select a node within the tree to work on: for example; a low risk score band exhibiting a higher than expected delinquency rate, with significant population size.

Results measures are used to assess the impact of the tree’s assignments - either existing assignments or assignments made to newly added leaf nodes - and to drive and assess the Propose Best Outcomes analytical process.

Results measures are based on results characteristics. Results measures are produced either by the component assigned to the tree’s outcomes or by the impact scripts associated with the tree’s outcomes. Results measures can be used as the Goal and / or constraints within Propose Best Outcomes.

The Measures table consists of:

Name - name of the measure as specified in the Add Embedded Measure dialog, the Create Measures dialog, or from a referenced measure.

Type - type of measure (e.g., Average, Max, Min), as specified when the measure is created.

Source - source of the measure, either Input, Tree Results, or Impact Results.

Label - by default, the label is the same as the name; the user can type in a different label. The label is used to identify the column used for this measure on the other editors.

Show - check this tick box to make this measure visible and available on the Assisted Design Project Tree editor; uncheck to hide the measure.

Format - determines how the measure will appear on the Assisted Design Project Tree editor. To change the format, click on the Measure format button to launch the Measure Presentation dialog.

To change the order of the rows in the Measures table, right click on a measure and select one of the following:

Select Move Up or Move Down to move measure up or down a row; select Move Top or Move Bottom to move the measure to the top or the bottom of the table.

To edit a measure, right click on a measure and select Open Editor. See Create an embedded measure for information on using the embedded measure editor.

To create embedded measures from Project Characteristics, drag and drop a Project Characteristic from the Resources window into the editor. The Create Measures dialog is displayed. See Create measures using Project Characteristics for more information.

To delete a measure from the table, right click on a measure and select Delete.
