Tree Growing Parameters sub editor

The Tree Growing Parameters sub editor allows the user to specify, from all the mapped characteristics in the logical data source, which ones to use as predictor characteristics and which to use as the target characteristic. Rounding can also be specified for predictor characteristics; this user defined rounding will be used to create the intervals in tree growing processes. The user must also select which Tree Growing Profile to use in building the tree, and whether to include measure results in the Next Best Split analysis.

The user can activate the Tree Growing Parameters sub editor by double clicking on Tree Growing Parameters in the Navigator window. It will open in the main editor:

By default, the characteristics metadata in the table or tree on this screen are limited to name only. You can display other columns as well by clicking on the Column Display button.

The Tree Growing Parameters sub editor consists of:

Tree Growing Profile

Select the profile that contains the settings best suited to your needs to create segmentation using Grow or Next Best Split for this Assisted Design Project.
The Advanced button next to the Tree Growing Profiles selection box displays the settings for the selected profile. These settings can be edited, allowing you some control over the results of the tree growing operation. The settings available to edit are:

  • Significance Threshold (p-value)
  • Min records into leaf nodes
  • Max levels to grow
  • Max leaf nodes to grow

Selecting the button will reset the values for these settings back to the default for the particular Tree Growing Profile the user has selected.

Logical Characteristics

The logical characteristics tree/table displays all the logical data sources that are published to the node in the system composition where the Assisted Design Project has been created, and have been mapped to physical characteristics. The characteristics can be used as Target or Predictor Characteristics. Use the filters to identify the mapped logical data source characteristics to use as predictor and target characteristics.

Show Tree View – toggle display of logical characteristics between tree or table view.

Select Characteristic – type a word or part of a word next to the Search icon and the Select Characteristic dialog will focus in on a particular characteristic or set of characteristics.

Using the * wildcard will search all the available logical data sources to display any characteristic name and logical data source name that contains the text. Matching is not case sensitive, so you can use * to match Applicant.Scores.Risk Score with Scor*risk for example.

Filter for Data Types – limit the display of characteristics to one or more types (e.g. String, Integer, Decimal, etc.). The Filter for Data Types icon will indicate when the range of characteristic types displayed have been narrowed down.

Target Characteristic – select the target characteristic from the list of tree growing characteristics by clicking on the Select Target button or by using the context pop-up menu. Click on to remove the target characteristic.

Predictor Characteristics

Select the predictor characteristics from the list of mapped characteristics. Click Copy , Copy All , Remove , or Remove All to select predictors. The pop-up menu can be used as well.

Suppress user defined rounding - suppresses the rounding settings defined in the Predictor Characteristics window during tree growing.

Use Rounding - use the rounding defined in the Rounding column for the characteristic specified during tree growing.

Rounding - for numerics, click or right click on the Rounding icon to toggle between:

  • Round to the specified number of decimal places.
  • Round to the nearest increment as specified (e.g., 100).

Measure Results

Include measure results during Next Best split – select this option to include Assisted Design Project measure results in the Next Best Split analysis.

  The performance of Next Best Split will be slower if you calculate measures, especially if many predictors are included.
  If you define data weighting in the Analysis Data Set, the weighted data will not be used in the calculation of the Next Best Split statistical measures. Therefore statistical measure results will be unweighted. However, any user-defined target and input measures will be based on the weighted data set.
