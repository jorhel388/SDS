Policy Rule toolbar

The Policy Rule editor toolbar is used to assist the user in defining a Policy Rule.

Compile Script - checks the script for syntax errors

Test - launches the Tester for the policy rule

Format Script - formats the script in the editor making it easier to read and correct syntax errors

Last edit - takes the user to the line of the script where editing last took place

Find Selection - select to locate a highlighted section of script. Can be used in conjunction with Ctrl + F.

Find Previous Occurrence - select to locate the previous occurrence of a highlighted section of script

Find Next Occurrence - select to locate the next occurrence of a highlighted section of script

Toggle Highlight Search - select to highlight all the occurrences of the highlighted section of script

Toggle Rectangular Selection - click to enable your cursor to select a rectangular selection. A useful tool for copying areas of script.

Shift Line Left - moves the whole line to the left by one tab stop

Shift Line Right - moves the whole line to the right by one tab stop
