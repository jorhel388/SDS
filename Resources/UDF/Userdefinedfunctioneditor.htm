User Defined Function editor

Depending on the option chosen, the User Defined Functions editor allows a user to:

  • create reusable scripts or functions by
    • adding the script freehand to the editor
    • using auto-complete
    • using the required resources from the Palette and Resources window
    • entering parameters from the Function Parameters tab and working storage variables from the Working Storage Variables tab
  • generate code that can be called or run code using an external Java program
 

The User Defined Function editor consists of:

User Defined Function toolbar with options designed to assist the user in defining a User Defined Function as well as a selection box where the type of User Defined Function can be selected.

Script editor - area of the editor where script can be typed in freehand or resources can be dragged and dropped into the editor from the Palette and Resources window. The editor also indicates in the right hand bar which line is currently being edited. Line wrapping can be enabled for the scripting editor from within the Tools menu.

Parenthesis matching - to provide visual assistance for parenthesis matching (brackets), matching parenthesis in the script editor will be displayed using the same colour. Those brackets that match will be highlighted in yellow, those that have no match will be highlighted in red.

 The Bracket Highlighting feature can be switched off by deselecting the Enabled check box that is found in the Brackets Highlighting tab (accessed from the Miscellaneous area of the Options dialog in the Tools menu).

In the Search field type the word or part of a word that makes up the name of the characteristic.
The Select Characteristic dialog will focus in on a particular characteristic or set of characteristics that match this word.

-The Filter for Data Types icon allows the user to narrow down the range of the characteristics displayed in the browsing area to a specific characteristic type (e.g. String, Integer, Float, Decimal and Date). The Filter for Data Types icon will indicate when the range of characteristic types displayed has been narrowed down.

- The Select Logical Data Source icon opens the Logical Data Source Select dialog from where the user can limit the number of logical data sources displayed. The Select Logical Data Sources icon will indicate when the number of Logical Data Sources displayed has been reduced.

User Defined Functions can be written using the:

  • PowerCurve® Scripting option which may involve a simple one-line statement or a complex script involving any of the functions and operators that are available.
  • Java option, which allows the user to call or run an external Java program providing advanced functionality that would not be provided by using the PowerCurve® Scripting.
 The Semi Structured Data Definition's Get/Set payload is not supported in the Java option in the User Defined Function, however it can be used in Derived Data Script.
In order to use, set the payload as a string characteristic and then the value from this string can be used in Java script
PowerCurve Scripting

Script editor - area of the editor where script can be:

  • typed in freehand (parameter names are case sensitive)
  • entered using auto-complete
  • dragged and dropped into the editor from the Palette and Resources window
  • dragged and dropped from the Characteristic Chooser area

The editor also indicates in the right hand bar which line is currently being edited and lines that contain errors. Clicking on a red error bar will take the user straight to the start of the line with the error in it. Line wrapping can be enabled for the scripting editor from within the Tools menu.

Characteristic Chooser - parameters that are defined in the Function Parameters area of the editor will be added to the characteristics chooser area. It is from this area that the user can drag and drop them into the script editor.

Function Parameters tab - area of the editor where parameters that will be used in the script are defined. The user must provide a parameter name and define its data type (string, numeric, date or Logical Data Model) and optional array size. As parameters are created in this area they will be added to the Characteristic Chooser area of the editor. Only parameters that conform to these settings will be listed in the Characteristic Chooser and are able to pass to and from the function when the script is run.

Working Storage Variables tab - area of the editor where working storage variables that will be used in the script are defined. The user must provide a variable name and select the existing Logical Data Model that will be used to create the working storage variable. As working storage variables are created they will be added to the Characteristic Chooser area of the editor.

 

The working storage variable functionality does not support the Semi Structured Data Definition parameter type.

A Semi Structured Data Definition can only be used in the working storage as a characteristic inside a Logical Data Model parameter.

When a user selects a Logical Data Model, the contents of the Logical Data Model will be used and available for selection within the Characteristic Chooser area of the editor.

Java

Tool bar - area of the editor, where the user selects the icon to Generate Code to open the Select Output Directory for Code Generation dialog, where the user can define where the code will be placed once it has been generated.

Class Path - area of the editor where a fully qualified class path name is entered. The name entered must be valid for the Generate Code icon to become active.

Function Parameters tab - area of the editor where parameters that will be used in the external call are defined. The user must provide a parameter name and define its data type (string, numeric, date or Logical Data Model) and optional array size.
