Use the generated Java code

The DataInterfaceAccess or interface allows you to interact with the characteristics defined within the User Defined Function using the following methods:

package com.experian.eda.component.externalcall.runtime.interfaces.IDataInterfaceAccessor.

Method public T getValue(IAtomicCharacteristic<T> characteristic)
Description Gets the Value from the DA Data Source
Parameters characteristic - the name of the characteristic as defined in the User Defined Function parameters.
Return Value The value held in the specified characteristic (strongly-typed data).
Method public void setValue(IAtomicCharacteristic<T> characteristic, S value)
Description Sets the Value in the DA Data Source.
Parameters

characteristic - the name of the characteristic as defined in the User Defined Function parameters value - the value you want to set the above characteristic to.
Return Value Void - this method does not return a value.
Method public int getSize(IArray arrayCharacteristic)
Description Gets the size of an array characteristic from the DA Data Source.
Parameters arrayCharacteristic – the array characteristic whose size you want to set.
Return Value An integer giving the size of the array characteristic.
Method public setSize(IDynamic dynamicCharacteristic, int size)
Description Sets the size of an array characteristic in the DA Data Source.
Parameters dynamicCharacteristic – the dynamic array characteristic as defined within the User Defined Function parameters whose size you want to change – the new size of the dynamic array characteristic .
Return Value Void - this method does not return a value.
Method void clear(IDynamic dynamicCharacteristic)
Description Clears all array elements of the specified dynamic array characteristic.
Parameters dynamicCharacteristic – the dynamic array characteristic you want to clear.
Return Value Void - this method does not return a value.

User Defined Function Parameters

A metadata class FuncP.java is generated and allows access to the User Defined Function parameters using its static global variable FUNCP.

  e.g. FUNCP.Balance :- This will return an ICharacteristic object representing the Balance (Numeric) parameter in the User Defined Function.

 

e.g. FUNCP.Address.Street :- This will return an ICharacteristic object representing the Street (String) characteristic of Address (Logical Data Model) parameter in the User Defined Function.

Pass the ICharacteristic object to the DataInterfaceAccessor functions and the functions will return the result accordingly.

  e.g. Number balance = dia.getValue(FUNCP.Balance); // this will get the value of holding by Balance characteristic.

Array Elements

Use element() method to access an array characteristic element.

  e.g. dia.getValue(FUNCP.Account.element(1).Balance);
