Characteristic Chooser

When a user adds input parameters to the Function Parameters tab or variables to the Working Storage Variables tab of the User Defined Function editor the system adds these to the Characteristics Chooser area. It is from this area that the user can drag and drop these parameters and variables into the script editor and use these in the script.

Two types of parameter can be added to the Function Parameter tab and used within the User Defined Function.

  • Primitive Characteristics
  • Logical Data Models

One type of variable can be added to the Working Storage Variables tab and used within the User Defined Function.

  • Logical Data Models

Primitive Characteristics

All primitive characteristics that are created in the Function Parameters area will be listed within the User Defined Function Editor's own Function Parameters Logical Data Source in the Characteristic Chooser editor. These parameters can be applied to the script area as normal either by dragging and dropping or by using auto-complete. Logical Data Models

In the Function Parameters tab, when a user selects a Logical Data Model as the parameter type, the parameter name for this parameter will be listed in the Characteristic Chooser area as the Logical Data Source with the contents of the Logical Data Model that was selected as the characteristics.


In the above example, within the Function Parameters tab, Cust has been defined as the parameter name and Customer has been selected as the Logical Data Model selected.
When the Account Type characteristic is dragged into the script editor the Select Characteristic Array Elements dialog will be displayed enabling the user to specify the indices for the dynamic array. Once defined, the characteristic will be added to the script as shown above.

In the Working Storage Variables tab, when a user select a Logical Data Model, the variable name will be listed in the Characteristic Chooser area as the Logical Data Source with the contents of the Logical Data Model that was selected as the characteristics.

In the above example, within the Working Storage Variables tab, Results has been defined as the variable name and AccountResults has been selected as the Logical Data Model. When Total is dragged into the script editor, the fully defined Working Storage Variable name will be displayed in the Script editor.
