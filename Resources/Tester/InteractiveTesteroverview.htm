Interactive Tester

The Interactive Tester enables users to execute test cases manually on a component or a number of components. Users can define and test a component and review the results; if a user has activated the Tester from within the component editor, it allows users to make the appropriate changes to the component and re-test it without having to close the component editor, as the Interactive Tester is a separate editor.

The Interactive Tester is configured to use the Date Format from the machine on which the Design Studio is installed (the default setting). This value can be changed to another date format using the Global Setting's Date Format option accessed from within the Properties window. When this value is changed, all open instances of Interactive Tester will be updated to match this new Date Format.

 

The Date Format value chosen only affects how the date is displayed in Interactive Tester, for example from DDMMYYYY to YYYYMMDD
  When data is exported from Interactive Tester, the date format will remain as YYYYMMDD regardless of the Date Format value chosen.

There are two views in the Interactive Tester editor:

  • Table View - displays flat data models containing static and dynamic arrays where the characteristics are listed with their full path names.
  • Tree View - displays data models containing static and dynamic arrays where the characteristics are displayed under their respective parent element and modify the model structure by adding dynamic array elements.
    •   The user can move between the views without losing data or test cases, enabling users to choose how the data is displayed in the editor.

Testing on components such as script components that can change the size of dynamic arrays and evaluating the results can be done in both the Table View tab and the Tree View tab. Using the Interactive Tester Tree View, users are able to define the number of elements that a dynamic Logical Data Model or dynamic array characteristic will contain for each test case and enter input data for these. The size of the dynamic arrays can vary between records according to the user's test case requirements.

Once executed, the results are displayed in the Results area of the Interactive Tester editor. The tab the user has selected will determine how the results are displayed. Data containing dynamic arrays can be imported into and exported from the Interactive Tester.

Test cases are manually entered or imported into the Interactive Tester editor, where they can be reviewed and edited. They are then executed against the selected component(s) and can be compared with previous values or against expected results.

The Interactive Tester is designed to allow users to define and run test cases and review results quickly and easily. The results are displayed on the screen.
