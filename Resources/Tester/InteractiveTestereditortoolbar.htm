Interactive Tester editor toolbar

The Interactive Tester editor toolbar gives the user control over the interactive testing function.

The first three buttons control the Interactive Tester's main functionality:

Execute Test - Starts running a test.

Stop Test - A test is made up of one or more test cases. Selecting Stop Test will stop the processing of the test after the currently executed test case is complete.

Refresh - Updates the Tester with any changes made to the component being tested. For example, if the list of input or result characteristics has been changed, the corresponding tables will be updated. All result characteristics' values dynamic elements and data entered for them will be cleared and all input and expected characteristics' values will be kept where relevant.

The next three buttons control test tracing levels for each test input case processed:

Trace Pathways - Produces a trace pathway for each test case that is passed through the component within the scope of the test.

Trace Characteristics Reads - Produces a trace of the value of the selected characteristics each time they are read during the test.

Trace Characteristics Writes - Produces a trace value of the selected characteristics each time they are written to during the test.

The next button filters for selected characteristics:

Show selected characteristics - Shows only those characteristics indicated by the checkboxes in the two tables. If there are any selected characteristics, this selection is taken into consideration during the export process, during which only selected characteristics from the input/results will be exported.

The next button allows quick data entry:

Quick data entry - Allows users to quickly remove or add string, date and numeric characteristic information to some or all of the dataset. For more information on entering data refer to the Entering data using the Quick Data Entry dialog topic.

Find and Replace - Allows users to search for Input and Expected values in the tester and replace them if necessary.

The next two buttons control the import and export of test cases and test results:

Import - Imports input as well as expected and/or results data.

Export - Exports input as well as expected and/or results data.

The next button allows users to configure the working directory:

Configure Working Directory - Specify the location for the trace files.

 

When Tracing is enabled, the working directory must be selected.

Once this directory has been selected, it will be saved. When Interactive Tester is opened again the directory will already be defined.

The following buttons facilitate the entry and editing of test cases

Tree View only - The test case number that is currently viewed is displayed in the test case field, as shown above. The image shows that case number 2 out of 10 cases are currently being viewed. A test case number can be manually entered in the Test case field. After entering the number, the user must press Enter after changing the number to confirm the move. Clicking outside of the box will restore the original value.

The next four buttons are used to navigate between test cases in both Tree and Table Views:

Go to first test case - Opens the first test case.

Go to previous test case - Opens the previous test case.

Go to next test case - Opens the next test case.

Go to last test case - Opens the last test case.

The next two buttons update the test cases:

Add a new test case - Creates a new test case and inserts it after the current test case.

Delete the current test case - Deletes the current test case.

Duplicate a test case - Creates a copy of the current test case. Where multiple test cases are selected, only the last test case will be duplicated.

Find previous/next invalid test data - Takes users to the previous or next invalid test data.
