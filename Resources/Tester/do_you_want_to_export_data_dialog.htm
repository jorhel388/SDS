Do you want to export the data? dialog

When closing the Interactive Tester editor, the user will be prompted with the Do you want to export the data? dialog. This dialog allows the user to select an option of their choice and save it. The saved option will then be performed every time the user close the Interactive Tester editor.

The Do you want to export the data? dialog consists of:

  • Remember my choice - if the checkbox:
    • is selected, the chosen option will be saved and will be performed every time the user closes the Interactive Tester editor.
    • is not selected, the Do you want to export the data?’ dialog will be displayed when closing the Interactive Tester editor.
  • Export - launches the Interactive Tester Export Wizard and closes the Interactive Tester editor.
  • Close Tester - closes the Do you want to export the data? dialog and Interactive Tester editor without exporting the data.
  • Cancel - cancels the Do you want to export the data? dialog and returns the user to the Interactive Tester editor.

Once an option is set, it can be changed via the Interactive Tester close option section.

 

The option that is set in the Do you want to export the data? dialog or in the Interactive Tester close option will be applied at the Design Studio level and not at the user level.
Interactive Tester close option

The Interactive Tester close option section in the Options dialog allows the user to set and orchange the preferred option for the Do you want to export the data? dialog. This section can be accessed from the Main menu - Tools > Options > Appearance > Explorer >.

The Interactive Tester close option section consists of:

  • Always open export dialog
  • Always close without exporting the data
  • Always ask me

When opening the Design Studio for the first time, the default setting is the Always ask me close option.
