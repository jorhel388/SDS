Using the Interactive Tester with Null values

Upon opening the Interactive Tester, by default, all numeric and date characteristics will be set to Null and all string characteristics will be empty. It is possible to run a test with these values in place.

To assign Null values to a characteristic

There are two ways to assign Null values to a characteristic.

  1. With the Interactive Tester editor open, right click on a characteristic in the Input table.
  2. Select Set Value to Null. The value is set as Null. The word Null indicates that there is now no data present within this field (i.e., in case of a string, it means that the string is Null and not simply an empty string).
  Or
  1. Select Quick Data Entry from the context menu (this can also be accessed via the Quick Data Entry button in the toolbar).

  2. The Quick Data Entry dialog appears.
    3.  
  3. Click Set to Null for the appropriate characteristic type (number, string or date).
  4. Click Close.
  5. The characteristics, number, string or date, will update to Null.

When the test is run, this characteristic in this test case will be processed with a Null value.

 Export and Import recognise the existence of the Null field. The .csv file identifies the Null field value as \0. In the .xml file, Null values are identified by the ISNULL attribute.
