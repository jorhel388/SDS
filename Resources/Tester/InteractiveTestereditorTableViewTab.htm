Interactive Tester editor

There are two views available in the Interactive Tester editor, Table and Tree. These are discussed in detail below.

Table View tab

The Table View tab in the Interactive Tester editor enables users to set up test cases to test a component and evaluate the results.

By default, the Table View tab will be shown. To go to the Tree View, click the Tree View tab. For information on using the Tree View, see Interactive Tester editor - Tree View tab.

The Interactive Tester editor is launched by right clicking on the required component in the Explorer and selecting Test, or from within the component editor by clicking on the Test button .

The Table View tab in the Interactive Tester editor opens with the list of input characteristics, which are passed from the component editor to the tester, in the top window, and the list of result characteristics in the bottom window. The first test case is created, and the input characteristics' default values for integers, decimal, float and date characteristics are Null. The default for string characteristics is an empty field.

The Table View tab in the Interactive Tester editor consists of:

The Interactive Tester editor tool bar with options designed to give users control over the interactive testing function.

Filter: Users can limit the characteristics displayed in the tables by typing letters or words into the content-sensitive filter. For example, typing the word "risk" into the filter will limit the display to those characteristics that contain "risk" as part of their name.

Input Table: The Input Table is populated with input characteristics and test cases containing values for the appropriate characteristics.

The Input Table includes the following columns:

  • #: Row number defines the position of the characteristic on the table.
  • Select: The user can display only those characteristics selected in the checkbox (using the Show selected characteristics button from the tool bar).
  • Characteristic: Consists of the characteristic type and its long name. The characteristic type is displayed as an icon; the type is either string (text), integer , date , decimal or floating point . The long name of the characteristic, displayed as a composite name with dots as separators.
  • 1, 2, 3, 4,...: Test case(s) values. The first test case is created automatically; the user can add up to 999 additional test cases. The values will be either Null or empty. The user can edit the values, and add, delete, duplicate, and move the test cases. The user can also assign Null values to a test field.
    •   The required syntax for entering values into date fields is context sensitive. Users can obtain the correct syntax for a particular date field by hovering the cursor over the field and reading the tooltip.

Results Table: The Results Table is populated with output characteristics and test cases containing values obtained as a result of testing.

The Results Table contains the same columns as the Input Table. The Results values are read only.

Results Table options include:

  • Highlight: The Highlight buttons enable the user to choose various options to highlight the differences in results between successive test runs.
  • Expected: Click on the Expected button to expand the Results Table. This option allows users to enter expected values below the actual results. This can be done before running the initial test, or can be done before re-running the test.
Tree View tab

The Tree View tab in the Interactive Tester editor enables users to test a component, by either manually entering input data, or by importing data, and evaluate the results.

The Interactive Tester editor is launched by right clicking on the required component in the Explorer and selecting Test, or from within the component editor by clicking on the Test button . By default, the Table View tab will be shown. Click the Tree View link to see the Tree View. For information on using the Table View, see the Interactive Tester editor - Table View tab topic.

The Tree View tab in the Interactive Tester editor opens with the list of input characteristics in the left window, and the list of result characteristics in the right window.

Dynamic test data can be created by adding as many elements as required to existing dynamic arrays.

The Tree View tab in the Interactive Tester editor consists of:

The Interactive Tester editor toolbar with options designed to give users control over the interactive testing function.

  When the component being tested uses dynamic arrays in either the Input or Results area, the Interactive Tester editor - Table View tab will be displayed by default. Click the Tree View tab to switch to the Tree View.

Both the Input and Results areas consists of the following:

Filter - Users can limit the number of characteristics displayed in the tree or table by typing letters or words into the content-sensitive filter. For example, typing the word "balance" into the filter will limit the display to those characteristics that contain "balance" as part of their name.

Column display button - Allows the user to display the Name, Type, Length, Scale, and/or Value; and choose whether the following should be available for each characteristic: Horizontal Scroll, Pack All Columns and/or Pack Selected Column.

Input area

The Input area is populated with input characteristics and test cases containing values for the appropriate characteristics. Imported test cases are populated with characteristic values and the default size of empty dynamic arrays is 0. Null values can be manually set to each cell.

The test cases are represented in a Tree View with leaf nodes where data can be entered.

Results area

The Results area is populated with characteristics and test cases containing values obtained as a result of executing the test.

The Results values are read only, however they can be exported as a .csv or .xml file.
