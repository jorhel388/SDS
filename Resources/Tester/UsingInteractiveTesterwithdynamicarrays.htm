Using the Interactive Tester with dynamic arrays

When the Interactive Tester is run on scripting components which contain dynamic arrays, these are not shown in the Table View, as they have a size of 0. Users need to go to the Tree View to add elements.

In the Tree View, dynamic array elements are initially shown with [n] at the end of the Name. See below, where PUBLICDATA is a dynamic array.

In the Interactive Tester, dynamic arrays can be sized in the Tree View by using the Add Element(s) option, by copying and pasting an existing dynamic array or via the import of a .csv or .xml file. The .csv or .xml file is scanned on import to find the maximum array size specified for any dynamic arrays, and that is used as the array size when the .csv or .xml has been loaded.

Changing the dynamic array size during execution

In the Interactive Tester, initial array sizes are detected and configured based on the input data configuration. The user can change the size of a dynamic array during execution, through the use of the ADDELEMENT and CLEAR scripting functions.

  • CLEAR sets the size of the dynamic array to 0, and if the dynamic array is a group array, then any dynamic arrays contained in it are also set to 0 array size.
  • ADDELEMENT on dynamic leaf array initialises that new array value to Null.
  • ADDELEMENT on dynamic group array initialises the contents of that new element to Null. So contained array values will be Null, contained dynamic arrays (group and leaf) will be size 0; contained static arrays will be their fixed size, but all elements within will be initialised to Null.

The size of an array may be reduced or increased, resulting in a mismatch between the fixed format of the output files and the actual results. Interactive tester handles inconsistencies as follows:

  • Where an array size has been reduced during execution the results output will need to be padded for the missing data. In this case, the Results table will be populated with Null values for each array element that is missing in the results:

    If the results are exported, the data will be padded with Nulls.

    A warning is displayed in the Results window:

    'Warning: The dynamic array characteristic 'ldsname.arraycharacteristicname' was reduced in size for one or more records during execution, the results file will contain Nulls for each record where this occurred'.

  • Where an array size has been increased beyond the bounds of the input file, the Results table will be populated only up to the upper bound of the array. So, for example, if there are seven unique results but the size of the array is fixed at five, then two of the results will not be displayed.

    A warning is displayed in the Results window:

    'Warning: The dynamic array characteristic 'ldsname.arraycharacteristicname' was increased in size, to a maximum of n occurrences, for one or more records (the results output will be truncated to the upper bounds configured by the input data)'.

     It is the responsibility of the user to understand their data and ensure an appropriate upper bound is configured on the input data file. The warnings will allow the user to understand when that upper bound is exceeded and how much it needs to be increased in order to be able to capture all their results into the output file or UI.
     
  • Information about the dynamic processes can also be found in the trace log files.
    •   Where Semi Structured Data Definitions are used, and the size of dynamic arrays are changed during test execution, no warning is written to the output file. Users should use the Tree View to assess the impact on the new array sizes.
Add Elements

Tests of components using dynamic array characteristics can be run interactively by entering test cases manually into the Input section of the Tree View tab in the Interactive Tester. Dynamic array characteristics (illustrated in the input area by the [n]) will need to have their structure built, by adding elements, before values can be assigned to the leaf nodes. The user is only able to add elements in the Tree View of the Interactive Tester. Elements can be removed by selecting Remove Element.

To add a new element to the input data

  1. Within any component editor, click on the Test button or right click the name of the component in the Explorer window and select Test. The Interactive Tester editor is displayed.
  2. Select the Tree View tab. The Tree View tab Interactive Tester Editor is displayed.
  3. Right click on the dynamic array and select Add Element(s)...


    4.  
  4. The Add Array Elements dialog appears.



  5. Enter the number of elements to add into the Add field. Select whether they should be added before the first element or after the last element by clicking the appropriate radio button.
  6. Click on the OK button.
  7. The system will add a new element(s) to the structure in the chosen location. If nested array elements exist in the structure, the system will only create the outer array element.



  8. Repeat Add Elements on the initial dynamic array to create the structure you require.



  9. Once the outer array elements have been created, right click on the next dynamic array in the input area and select Add Elements as required. The following is an example where Add Elements has been used to create four customer records with one or two accounts in each.

Values will now need to be entered into each leaf node to create the test record.

  Once an initial dynamic array has been created, the copy and paste options can be used to duplicate the element(s) and values, including those of any child characteristics, within the same dynamic array or another dynamic array of the same base type. For further information refer to the Copy and Paste Elements section.
Copy and Paste Elements

Tests of components using dynamic array characteristics can be run interactively by entering test cases manually into the Input section of the Tree View tab in the Interactive Tester. Dynamic array characteristics (illustrated in the input area by the [n]) will need to have their structure built, by adding elements, before values can be assigned to the leaf nodes. The user is only able to add elements in the Tree View of the Interactive Tester. Elements can be removed by selecting Remove Element.

Once an initial dynamic array has been created, the copy and paste options can be used to duplicate the element(s) and value(s), including those of any child characteristics or child Logical Data Models, within the same dynamic array or another dynamic array of the same type.

The Copy option will only be enabled if the selected characteristic is a dynamic array container (illustrated by the [n]) or an element of a dynamic array (illustrated by a number e.g. [1]). All elements or a single element of a dynamic array can therefore be copied.

The Paste option(s) will only be enabled if the chosen characteristic is a dynamic array container or an element of a dynamic array and also a valid target for the copied item.

  • Logical Data Model arrays: The source and target must be dynamic array characteristics that are instances of the same Logical Data Model.

    •   For example, if ‘Current Address’ and ‘Previous Address’ are both dynamic arrays and both instances of the same ‘Address’ Logical Data Model then ‘Current Address’ can be copied and pasted to ‘Previous Address’.

  • Primitive characteristic arrays: The source and target must be dynamic array characteristics that are the same data type. For example, both String, both Integer, both Decimal, both Float or both Date

  The Remove Elements option can be used to delete unwanted elements created by the paste option.

To copy and paste all elements of an input dynamic array

With the Tree View tab of the Interactive Tester Editor open and with elements added to the input data:

  1. Right click on the dynamic array container you wish to copy (illustrated by the [n]).

  1. Right click on the dynamic array characteristic you wish to paste to.
    When the paste is performed on a dynamic array container, new elements will be added to the end of the dynamic array.




    When the paste is performed on an existing element within a dynamic array, Paste Before and Paste After options are available to select where the copied elements should be inserted.



    All paste options will add the appropriate number of new elements to the target array and populate these elements with the copied values.

  The Copy functionality will paste everything that you have selected to copy.
For example, if you copy an array that contains three elements, and during the copy you not only select the array, but also the first element, the whole array and the first element will be pasted.

To copy and paste elements of an input dynamic array

With the Tree View tab of the Interactive Tester Editor open and with elements added to the input data:

  1. Right click on the element of the dynamic array characteristic you wish to copy.

  1. Right click on the dynamic array characteristic you wish to paste to.
    When the paste is performed on a dynamic array container, only one Paste option is available and new elements will be added to the end of the dynamic array.



    When the paste is performed on an existing element within a dynamic array, Paste Before and Paste After options are available to select where the copied elements should be inserted.




    All paste options will add the appropriate number of new elements to the target array and populate it with the copied values.

  Multiple elements from one or more dynamic arrays can be copied at the same time by selecting them with Ctrl + left click or Shift + left click before using right click and the Copy option. The Copy option will only be enabled if all the selected characteristics are part of a dynamic array and all of the same type. When pasting the copied characteristics, they will be concatenated in the same order they appear in the Tree View.
Remove Element

Tests on components can be run interactively by entering test cases manually into the Input section of the Interactive Tester. Dynamic array characteristics (illustrated in the input area by the [n]) will need to have their structure built, by adding elements, before values can be assigned to the leaf nodes. The user is only able to add elements in the Tree View of the Interactive Tester. Elements can also be removed when using the Tree view tab.

To remove an element from the input data

With the Interactive Tester Editor open and with elements added to the input data:

  1. Right click on the element you wish to remove and select Remove Element(s).


     You can select to Remove any dynamic part of the structure and the appropriate branch will be removed.
     

    If you click on the parent element and select Remove Element(s), all child elements will be removed as well.

    Multiple elements from one or more dynamic arrays can be removed at the same time by selecting them with Ctrl + left click or Shift + left click before using right click and the Remove Element(s) option. The Remove Element(s) option will only be enabled if all the selected characteristics are part of a dynamic array.

The element will be removed.

  1. Repeat as necessary.
