Derived Data Script Tree editor

The Derived Data Script Tree editor enables the user to create a tree using tree splits to define segmentation levels (leaf nodes) to which Derived Data Script can be applied.

The Derived Data Script Tree editor consists of:

Toolbar

The Derived Data Script Tree editor toolbar is used to alter the view of the tree seen in the editor and to assist the user in defining a tree.

Test - launches the Tester for the tree.

Copy component image to clipboard - select to copy the complete tree, including the column headers contained in the editor, as an image to the clipboard from where you can paste this image into any appropriate application.

  Selections made using the Column Display icon will not change (reduce) the number of columns included in the image created using the Copy component image to clipboard functionality.

Assign outcome - adds the outcome colour that the user has selected in the Outcome table to the chosen leaf node.

Clear outcome - removes the outcome colour from the selected leaf node and sets the outcome to <<Unassigned>> and <<Undefined>>.

Add bookmark - allows the user to bookmark specific split headers in the tree. When the contents of a tree are displayed in the Navigator window the bookmarks are displayed separately. Clicking on a bookmark in the Navigator window will open the tree in the tree editor at that point in the tree, giving the user quick access to a specific split header in the tree.

Add annotation - select to add annotation to any node of the tree. Once some annotation has been added, the user can choose to display it or hide all, edit, remove or show all annotations by using options selected from the right click menu accessed from any node.

Tree Table View - select to display only the leaf nodes of the tree. This view has been designed to make it easier for the user to assign outcomes.

Tree Editor - is the area of the derived data script tree editor where the tree splits, (the graphical representation of the segmentation rules) are applied together to form the tree. Tree splits contain the information used to group those records which are to be treated in the same way. Leaf nodes are the end points of these splits where specific derived data script are assigned to the outcome. The leaf node name is a user defined description that identifies the action that will be applied to any record that falls into this leaf node.

Outcomes area - is the area of the derived data script tree editor where the names of outcomes are created, their colour defined and the specific derived data script assigned. Outcomes are linked to the derived data that is assigned to a record that falls into a specific leaf node. Outcomes are assigned to leaf nodes in the tree editor. Every leaf node must have an outcome assigned to it in order for the tree to be valid. An outcome can be assigned to more than one leaf node.
