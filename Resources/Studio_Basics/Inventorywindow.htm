Inventory window

The Inventory of saved components is available to the user at all times. An Inventory of all components within the selected folder is given in the Inventory window.

When the Inventory window is opened for the first time in a current session, it is housed in the Output area of the User Interface. By default, the Output area is displayed at the bottom right hand side of the interface. If the Inventory is not displayed, it can be opened at any time. Components that have been moved to the Recycle Bin can also be viewed in the Inventory window when the Recycle Bin is selected from the Explorer window. The following is an example of the Inventory window for the Recycle Bin.

The user can customise this window; you can change the row order, change the column order and remove or add columns from view.

The user can perform some actions by right clicking on a component row in the Inventory window. The actions available depend upon the component type. Available actions are the same as the actions available in the Explorer window; see the Explorer window help page for further information.

The following options are available in the Inventory window:

Show filter bar/Hide filter bar: Use this button to display or hide the Filter bar at the bottom of the Inventory window. The user can use the filter field to filter for specific component names.

Show components in sub folders: Use this button to show or hide the content of sub folders.

Change Visible Columns: Use this button to choose which column you would like to view. You can also right click in the column header to display the Change visible columns dialog.

The following columns are available:

Component: This column displays the Component name.

Type: This column displays the Component Type (Decision Process Flow, Call Interface Manager, etc.)

Lock state: This column displays the Lock/Unlock status of the component. indicates that the component is locked by the user who is currently logged in. indicates that the component is locked by another user. If the field is empty, the component is not locked.

Area state: This column displays the domain that the component sits in. indicates that the component sits in a user domain. indicates that the component sits in a shared domain.

Component state: This column displays the component state. indicates a new component. indicates a modified component. If the field is empty, the component is unmodified.

Conflict state: This column displays the conflict state of the component. It indicates that there is a conflict. If the field is empty, there is no conflict.

Broken state: This column displays the broken state of a component. indicates that there are no publishing rules defined between the component and a dependant component. If the field is empty, the component is not broken.

Favourite state: This column displays any components that the user has marked as a favourite. A user can click in here to mark a component as a favourite or to remove the favourite state.

Protected state: This column displays the protected state of a component. indicates that the component is protected and cannot be opened or printed by a normal user. If the field is empty, the component is unprotected.

Locked by: This column displays the user name of the user currently locking the component.

Revision shared area: This column displays the version number of the component on the shared domain.

Revision user area: This column displays the version number of the component on the user domain.

Update date: This column displays the last date that the component was updated.

Author: This column displays the author/creator of the component.

Creation date: This column displays the date the Component was created.

Name: This column displays the Name that has been given to the component.

Path: This column allows you to display the full path of a component.

Update author: This column displays the author responsible for the latest update of the component.

The text used in the Inventory window varies, see the following descriptions:

Normal text - Item is located in the Shared Area only

Blue text - Item is located in the User Area and also in the Shared Area

Green text - Item is located in the User Area only

Red text - Item is located in the Recycle Bin

The user can customise the text colouring if required. See the Customise the text colouring help topic for further information on this.
