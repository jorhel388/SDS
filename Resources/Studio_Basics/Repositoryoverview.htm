Repository overview

A Repository is used to hold a secure and persisted copy of the client’s system(s) which can be accessed and updated by the users of the Studio applications. These users may be collaborating on changes to shared systems or may be working alongside each other in separate areas of a system (or on separate systems); the Repository provides an archive and audit trail of changes made by these users during the lifetime of the systems.

  Repositories are displayed in the Server Connections Manager window and in the Explorer window.

The Repository is also the location from which collections of users' changes will be coordinated and collated into deployment packages (see Label Management).

Repositories are displayed with the following icons:

Content repository

Reporting repository

Solution repository

The user can create as many repositories as is required and can connect to several repositories thanks to the single sign on feature. A user may have access to multiple repositories, but must be connected to a repository to work on the components within it.

A Repository is the receptacle where the Domains and the Solutions are stored.

Connect to a repository

A user with adequate permissions can log in to a repository as required. The user can work in a repository only when connected to it.

To connect to a repository

  1. In the Explorer window, right click on the appropriate repository.
  2. Select Connect.
  You can also double click on the Repository to connect.

The Repository name turns blue to show that you are connected to it. Click on the icon to expand the list of domains within the repository.

Open a repository

A user with adequate permissions can connect to a repository as required. The user can work in a repository only when connected to it. Once connected to a repository, the user must open it to view the domains, solutions, folders and components stored within it.

To open a repository

  1. You must first connect to a repository.
  2. In the Explorer window, highlight the required repository and click on the icon.

The domains within the repository will now be displayed in the Explorer window. You can now load a domain.

  Clicking on the to the left of the repository icon in the Explorer window will expand a repository.
Disconnect from a repository

A user with adequate permissions can connect to a repository as required. The user can work in a repository only when connected to it.

The user can disconnect from repositories as required.

To disconnect from a repository

  1. In the Explorer window, right click on the Repository you wish to disconnect from.
  2. Select Disconnect.

The repository name turns grey which means that you are disconnected from the repository.

Define Repository Lock behaviour

When a user first tries to save a component that exists in the Repository, the studio will display the Do you want to perform a lock? dialog. It is from this dialog that the repository lock behaviour on selecting the Save icon is first defined. This behaviour can be changed using the Options dialog.

To define the repository lock behaviour

  1. In the Main system view, click on the Tools option in the Main menu bar.
  2. A drop down list will appear.
  3. Select Options.
  4. The Options dialog will be displayed.
  5. Click on the Appearance tab followed by the Explorer tab.
  6. Select one of the following three options
    • Never lock my component on save
    • Always lock my component on save
    • Always ask me - the default setting
  7. Click on the OK button.
    The Options dialog will close.

The repository lock behaviour will be updated immediately.

Rename a template

A template is a snapshot of a part of the repository, and it can be created either from a single component(s), from a solution(s) or from a folder structure(s) with all the associated publishing rules and allowed component types.

For more information, refer to the Content Management topic.

The name of a template can be changed.

To rename a template

  1. In the Explorer window, right click on the template you want to rename from the Content Repository and select Rename...
  2. In the Rename dialog, enter the new unique template name.
  3. Click on the OK button.

The renamed template is displayed in the Explorer window.
