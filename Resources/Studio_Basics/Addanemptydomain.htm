Add an empty domain

This topic provides information on how to add an empty domain into a repository. A repository may contain one or more domains, each of which can contain one or more solutions. Domains are stored and displayed within a repository in the Explorer window.

 

Only a user who has an Architect functional role assigned to their security profile account can manage domains (add, remove, rename or change the unit value assigned to it).

To add an empty domain

  1. From the Explorer window, right click on the required repository and select Connect
  2. Right click on the same repository and select New...
  3. In the New dialog, select the Empty domain option and click OK.
  4. In the Add domain dialog, enter the domain name in the Name field.
  5. Select the required unit using the Unit drop down list.
    6.  

    If there are no units saved in the Security repository, the drop down list will be empty.
     

    Depending on the user profile, specific units will be available to the user from the Unit drop down list. A user who has an Architect functional role assigned to their security profile account and is:

    • assigned to a unit can select either the unit account assigned to the user or no unit (empty value)
    • not assigned to a unit can select any unit account that is stored in the Units folder of the Security Explorer window.
     

    A user with the Security Administrator Profile that has been assigned to a unit can view the content of any domains that have not been assigned to a unit (have an empty value) in the Explorer column from the Security Profile editor.

  6. Click OK.

The new domain will be displayed in the selected repository. You may now add a solution (empty or pre-configured) to your domain.
