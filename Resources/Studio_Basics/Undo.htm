Undo/Redo

The user can undo modifications made in the editor by clicking on the icon in the Main tool bar.

The redo option is activated after the first undo action is performed.

The user can redo undone modifications in the editor by clicking on the icon in the Main tool bar.

Undo

Undo is only available for some specific actions:

  • Actions that change the state of a component
  • Navigating within the tabs of the main editor
  • Navigating between views of embedded components

Undo is not available for actions that change how a component is displayed, for example:

  • Zoom in the matrix
  • Changing how the information in the cells are displayed in the matrix


The user can undo up to the last 100 actions per component in a current session. Actions performed on embedded components count against this limit:

 

Open Scorecard A that contains an embedded class set.

Opening the class set will count as one change.

Adding a row to the class set will count as a second change.

Closing the class set will count as a third change to Scorecard A.

Opening a component referenced in Scorecard A, through the scorecard editor, and making changes will not count against the limit for Scorecard A

Opening Scorecard B and making changes will not count against the limit of 100 changes for Scorecard A.

The undo option may be cleared if a referenced component is changed (i.e. by reference class set has been changed or made in a matrix editor) because the stored changes may invalidate the state of the undo actions. The Undo icon will be inactive if the undo history is empty.

If the undo action is not available in an editor the icon will be inactive.

Redo

The user can redo undone modifications in the editor by clicking on the icon in the Main tool bar.

Redo is only available for actions that have been undone. The user can redo the last 100 undo actions per component, including actions performed on its embedded components:

 

Open a component and make change A and then change B, then undo change B.

Both the undo and the redo buttons are activated.

You can choose to redo change B that you have just undone, or to undo change A.

If you make another change to the component or save it, the redo button is disabled and all changes that have been undone are removed.

The redo option may be cleared if a referenced component is changed (i.e. by reference class set has been changed or made in a matrix editor); the stored changes may invalidate the state of the redo actions. Once the component is saved, or another change is made, the redo history is cleared. The Redo icon will be inactive if the redo history is empty.

If the redo action is not available in an editor the icon will be inactive.
