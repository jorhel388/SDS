Folder overview

Folders are used to provide an organisational structure for the components contained within a solution. Folders can contain many different types of components. It makes things easier to find if components of a similar type are grouped together, for example; segmentation devices, decision process flows, etc. Folders are stored in the shared area and displayed in the Explorer window.

A folder is displayed with the icon and can be viewed, added, deleted, renamed and published in the Explorer window. A folder can not be deleted if it contains components which are located in the shared repository. All actions within folders can be performed by a user with Architect access rights.

The user can define which components will be allowed in the folders. Please see the manage allowed components types help page for more information on this topic. Specific access rights to folders can be assigned to individual users or to user groups.

The publishing mechanism within folders allows for the sharing of components within the solution boundary, for example; definitions of data models and layouts can be located in a folder and published for use within other parts of the solution, but not within other solutions; please see the Publishing overview for more information.

The user can import a previously exported component, folder or solution along with any dependent components and folder structures.

The user can export a component, folder or solution along with any dependant components and folder structures.

Add a folder

Folders can be added to a solution or to a folder.

To add a folder to a solution or a folder

  1. In the Explorer window, right click on the solution or the folder to which you want to add the new folder.
  2. Select Add folder.
  3. In the Add folder dialog, type the name of the new folder in to the Name field.
  4. You must select the components to be allowed within this folder.
  5. To filter the component types according to categories, select the required categories from the drop-down list. By default, the categories is displayed as "All Categories".
  6. Use the buttons in the middle of the Add folder dialog to allow or prevent the use of component types in the folder:
    • > to add selected
    • >> to add all
    • < to remove selected
    • << to remove all
    • Copy from parent: copies all component types from the parent of the selected folder.
    • To filter the list of components displayed, choose a category from the drop-down list
  7. Once you have selected the required components, click on the OK button.

The system will check to ensure that this name is unique within the solution. The Add folder dialog will close. You will now be able to add components to this folder. Use Manage Allowed Component types to amend any of the selections you have made.

To configure licence constraints in the folder, see Define additional configuration licence constraints for more information.

Create content folders

The user must create content folders for the various types of templates that will be created. It may be helpful, for example, to store scorecards and class sets in separate folders. Creating a new content folder is like creating a new solution folder, except that the allowed types are all templates rather than components.

  If a user wants to have the ability to create or apply solution templates they will need to have "Solution" configured as one of the Component types in their Content repository. It is the only component type listed under the Solutions category in the Functional Roles editor.

To create a content folder

  1. From the Content Repository, right click on a content solution and select Add folder. The Add folder dialog is displayed.
  2. Click on the button to add the component template types from the left pane to the list of Allowed component types in the right pane:

  3. Click on the OK button to create the folder.

Now, when you create templates, only templates of the allowed type can be added to this folder. Furthermore, when you create a template of a different type, this folder will not even appear in the Save <component, folder or solution> as template wizard.

Rename a folder

The user can rename a folder.

To rename a folder

  1. In the Explorer window, right click on the folder you wish to rename.
  2. Select Rename.
  3. In the Rename dialog, type the new name in the New name field.
  4. Click on the OK button.

The system will check to ensure that this name is unique within the solution and rename the folder.
