Add a folder or solution template from the local repository

This topic provide details on how to use the Add from local template wizard to consume a folder or solution template from the local Content Repository into a solution located in the same repository.

A template is used to create generic content that can be reused in a solution, speeding up the solution build process. Once a template has been consumed, any template tracking information (information that links the template to the repository which was used to create it) can be viewed using the Consumed Templates window. For more information about templates, refer to the Content Management overview topic.

 

Before consuming a template, ensure:

  • you have a security profile that includes the Architect functional role
  • the target location (folder or solution) has the correct allowed component type(s) and the Recycle Bin is empty (to avoid any potential conflicts).
 

During the Add from template process, all component references will be properly retained depending on conflict resolutions. However, this cannot be guaranteed for characteristic references, since characteristic references are not resolved by name in the Class Set, but by the ID of the characteristic. In this case, some manual steps are needed to resolve these validation errors, although the Class Set references the correct Logical Data Source (from the local system).

 

A consumed template will keep the internal relationships between the components, the associated publishing rules and the allowed component types.

To consume a folder or solution template from a remote repository into a folder or solution

Consuming a folder or solution template into a target location
  1. In the Explorer window, load the solution with the folder or solution template that you want to consume from the local Content Repository. In this example, the template has tracking information.
  2. In the Solution Repository, right click on the folder or solution into which you want to consume the template (folder or solution), select Add from template and then Local repository...
  3. The Select template step is the first screen of the Add from local template wizard.
    1. Select the template (folder or solution) you want to consume.
    2. Click Next.
  4. The Configure options step is the second screen of the wizard.
    1. Optionally, if there is a URL displayed in the External Link (URL): field, to view the web page in your default browser, click Open.
    2. Click Next.
  5. The Configure targets step is the final screen of the wizard.
    6.  

    When consuming a folder or solution the following options are disabled by default:

    • Conflicts: Precedence
    • Original Template Structure.
     
     

    To collapse a folder structure, right click on the solution or folder and select Collapse all. To expand a collapsed structure, right click on the solution or folder and select Expand all.

    1. In the Configuration name field, enter the name of your current configuration. This configuration name will be saved in the solution once the template has been consumed. Its purpose is to allow you to differentiate between different consumptions of the same template in the same solution. It is displayed in the Consumed template window, under the Template Structure column. For example, <template name> (<configuration name>).
      2.  

      To view the content of a note attached to a component, select the component row that is displaying the Bold Notes icon. The note will be displayed in the Notes area below the table columns. Alternatively, the content of the note can be viewed using the tooltip.

    2. Click Finish.
  6. Click OK to launch the Job Submission Console from the Remote Job Notification dialog.

Once the job has been successfully completed, the content of the template (folder or solution) will be displayed in the Explorer window, under the Solution Repository. Any folders created by the Consume Template Job are saved in the shared domain.
