Target Selection panel

The Target Selection panel allows the user to select the target Data Model component for the selected source Data Model component, as part of the Merge process.

  In this topic Logical Data Sources, Logical Data Model characteristics and Logical Data Source characteristics will be referred to as ‘Data Model components’.

 

The Target Selection panel consists of two tabs (Auto-Match and Manual Select), a toolbar and a contextual menu:

Auto-Match tab

In the Auto-Match tab the user can select a target component based on a Match score percentage.

This option can be used when the imported content is referring to existing characteristics within the target Entity Model, and it has the same business context. It will propose the best candidate(s) for each of the source characteristic to bind to the target Data Model component. The user can then trigger the automatic mapping for all the selected source characteristics.

The Auto-Match tab consists of a table with three columns that contain the candidate characteristics, which can be used as the target characteristics and an Information area:

Parent name - displays the full name of the mapped target Data Model component. Hovering with the mouse over the component name will display the folder path.

Characteristic name - displays the full name of the mapped target Data Model component. Hovering with the mouse over the component name will display the target path.

Match score - displays the target characteristics sorted according to their match score percentage. The higher the score percentage the better the match (for example, a Perfect match is 100%).

The target characteristics that could match the selected source characteristic are listed from the top with Historic matches (if any), followed by Perfect matches (if any) and then by the next highest match score in descending order. For information on what determines a Perfect match and to set the Visibility score (minimum percentage threshold) see the Matching Options topic.

 

To change the row order displayed in the Characteristic Panel, click on the column header once for ascending order, twice for descending order and three times for the default order.

To move a column drag and drop the column header.

  
 To show or hide the columns, either right click on a column header to access the contextual menu or click on the Select Visible Columns button located above the vertical scrollbar.

Information area - displays details about the selected target characteristic (for example, its properties, folder path and characteristic path as well as the current mapping details including any mismatches between the source and target characteristics)

Manual Select tab

In the Manual Select tab the user can either:

  • navigate to a target component destination that can be mapped to. This option can be used when the Automap process cannot find a Perfect match or a Best Candidate that fits the solution context. Therefore, the user can navigate to a Logical Data Source and select a specific target characteristic.
  • navigate to a target component destination to create a new characteristic(s). This option can be used when the imported characteristic does not have the same equivalence in the target solution. Therefore, this characteristic can be mapped as 'new' in the selected Logical Data Source that belongs to the target Data Model component.

The Manual Select tab consists of three columns and an Information area:

Name - displays the target Data Model components and their structure in a hierarchical tree

Length - displays the number of digits or characters the field can hold (including any decimal components)

Scale - displays the number of decimal places required

 

To change the row order displayed in the Characteristic Panel, click on the column header once for ascending order, twice for descending order and three times for the default order.

To move a column drag and drop the column header.

  
 To show or hide the columns, either right click on a column header to access the contextual menu or click on the Select Visible Columns button located above the vertical scrollbar.

Information area – displays details about the selected target characteristic

Toolbar

The toolbar consists of:

Map - maps the target Data Model component to the selected source Data Model component.

 When Logical Data Sources are mapped their characteristics are not taken into account. The Logical Data Sources characteristics should be mapped separately.

New - assigns a Logical Data Source or a Logical Data Model characteristic as the destination for the selected source Data Model component(s). During the Merge process the target characteristic is created in the destination that has been selected using the same name as the source characteristic. If a characteristic exists with the same name the new characteristic with be renamed automatically (for examples, char would be renamed to char1).

Contextual Menu

The contextual menu can be accessed by right clicking on any row:

Map - maps the target Data Model component to the selected source Data Model component

New - assigns a Logical Data Source or a Logical Data Model characteristic as the destination for the selected source Data Model component(s). During the Merge process the target characteristic is created in the destination that has been selected using the same name as the source characteristic. If a characteristic exists with the same name the new characteristic with be renamed automatically (for examples, char would be renamed to char1).

Where used - displays all components that have references to the selected Data Model component
