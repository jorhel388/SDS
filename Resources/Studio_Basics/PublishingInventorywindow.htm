Publishing Inventory window

The Publishing Inventory window enables the user to see an inventory view of all publishing rules that have been carried out in the solution. The list will alter depending on whether Outbound or Inbound has been selected in the Publishing editor.

The Publishing Inventory window consists of the Publishing Inventory window toolbar, the Inventory table and the Filter.

Publishing Inventory window toolbar - The Publishing Inventory window toolbar is displayed down the left hand side of the window and selecting options from this tool bar alters the content of the inventory.

The Inventory table consists of up to 4 columns. To add or remove a column, right click in the column header row and the Change Visible columns dialog will be initiated. Simply tick to display or un tick to remove. The Change Visible Columns dialog can also be initiated by clicking on the icon in the Publishing Inventory window.

Available columns are;

Source - displays the name of the source folder used to create the publishing rule

Path - displays the entire path of the source folder used to create the publishing rule

Type - indicates the type of publishing rule (transversal / hierarchical up or down)

Target - displays the name of the target folder used to create the publishing rule

Filter - Typing entries into the Filter box will filter out the names of target folders that do not match the contents of the filter. Select the Clear button to remove the filter selection.

Publishing Inventory window toolbar

The Publishing Inventory window toolbar is displayed down the left hand side of the Publishing Inventory window and enables the user to alter the content of the displayed inventory.

Expand All - expands the contents of all the folders to display fully all the outbound or inbound publishing rules that exist in the solution

Collapse All - collapses the list so that only the folders are displayed

Switch from Target to Source grouping - will cause the inventory window to display either Outbound publishing rules or Inbound publishing rules

Display current folder's rules only - when displayed the rules for all folders are displayed
