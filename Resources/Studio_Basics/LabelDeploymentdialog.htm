Label Deployment dialog

The Label Deployment dialog enables the user to deploy one or more labels at a time. The user can supply edition names and deployment notes.

The Label Deployment dialog consists of the following:

Label Suffix - enter a label suffix that can be applied to all deployed labels at once to provide a uniform edition name. Alternatively, an edition name can be typed directly into the Edition Name field.

Notes - enter notes that can be applied to all deployed labels at once. Alternatively, notes can be typed directly into the Deployment Notes field.

- click to apply the contents of the Label Suffix and/or Notes fields to all labels selected for deployment.

Select - select the labels to deploy.

Label Name - the name of the label selected for deployment from the Label Management editor. Field is not editable.

Edition Name - the name of the label edition as it will appear in the Label Management editor once it is deployed. This must be different from the Label Name.

Deployment Notes - optional notes regarding the deployment.

Expected Edition - the edition number that will be assigned following deployment. This column is not editable, but the user can change the expected edition number by clicking on the following button and using the Override Edition Number dialog. The Expected Edition field will contain the values N/A if the deployable component is not a Decision Process Flow and the button will remain inactive.

- selects all labels for deployment.

- deselects all labels selected for deployment.

- deploys all selected labels.

- cancels the deployment and close the dialog.
