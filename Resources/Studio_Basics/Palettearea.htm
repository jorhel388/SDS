Palette area

By default, the Palette area is displayed down the right hand side of the User Interface.

The Palette area houses the following windows:

  • The Palette window
  • The Resources window
  • The Properties window

By default on opening the software the Palette area is empty.

  Components that have been moved to the Recycle Bin cannot be viewed in the Palette area.
Palette Overview

The Palette window is displayed in the Palette area when there is a palette of system resources available for the component being edited or when opened from the Main menu bar. When there are no system resources available, the Palette area will not be displayed.

The Palette contains a list of system resources that are available for use in the active editor. The user can drag and drop resources from the Palette window into a component being edited in the Main editor. The content of the Palette is directly related to the type of editor open in the Main editor, the capability of the user's particular software, together with the access rights of the user.

If the editor does not require the user to use any resources, or an editor is not open in the Main editor, the Palette area will empty.

If the Palette window has been closed, it can be reopened again at any time.

To open the Palette window

  1. In the main system view, click on Window in the Main menu bar and select Palette.

The Palette window is displayed.

Resources Overview

The Resources window is displayed in the Palette area when there is a resources window available for the component being edited or when opened from the Main menu bar. Only resources created by the user will be available in the Resources window.

The Resources window contains a list of resources that are available for use in the active editor; components that are relevant, components that are visible from the folder of the component being edited or components in another folder that are published to it. Please see the Publishing overview for more information.

The user can drag and drop resources from the Resources window into the component being edited in the Main editor. The content of the Resources window is directly related to the type of editor open in the Main editor along with the access rights of the user.

Components in italics are located in a different folder to the component being edited and are available for use because they have been published to this location.

If the editor does not require the user to use any resources, or an editor is not open, the Resources window will be empty.

If the Resources window has been closed, it can be reopened again at any time.

To open the Resources window

  1. In the main system view, click on Window in the Main menu bar and select Resources window.

The Resources window is displayed.

Properties overview

The Properties window is displayed in the Palette area when properties for the item selected are available. By default, on opening the studio the Properties window is not displayed. The Properties window can be opened from the Main menu bar.

Properties are the characteristics of a Repository, Domain, Solution, Folder, Component or Decision Process Flow node.

The detailed properties of any selected Repository, Domain, Solution, Folder, Component or Decision Process Flow node can be displayed in the Properties window. The properties displayed will depend upon the item selected.

If the Properties window has been closed, it can be reopened again at any time.

To open the Properties window

  1. In the Main system view, click on Window in the Main menu bar and select Properties.

The Properties window is displayed. You will now be able to select display the properties for any Repository, Domain, Folder, Component or Decision Process Flow node.

Display Properties

The detailed properties of any selected Repository, Domain, Solution, Folder, Component or Decision Process Flow Node can be displayed in the Properties window. The properties displayed will depend upon the item selected.

The user can view the properties.

To display properties

  1. In the Main system view, click on Window in the Main menu bar and select Properties.
  • To view the properties for a repository, click on the required repository in the Explorer window. The Properties window will be populated with the property detail for the repository.
  • To view the properties for a domain, click on the required domain in the Explorer window. The Properties window will be populated with the property detail for the domain.
  • To view the properties for a solution, click on the required solution in the Explorer window. The Properties window will be populated with the property detail for the solution.
  • To view the properties for a folder, click on the required folder in the Explorer window. The Properties window will be populated with the property detail for the folder.
  • To view the properties for a component, click on the required component in the Explorer window. The Properties window will be populated with the property detail for the component.
  • To view the properties for a decision process flow node, click on the required node in the Decision Process Flow editor. The Properties window will be populated with the property detail for the node.
