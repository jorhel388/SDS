Quick Search

The Quick Search option allows the user to search for a word or a phrase. This search option will locate items in component names and within scripting components and include items that have been moved to the Recycle Bin.

  A search will be restricted to the components for which the user has permissions.

A Quick Search can be carried out using the Quick Search bar in the Main menu bar.

The Quick Search bar consists of two areas:

Category Selection- Click on the magnifying glass icon to display the available search categories.

By default the Quick Search is set to Components and Text Content. The user can confine the search to the following areas:

  • Components: This category lists the search results from the Solution components and Content Repository.
  • Text Content: This category lists the search from the contents (the script) contained in all the scripting components from the Solution.
    •   The Text Content category will not be populated with any results from the Content Repository, since the Content Repository only contains templates, not content (text).

Quick Search in the system - This is a free text field. The user may type a word or a phrase in this field.

The Search results will display beneath the Quick Search bar, (in an alphabetical list split by category) the first 15 results that satisfy the search.

A Quick Search can be carried out using the Quick Search bar in the Main tool bar.

Use Quick Search in a defined category area

To search within a defined category

  1. Load a system.
    2.   You will be unable to carry out a search until you have loaded a solution. By default the Quick Search is set to All Categories. The search can be defined to certain areas.
  2. Click on the Category Selection icon.
  3. From the drop down list, select and click the area for which you wish the search to return results.
  4. Click in the Quick Search field .
  5. Type in the word or the phrase you want to search for.
  6. The results will display beneath the Quick Search bar, (in an alphabetical list split by category) the first 15 results that satisfy the search.
  7. Select and click on a search result.

Dependant on the category that the result sits within, the appropriate component or scripting component will be displayed.

Use Quick Search to find a word or phrase

To use Quick Search to find a word or a phrase

  1. Load a system.
    2.   You will be unable to carry out a search until you have loaded a solution. By default the Quick Search is set to All Categories. The search can be defined to certain areas.
  2. Click in the Quick Search field or use CTRL+I to take you to the text field.
  3. Type in the word or the phrase you want to search for.
  4. The results will display beneath the Quick Search bar, (in an alphabetical list split by category) the first 15 results that satisfy the search
  5. Select and click on a search result.

Dependant on the category that the result sits within, the appropriate component or scripting component will be displayed.

The Advanced Search function and the Where Used query are also available to the user.
