Using the Help System

The Help System is available at all times. The user can activate the Help System by clicking on the F1 button in any area within the software, clicking on a Help button from any dialog or by selecting the Help menu option from the Main menu bar.

To access Help using F1

  1. Whilst anywhere in the software, click on the F1 button.
    The Help dialog will appear. Clicking on the F1 button initiates context sensitive help, so that the Help dialog opens on an appropriate page. A help information screen relative to the area of focus will be activated.
    2.   Users must have clicked in or be working in an editor to activate help information relative to that area.

To access Help using the Main menu bar

  1. Click on the Help option in the Main menu bar.
    A drop-down menu will appear
  1. Select Help Contents.

The Help dialog will appear. Using the Main menu option initiates general help; the Help dialog will open at the Introduction page.

To view the images in the help

The help is designed so that the images in the help appear as thumbnails.

  1. Click on the thumbnail in the topic.
    The image will appear full size.
  2. Click on the full size image.
    The image will return to how it appeared as a thumbnail in the topic.
Using the Search in the Help System

The Search box enables the user to search for a key word or words within the Help System. Using the search will display all the help pages where that word is used, either in the title, or within the help page content. The Help System's search engine uses a combinations of factors to rank the search results. When you search, the search engine considers the number of links to a topic (Importance) as well as the number of times a search term appears in a topic. This gives you the most accurate results.

To search for a word within Help

  1. Within the Help System, in the Search box type a word or words relating to the information you wish to find into the box.
  2. Press Enter on your keyboard.
  3. Click on the title of the Page listed in the Help window.
    The Help System will display the help topic.
  4. To return to the search results, click on your browser's Back button. The Help System will display the search results once more.

For more details on how to refine your search refer to the Search Methods and Syntax topic.
