Printing

A printable document can be invoked for view or for print out from the Explorer window, from the Main menu bar of the user interface or from Label Management when a label is selected. Only components that the user has access to will be available to view as a printable document.

When a component has been marked as Protected it will be listed in the Explorer Window with the following icon . A component that has been marked as protected cannot be printed by a normal user.

  To ensure that the print matches the latest state of the component, any component being edited should be saved before printing.
Printable document types

From the Explorer window there are different types of printable documents available, at the Solution, Folder and Component level:

Inventory: When Printable Doc . . .> Inventory is selected the printable document will contain a list of the names of the components contained in the solution, folder or component from which the user invoked print. See the Produce an Inventory printable document help topic for more details.

Summary: When Printable Doc . . .> Summary is selected the printable document will contain a list of the name of the component(s) contained in the solution, folder or component from which the user has invoked print as well as a printout of the component itself. Using a Scorecard as an example, if the user selects Printable Doc. . .> Summary, the printable document will include the name and inventory details of the Scorecard in addition to a printable document of the Scorecard itself. See the Produce a Summary printable document help topic for more details.

Detailed: When Printable Doc . . .> Details is selected the printable document will contain the name of the component(s) contained in the solution, folder or component from which the user has invoked print, a printable document of the component itself as well the names and properties of all the dependent components. Using a Scorecard as the example, the printable document will be the same as the summary, but will also include details of the referenced and embedded Class Sets, Matrices and Boolean Expressions as well as all the characteristics and Logical Data Sources they reference. See the Produce a Detailed printable document help topic for more detail.

Print From Template: When Printable Doc . . .> Print From Template is selected the printable document will contain the name of the component(s) contained in the solution, folder or component from which the user has invoked print, a printable document of the component itself as well the names and properties of all the dependent components. The order that this information is produced in the document will be determined by the Print Template selected from the Print From Template dialog.
Within Label Management when a label is selected only the Print From Template printable document level will be available for selection. See the Print from Template help topic for more details.

The Main menu bar of the user interface allows the user to set one type to be made available for view and print. The Lite print can be made available here, it is not available for selection from the Explorer window.

  The Lite level must be selected in the Printing dialog available in Options. Please see the Produce a Lite printable document topic for more information.

Lite: When File > Printable Lite Doc is selected the printable document will contain a view of the component the user has open in the editor. The printout will not include a front page.

When the print type has been selected the Print editor will be displayed in the Main editor. It is from this editor that the actual printout can be manipulated.

Print Process
View or edit the page setup prior to printing

The user can view or edit the page setup prior to printing.

To view or edit the page setup prior to printing

  1. Within the Help dialog, ensure that you are viewing the help page you wish to view or edit the page setup and click on the button.
  2. The Page Setup dialog will appear, similar to the following:

  3. You have the option to edit the paper size and source, the orientation and the margin limits. Once you have viewed or edited the page setup, click on the OK button.

You may now print the customised page.

Print a printable document

The user can produce an Inventory, Summary , Detailed or Print From Template printable document from the software.

To print a printable document

  1. Right click on a solution, folder or component in the Explorer window and select Printable Doc, then select Inventory, Summary, Detailed or Print From Template.
  2. The print editor will be displayed in the Main editor area of the user interface.
  3. To print the printable document, click on the icon in the print editor tool bar.
  4. The system will open the Print dialog for your printer.
  5. Configure the printable document as appropriate for your requirements.
  6. Click on the OK button.

The document will now be printed.

The user may also Produce a Lite printable document and print this if required.

Printing a graphical component

The Print settings for graphical components are defined using the Scaling and Auto Rotation options found in the Component Scaling Rotation tab in the Options dialog when the Printing icon is selected.

Scaling can be set to a value of 50%, 60%, 70%, 80%, 90% and 100%:

  • When a % value has been selected, then the printing framework will scale the image down until it fits this percentage. If the image fits on a page before the selected % then it will stop and not continue to scale down. If a single page fit cannot be made, the image will remain at its new scaled down size, but it will be split across pages.
  • To aid the user, the printout will be produced with coordinates enabling the printout to be put back together by the user in the correct sequence. For an example see Tiled print.

Auto Rotation can be set to On (default) or Off:

  • On - the printing framework will attempt to fit the image on a single page in either landscape or portrait. If the image does not fit on a single page then the orientation which takes the least number of pages will be used.
  • Off - the printing framework will print the image to the print layout in the orientation that has been supplied.

Printing for a graphical component has currently been implemented for the following components:

  • Batch Process Flow
  • Business Process Composition
  • Business Process Flow
  • Connectivity Process Flow
  • Connectivity Process Subflow
  • Customer Management Solution
  • Database Physical Data Model
  • Decision Process Flow
  • Decision Process Sequence
  • Enrichment Access Strategy
  • Enrichment Hierarchy
  • Enrichment Pack (Enrichment Solution tab and the Enrichment Hierarchy tab)
  • Entity Model
  • Event Process Flow
  • Hierarchical Enrichment Definition
  • Interface Pack
  • Page Flow
  • Policy Rule Set
  • Solution Pattern
Save a printable document

The user can produce an Inventory, Summary or Detailed printable document from the software. A printable document can be saved to a location of the users choice, in either PDF, RTF or HTML format in order that it can be printed or used when required.

To save a printable document

  1. Right click on a solution, folder or component in the Explorer window and choose Printable Doc, then select Inventory, Summary or Detailed.
  2. To save the printable document, click on the icon in the print editor tool bar.
  3. The system will open the Save dialog.
  4. Locate the folder to which you would like this printable document to be saved and the format of the save.
  5. Click on the Save button.

The printable document will be saved to the location you have chosen and be available to print as required.

The user may also Produce a Lite printable document and save this if required.

Select a Default Print Theme

The user can select a Default Print Theme to be used within the Printing dialog available in Options.

Only custom themes that have been configured for the studio that a user is running will be available for selection.

To select a Print Theme

  1. In the Main menu bar of the user interface, click on Tools.
  2. Select Options.
  3. The Options dialog will be initiated.
  4. Click on the icon.
  5. Click on the Component Sequence tab.
  6. From the Template field, select the appropriate theme from the drop down list.

    A text pane will be displayed giving information about the theme you have chosen.

  7. Click on the OK button.

    The Print Template is now set.

The user can produce an Inventory, Summary, Detailed or Lite printable document from the software and the template selected using the Component Sequence tab within Printing will be used.
