Explorer view bar

The Explorer window is housed in the Explorer area of the user interface. It can be opened from the Main menu bar should you find it closed upon opening the software.

The Explorer window consists of a tool bar, the hierarchical tree structure area and the Explorer view bar.

The Explorer view bar is displayed at the bottom of the Explorer window.

The icons allow the user to choose different views of the hierarchical tree structure of the system.

Explorer view (default view) - Click on this icon to display the hierarchical structure of the repository. In this view, components are organised in folders in alphabetical order.

Component Types view - Click on this icon to display components in groups depending on types. The component types that are present in the selected repository are displayed in a list.

Recently Changed view - Click on this icon to display only those components that have changed within the past week, regardless of the user.

Referencing Components in Recycle Bin - Click on this icon to display only those components that have dependent components in the Recycle Bin.

My Work view - Click on this icon to display only those components that the user has created or modified. Components in the local and shared areas will be displayed.

Favourite view - Click on this icon to display only those components that the user has marked as favourite. For more information, refer to the Mark a component as favourite topic.

My Workspace - Click on this icon to display only those components that the user is currently editing, components that the user has checked out from the shared area. Components that have been checked in will not be listed here.

  You can use the and the icons to collapse and expand the folders.
