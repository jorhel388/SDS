Main toolbar

The Main toolbar enables the user to save work, save changes, cut, copy and paste. It also enables the user to undo and redo actions, monitor memory usage, carry out a quick search and validate a component. It is located directly below the Main menu bar in the user interface.

The following tools are displayed on the toolbar:

Validate - Allows the user to validate the component in focus in the Main editor.

Save - Allows the user to save changes.

Save all files - Allows the user to save all files.

Cut - to cut an object and place it into memory.

Copy - to copy an object into memory.

Paste - to paste an object that has been stored in memory.

Undo - to undo actions made in text editors and table editors.

Redo - to redo actions made in text editors and table editors.

Memory monitor - allows the user to monitor memory usage. This shows the amount of memory currently being used by the application and the total amount of memory allocated to the application.

Snapshot - allows the user to generate a snapshot of memory usage which can be saved and sent to Experian support for further analysis. Click to start the capture process and then click to stop the process and save the data.

Last Login - allows the user to directly access the Audit Trails editor within the Security Explorer window. It displays the time of the previous login of the current user. Any suspicious times should lead the user to check the Audit Trails log. The user can view Audit Trails of their own activities with the option to filter for a date and time period using this button.

If all options do not appear available to the user, the user can modify the Main toolbar if required.

Modifying the Main toolbar

The Main tool bar enables the user to save work, save changes, cut, copy and paste. It also enables the user to undo and redo actions, monitor memory usage and carry out a quick search. It is located directly below the Main menu bar in the user interface. If all options do not appear available to the user, the user may modify the Main tool bar.

To modify the Main tool bar

  1. In the main system view, click on the View option in the Main menu bar and select Toolbars.
  2. Click on the listed tools to add or remove them from the toolbar display.

The Main menu toolbar will display accordingly.
