Read only component notification message

The Read only component notification message is displayed when a user opens a component for which they only have Read only access. A user can amend and test the component and save it locally, but they will not be able to check in the component.

The message will be displayed when:

  • components with Read only permissions are opened from the Explorer

  • a referenced component for which the user has Read only permissions is opened within another component

 

The message will not be displayed when opening a component for which the user has Update or Create permissions.

For more information on the functional roles available to a user, see the Functional Roles topic.

Selecting the 'For this component, select to hide this message for the duration of the session', check box will stop this message from being displayed every time the component is opened during the current session (that is whilst the user is logged into the Design Studio).

When the component is opened, even though the message will no longer be displayed, the title bar will still indicate to the user that they have Read only access to the open component.
