Label Management

Label Management allows the user to define and tag a set of components that can then be acted upon as a group rather than individually. The label can be used to access the component set from the shared repository for export, check out, printing, deployment, etc. It is also used for versioning, to stamp a label onto a set of components or revisions to record the fact that they have been subjected to a specific action. Labels can be deployed repeatedly; different deployments are treated as different editions of the original label.

Overview

Label management allows the user to identify labels that have been assigned to component(s) located in the Recycle Bin or edition labels that contained some components that have been permanently deleted.

Label Management also enables users to compare two label sets (typically deployment edition labels), to see at a summary level, within the Label Comparison View which components have been added/removed/modified across the two labels, and which components have been changed.

Labels can be assigned from the Explorer, or whenever a check in action is performed on a component. The user can either create a new label or use an existing label (thus adding the component to an existing set). Labels can also be used when components are imported into a shared repository, to tag the set of components brought into the system. Labels themselves are stored in a shared area, available to all users.

Finally, the user can use labelling to pull together a component set by selecting individual components from the explorer; by assigning a label to a group of related components at the folder or solution level; or by some automatic discovery process (for example, all components referenced by a particular process flow).

While one label can be assigned to many different components, the same label cannot be assigned to different revisions of the same component. This is because labelling is intended to keep track of the various revisions in a coherent system.

Assign a label to a component

The user can select an individual or a number of components from the Explorer and assign a label to it; or the user can assign a label to all or some of the components within a selected folder or solution.

The assigned label can be created as part of this process, or it can be a pre-existing label that may or may not include other components. The selected components can be added to the label by itself, or along with some or all of its dependent components. These various options are all managed by the Assign label Wizard.

  A label can also be assigned whenever a check-in action has been performed on a component (using the Check-in Wizard).
 

Labels can only be applied to versions in the shared area. They cannot be applied to components that haven't been checked in or to changes that only exist in a user's area.

To assign a label to a component

  1. From the Explorer window right click on a component and select Assign label. The first screen of the Assign label wizard, Component Chooser, is displayed.
    2.   To assign a label to more than one components within a folder; with a folder selected, click on the Step into icon to view the contents of this folder in the Explorer window. Use the Ctrl key on your keyboard to select the components you require.
     

    To assign a label to all the components within a folder or solution, right click on a folder or a solution, select Manage components and then select Assign label.
  2. If more than one revision of any component exists, you can select the revision number to which you want to apply the label from the drop down list, in the Revision column.
    3.  

    To exclude the dependencies of a specific component(s) from the label, select the No option from the drop down list in the Dependencies column.
  3. Select the Custom selection of dependencies checkbox, to include only a custom selection of dependencies with the component.
    4.   When the Custom selection of dependencies checkbox is left unchecked, all the dependent components will be included into the label. After clicking on the Next button, the wizard will skip to the third screen, Label Choose .
  4. Click on the Next button. The second screen of the wizard, Custom selection of dependencies will be displayed.


  5. By default, all the dependent components are selected to be included into the label, along with the original component(s). Unselect the components you do not want to include in the label, or click on the button to include none of the dependent components.
  6. Click on the Next button to display the third screen of the wizard, Label Chooser. A list of all the existing labels in the solution is displayed.

  7. Select an existing label to assign the components to or create a new label for the components by selecting the Create label button.
    8.  It is not possible to select multiple labels
  8. Click on the Next button to display the fourth and final screen of the wizard, Summary. This screen displays information about the label you are about to create and the list of components that will be assigned to the label. If the information displayed is correct, click on the Finish button to create the label.

The label is now assigned to the selected components.

Check out a label

The Label Management editor enables the user to check out a set of associated components by checking out the label assigned to them.

To check out a label

  1. From the Window menu, select Label Management from the Window menu. The Label Management editor is displayed.
  2. From the Label Management editor, select a label to check out.
  3. Right click on the label and select Check-out from the menu. The first screen of the Check-out wizard, Component Chooser, is displayed:

    The following information is displayed for each component:

    Name - component name

    Broken state - indicates if the component is in a broken state

    Revision user area - displays component version number in the user domain

    Revision shared area - displays component version number in the shared domain

    Update date - displays the date component was last updated

    Update author - displays who last updated the component

    Status - displays if the component can be checked out

    Detail - display label detail

    Select - check the tickbox to include the component in the check out procedure

  4. Select the components to check out. By default, all components are selected. If there are problems with any components, the Accept Warnings tickbox will become activated. You can still check out a problem component by checking the tickbox.
  5. Click Next to display the second screen of the wizard, Summary. The Summary screen displays the list of components that will be checked out if you continue.
  6. If you are satisfied with the list, click Finish to check out the set of components.

The set of components associated with the label are checked out.

Compare the contents of two labels

Label Management enables users to compare two label sets (typically deployment edition labels), to see at a summary level, within the Label Comparison View which components have been added/removed/modified across the two labels, and which components have been changed.

A component that has changed will be displayed in blue as shown below:



Within the Label Comparison View the user can select the specific component that has changed followed by either the:

Print Comparison icon, or the

Text Comparison icon (On-Screen view)

The software will produce details of the component differences either as a print out that can be saved or printed or via a read only display that provides descriptive details of any changes in text form, enabling the user to view the details of the component differences easily.

To compare the contents of two labels

  1. From the Windows menu select Label Management. The Label Management editor will open.
  2. Select the two labels that you wish to compare.
  3. Click on the Compare Labels icon.
    The Label Comparison View will open.
  4. Using either the up or down arrow as required, select the component that has changed.
    The Text Comparison icon and the Print Comparison icon will become active.
  5. Click on the On-Screen Comparison icon to open the Text Comparison view.
  6. Click on the Print Comparison icon to open the Print Comparison view.

Use either comparison tool as required.

Merge labels

The Merge Labels Wizard is used to assign to a specific label the content of several labels.

To merge labels

  1. From the Window menu, select Label Management. The Label Management editor is displayed.
  2. From the Label Management editor, select the labels to merge. To select multiple labels, hold down the Ctrl key while clicking on a label.
  3. Right click on one of the selected labels and select Merge from the menu. The first screen of the Merge Labels Wizard, Component Chooser, is displayed:

  4. By default, all the components within the selected labels are selected for the merge. Unselect any components you do not want to include in the merge.
  5. Click on the Next button to display the second screen of the wizard, Label Chooser. The list of all the existing labels in the solution is displayed:

    At the bottom of the screen is a set of buttons that allow you to limit the labels that will be displayed. Also a new label can be created, if needed:

    All labels - displays the list of all the existing labels in the solution

    My labels - displays only the labels you created or modified

    Recently changed - displays labels that were changed in the past 7 days

    Create label - creates a new label for the content of several labels

    Show label - displays all components that are assigned the selected label

  6. Select a label to assign or create a new label for the merged set of components.
  7. Click on the Next button to display the third screen of the wizard, Summary. This displays information about the label you are creating, and the list of components to which you are assigning the label. If the information displayed is correct, click on the Finish button to create the label that includes the merged set of components.

All the components assigned with the selected labels from the first screen (Component Chooser) of the wizard have been assigned with the label selected in the second screen (Label Chooser).

 

If the same component with the same revision exists in several labels to be merged, then this component and revision will appear once in the outcome label.

If the same component with different revisions exists in several labels to be merged, then the highest component revision will appear by default in the outcome label; one of the older revisions can be manually selected from the drop down list as shown in the example below.
Unassign a label to a component

Labels can be unassigned to components from the Label Inventory.

  An Edition label cannot be unassigned.

To unassign a label

  1. Open the Label Inventory from the Label Management editor or from the Label Chooser screen of any of the label wizards, by selecting a label and clicking the View components button .
  2. Click on the component for which you want to unassign the label, or select multiple labels by holding down the Ctrl key while selecting the labels, then right click on a label and select Unassign label from the menu.
  3. At the prompt, click Yes to unassign the component(s).

The label(s) has been usassigned from the component(s).
