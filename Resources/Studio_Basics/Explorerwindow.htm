Explorer window

The Explorer window is housed in the Explorer area of the user interface. By default, on opening the studio the Explorer window will be displayed. If it is not displayed, it can be opened from the Main menu bar. Once opened, it will be displayed on the left hand side of the interface (default position).

 

The Explorer window will display only areas for which the user has permissions.

The Explorer window consists of:

Explorer toolbar

Explorer view bar

Hierarchical tree structure area: - displays the hierarchical tree structure of the system and includes the following items: repositories, domain(s), solution(s), folder(s) and components(s).

The text colours displayed in the Explorer window vary depending on where the item is located. The text colours can be customised, if needed.

  • Black text (default) - this item is located in the shared area
  • Green text - this item is located in the user area
  • Blue text - this item is located in both the user and shared areas
  • Grey text - this item is not available to the user in the current solution
  • Red text - this item is located in the Recycle Bin
 

The number of components displayed in brackets next to the Recycle Bin indicates the number of components that have been moved into the Recycle Bin. It is recommended to empty the Recycle Bin to have a clean export of the components and better performance of the system.

Some components may include a Stamp icon (for example, in the above screenshot, the <> can be seen in front of the component names in the Customer Components folder). A Stamp icon allows users who have access to the solution to identify which components are coming from a stamped template in the Explorer window. The Stamp icon can be applied to a consumed template using the Consumed Templates window.
