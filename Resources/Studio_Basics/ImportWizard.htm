Import wizard

The Import wizard allows a user to import an exported item (saved in an export.xml file), such as:

  • a component, folder or solution into a solution
  • a template into a Content Repository
 

To create an Import job a user must have the Solution Administrator or Architect Functional role in their security profile.
 

The import and export functionalities are available for the repository types (Content, Reporting and Solution). An .xml file can only be imported into its respective repository type (the same repository type that was used to create it) otherwise, a warning message will be displayed.

For information on how to use the Import wizard, refer to the Import a component, folder, solution or template topic.

The Import wizard consists of the following screens:

Select import source

The Select import source is the first screen of the wizard. It allows the user to select the .xml file and the import source type to use for the import.

 
 

The Overwrite functionality does not support legacy templates when importing contents that already exist in the Content Repository. The wizard will stop the process and no components will be imported.

Legacy templates include contents exported using Design Studios prior to and including PowerCurve Originations v1.13 and Strategy Design Studio v2.13.

This screen consists of:

File name - displays the selected file name and its extension

Files of type - allows the user to select the import source type using the drop down menu

View import file

The View import file screen is the second screen of the wizard. It displays the content of the repository structure that will be imported.

Review Components

The Review Components screen is the third screen of the wizard. It displays information about the conflicts on the components that will be imported. It also allows the user to specify the import option and to accept any warnings detected by the wizard.

 

The Components to import area will be blank on the Review Components screen, if there are no conflicting components in the target repository (solution or content) when importing a component, folder, solution or template.

This screen consists of the following.

Table Columns

Type - displays the component category type

Name - displays the component name

Revision - displays the last version of the component in the shared area

 
 

When importing a content into the Content Repository, the Revision column will be replaced by the Local and Import columns.

Local - displays the latest revision of the component in the Content Repository

Import - displays the revision of the component to be imported

Locked - displays the Lock status icon for a locked component

Update Date - displays the date when the component was last modified

Status - displays the state of the target components in the solution compared to its counterpart in the .xml file:

  • Ready - the component has no conflict and is ready to be imported
  • Failed - the component has failed due to an issue(s). To proceed with the import process the issue(s) must first be resolved (for example, the component is currently being edited - please close the editor to continue).
  • Warning - the component has a warning, for example:
    • the component has been modified in the user area. To proceed with the import process the user can accept the warning(s) using the Accept Warnings checkbox.

    • the component to be imported into the Content Repository will be skipped, if it has the same or a lower revision than the one currently in the Content Repository. Only newer revision(s) will be imported.

Details - displays the failed or warning message (more information is displayed in the area below the Accept Warning checkbox)

Import Options

 
 

Both the 'Accept Warnings checkbox' and 'Radio buttons' do not apply to a template and are disabled by default.
 

To view all the available import options, a user must have the Architect licence and Architect security profile.

Accept Warnings - accepting the warnings detected by the wizard will allow the user to proceed to the next step of the import, which will overwrite components in the user area.

Confirm choices

The Confirm choices screen is the fourth screen of the wizard. It displays the import summary details and allows the user to add comments and a label.

This screen consists of:

Import Summary - displays the import summary details

Solution Properties - displays the solution properties information, such as a Signature, the DA Null Handling value in a table:

 

During import Architect users will have the option to overwrite existing property values in the target solution with the value in the export file (.xml) if it is present. Non-architect users will be able to see the property settings in both the target solution and the export file as read-only.
 

When creating a new solution from an export file, all users will be able to choose to use any property value in the file or to use the default setting.

  • Property - displays the solution property name.

  • Value in Solution - displays any property value set in the target solution stored in the studio repository. The DA Handling value in the file will be empty, if the import file was exported using an earlier version of the Design Studio, whereby this value was not available.

  • Value in File - displays any property value detected in the export file.

  • Overwrite - users can choose to use any property value in the export file or to use the default setting in the target solution. If the Overwrite setting is used, the user will be prompted to confirm their choice to overwrite properties in the target solution with the values from the export file.

    •  
     

    The DA Null Handling property can be set in the solution Properties window.

The property value cell in the Overwrite column:

  • will be selected by default (indicated by a green tick), if:

    • a property value has been detected in the export file.

    • the export file is being used to create a new solution.

  • will be enabled but set to do not overwrite (indicated by a red cross), if any property values have been detected in the export file, and in the target solution and the property values do not match. Clicking on the cell with the red cross will select the Overwrite option (indicated by a green tick). Any property value in the target solution will be overwritten with the value from the export file.

  • will be disabled (indicated by a red cross which cannot be changed), if:

    • the export file does not have any property value defined.

    • the export file property value matches the value in the target solution.

    • the user does not have permission to overwrite any existing property value.

Comments* (mandatory) - allows the user to type in comments related to the import. The comments can be viewed by other users using the History window.

Label - allows the user to assign an existing or a new label to components being imported.

Import Job summary

The Import Job summary screen is the final screen of the wizard.

When the user clicks Finish, the Import job will be sent to the Job Submission Console for execution.
