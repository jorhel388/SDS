Navigating the User Interface

The software is an architectural framework designed to support a seamlessly integrated suite of business-user applications that share common modules and business definitions.

The software is built in Java and delivers what is known as a rich-client platform; it is easy to install and can be automatically updated. It offers a completely flexible solution structure which solution owners can work within to create unique perspectives for other system users. The software gives the user the ability to:

  • Create Repositories
  • Create Domains
  • Create Solutions
  • Create a Solution structure
  • Edit the Global Data Universe including logical data sources, characteristics and physical definitions
  • Design and create components required to build a solution

The User Interface enables the user to design and build the system.

The User Interface consists of:

The Main menu bar

The Main tool bar

The Main editor

The Explorer area

The Output area

The Palette area

See the Security Help topics for information on the permissions required to perform certain actions.

The user can customise the User Interface view. See the User Interface view options overview help page for more information.

Any changes made in the editor can be undone and redone.
