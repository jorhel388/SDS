Label Management editor

The Label Management editor manages default labels and edition labels within a solution. From this editor, the user can create new labels, edit and delete labels, display the label inventory and compare the contents of two labels. The user can also check out a labelled set of components; merge multiple sets of components under a single label; deploy a labelled set of components (as long as one of the components is deployable); and sanction or reject the pending deployment of a label. The user is also able to identify labels that have been assigned to component(s) located in the Recycle Bin or edition labels that contained some components that have been permanently deleted.

A label that has been successfully deployed (i.e., sanctioned) creates an edition of the original label; it is identified in the editor by the icon. Label editions are also identified by the label suffix applied when the label is deployed.

Only deployed labels can be archived to the repository. Archived labels can be restored from the repository, and will be displayed in the Label Management editor.

To open the editor, select Label Management from the Window menu in the Main menu bar of the user interface.

The Label Management editor consists of:

Label Management editor toolbar with options enabling the user to add, delete and edit labels, archive and restore labels, as well as to display the Label Inventory and to apply a filter to narrow the list of labels in the editor.

Columns:

Label - label name

Status - deployment status (related to editions only) as well as displaying status for labels that contain components that have been recycled or permanently deleted:

  • Pending
  • Sanctioned
  • Archived
  • Rejected
  • Invalid pending/sanctioned/rejected label(s) that contains components that have been moved to the Recycle Bin
  • Pending/sanctioned/rejected label(s) that contains components that have been permanently deleted

Creation date - the date the label was created

Author - the user who created the label

Update date - the date the label was last updated

Update author - the user who last updated the label

Number of Components - the number of components included in this label

Notes - notes included with the label (hover cursor over the notes icon to display the notes)
