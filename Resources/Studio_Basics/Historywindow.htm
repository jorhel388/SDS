History window

Every time a component is checked into the Solution Repository, or a template is saved to the Content Repository, a new version (revision) is added to the history of that item. Each saved version of the component or template is given a revision number.

The History window allows the user to view the history details of a component or template.

The History window can be opened from the Main menu bar, Explorer window or Recycle Bin. It is displayed in the output area of the user interface and if it is closed, it can be reopened at any time. There can be more than one component or template opened at any time in the History window view.

 

If the selected component or template is located in the Recycle Bin, the History window view will be disabled.

The History window can be customised. For example, the user can change the row order, change the column order and remove or add columns from view.

The History window displays the component history information differently for a component and for a template.

Component history tab

From the component history tab the user can:

  • view the history details of the selected component
  • compare different revisions of the component
  • revert the component back to a previous version

 

The Clone source history table is the second table in the History window. It displays the source solution component history and will only be visible when a cloned solution has been selected.
 

If the source solution is deleted, the cloned solution will lose reference to its source content. A message ‘Clone source solution no longer exists’, will be displayed to notify users of the absence of the source solution via the History window and Properties panel (Origin solution path).

The component history tab consists of:

Table Columns

  • From - allows the user to select which revision of the component to perform a comparison from, using the Radio button
  • To - allows the user to select which revision of the component to perform a comparison to, using the Radio button
  • Revision - displays the component revision number at check in
  • Date - displays the date at check in
  • Author - displays the author name at check in
  • Comment - displays the comment at check in
  • Label(s) - displays the label applied to the component at check in, along with any other added labels. For example, Revision 1.0 includes two labels (Baseline Labels; Changes to App data U) separated by a semicolon (;) as shown in the above image.

Toolbar

 

The following options allow the user to compare different revisions of the component either in the Print or Text view. To activate the options, select a different revision of the component in the From and To columns.

Print Comparison - displays the history details of the selected component revisions in the Print Comparison view

Text Comparison - displays the history details of the selected component revisions in the Text Comparison view

Template history tab

From the template history tab the user can view the history details of the selected template and it revision history details.

The template history tab consists of:

Table Columns

  • Revision - displays the template revision number assigned when it was saved
  • Version - displays the template version number assigned when it was saved
  • Date - displays the date and time assigned when the revision was saved
  • Author - displays the author name assigned when the revision was saved
  • Comment - displays the template description added by the user when the revision was saved
    •  

    In the case of a template being renamed, any information displayed in the Comment cell for the latest revision will be replaced by the template's previous and new names. For example, LDS (previous name) -> LDS_2 (new name) as shown in the above image.

    Any information from the Comment cell can be viewed using the <Template name> <revision number> details dialog.

Toolbar

Show revision details - displays in read only the selected template revision history details in the <Template name> <revision number> details dialog.


Customise the History window

The History window displays the history details of the selected component or template.

The History window view can be customised. For example, you can change the row order, change the column order and remove or add columns from view.

Changing the row order

To change the row order in the History window

  1. In the History window, click on the column header for which you want to change the row order. The data will be sorted accordingly to their data types, for example, text, numeric or date. Text data will be ordered in alphabetical order starting at the top.
  2. To reverse the order, click again on the column header.
Changing the column order

To change the column order in the History window

  1. In the History window, drag and drop the required column header to the required column.
Removing or adding columns from view
  The Change Visible Columns button is only visible when the scroll bar on the right of the History window is visible. If it is not shown, make the window smaller by dragging the top of the frame toward the bottom of the screen.

To remove or add columns in the History window

  1. Click on the Change Visible Columns button. The Change Visible Columns dialog is displayed.
  2. Unselect one (or multiple) columns that you want to remove (hide) from the History window view. Only selected columns will be displayed.
  3. Click OK.
  To remove (or add) a column in the History window, right click on any column header and unselect the column name that you want to remove (hide) from view using the context menu.
