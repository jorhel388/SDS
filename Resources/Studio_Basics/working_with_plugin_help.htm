Working with the plugin helpset(s)

When a plugin is imported into the design studio, a helpset for the plugin is installed automatically in the Help Plugins folder of the Design Studio.

Moving the plugin helpset(s)

Users are able to change the location of the helpset(s) via the Tools>Options menu in the Design Studio.

To change the location of the plugin helpset

  1. In the Design Studio, navigate to the Tools>Options menu.
  2. Click Help File. The dialog will show two fields: Help File Root Location and Help Plugins Files Root Location.
    3.   It is important not to change the location of the Help File Root Location as this is the location of the helpset for the Design Studio.
  3. Click Browse next to the Help Plugins Files Root Location field. Navigate to the folder in which you would like to place the help.
    4.   If multiple plugins have been installed into the Design Studio, ensure that all plugin helpsets are in the same file location as only one location can be selected for all plugins.
  4. Locate an empty folder into which you would like to move the plugin helpset.
  5. Click Open.
  6. Click OK.
  7. Restart the Design Studio.

The plugin helpset has been moved to the new location.

  When a plugin helpset is updated, the previous version will be overwritten automatically, so users will be accessing the new helpset from the studio.
 

If a plugin is removed from the studio, the helpset remains in the "Help Plugins" folder of the studio installation folder, from which it can be accessed.
 

If the studio is uninstalled, the plugin helpset may need to be deleted manually due to configurations in the uninstallation process.
