Merge Editor Apply Wizard

The Merge Editor Apply Wizard allows the user to preview the changes before executing the Merge process.

For more information about the Merge process refer to the Merge overview topic.

The Merge Apply Wizard consists of four screens.

Merge options

The Merge options screen is the first screen in the wizard. This screen allows the user to configure the Entity Model mapping and to enable the launch of the Move to Recycle Bin Wizard after the Merge process is complete.

This screen consists of:

Mapping summary area - provides general information about the selected characteristic mappings.

Entity Model mapping area - allows the user to select the target Entity Model to map to the source Entity Model.

Post-merge process area - check box that enables the launch of the Move to Recycle Bin Wizard after the Merge process is complete.

Pre-process

The Pre-process screen provides information about the components that will be modified by the Merge process. It also allows the user to exclude components from the Merge process.

This screen consists of:

Toolbar

The toolbar area contains the following icons:

Expand all - expands the hierarchical tree structure for all the selected items (components or mappings).

Collapse all - collapses the hierarchical tree structure for all the selected items (components or mappings).

Check all - checks the check box for all the selected source components.

Uncheck all - unchecks the check box for all the selected source components.

Invert all - inverts the state of the selected components check box, from checked to unchecked or vice versa.

Export - saves the content of the selected tab as an XML file.

Tabs

Components - displays the components details, such as its name, mappings, status and path. Only checked components will be processed.

Mappings - displays the mappings details, such as its characteristic names, components, status and details.

Log - displays the simulated Merge process log generated by the server.

Confirm

The Confirm screen displays a list of components that will be modified by the Merge process.

Report

The Report screen is the final screen in the wizard and displays the results of the Merge process.

This screen consists:

Toolbar

The toolbar area contains the following icons:

Expand all - expands the hierarchical tree structure for all the selected items (components or mappings).

Collapse all - collapses the hierarchical tree structure for all the selected items (components or mappings).

Export - saves the content of the selected tab as an XML file.

Tabs

Components - displays the modified components details, such as its name, mappings, status and path.

Mappings - displays the mappings details, such as its characteristic names, modified components, status and details.

Log - displays the Merge process log generated by the server with details of the modifications.

For more information on using the wizard refer to the Merge a source characteristic into a target characteristic using manual selection topic.
