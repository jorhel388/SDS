Label Management editor toolbar

The Label Management editor toolbar enables the user to add, delete and edit labels, archive and restore labels, as well as to display the Label Inventory, compare labels and to apply a filter to narrow the list of labels.

Create label - creates a new (empty) label

Delete label - deletes an existing label. This icon is greyed out for editions.

Edit label - edits an existing label (name and notes only). This icon is greyed out for editions.

View components - views the contents and properties of a label in the Label Inventory window

Compare labels - when two labels are selected within the Label Management editor the Compare labels icon will become active. Selecting this icon will open the Label Comparison View where the user can launch either a print or text based comparison of the two versions of the same label.

Archive label - archives the selected deployed labels to the repository. Those labels will be assigned with the Archive label icon , and will be hidden from the Label Management editor (if the Show archived labels checkbox is set as unchecked from the toolbar).

Restore label - restores the archived labels from the repository and displays them in the Label Management editor.

checkbox - when checked will display all the archived labels in the Label Management editor.

Show/hide filter bar - filters the list of labels (filters by name)

Adding an empty label to the editor

Click the Create label button on the toolbar to display the Create label dialog. Provide a label name and (optional) notes. The empty label is added to the editor, and to the shared repository; it can be selected when checking in components, for example.

Deleting a label from the editor

Select a label and click the Delete label button on the toolbar to delete the label. This icon is greyed out for editions.

Editing a label

Select a label and click the Edit label button to display the Edit label dialog. The dialog allows the user to edit the name of the label, and to edit or add notes. This icon is greyed out for editions.

Viewing components

Click the View components button to display the Label Inventory.

Compare Labels

When two labels are selected, click the Compare Labels button to display the Label Comparison View. The Label Comparison View allows users to see, at a summary level, which components have been added/removed/modified across the two labels, and which components have been changed.

Archiving a label from the editor

Select a deployed label(s) , and then click on the Archive label button from the toolbar (or use the context menu). The Archive label... dialog will be displayed. Click on the Yes button to archive the label(s) to the repository. The label(s) will be assigned with the Archive label icon .

  Select the Show archived labels checkbox from the toolbar to display all the archived labels. Archived labels will be displayed with the archive label icon .
 

An archived label cannot be sanctioned, rejected or merged.

Restoring a label from the editor

Select the Show archived labels checkbox to display all the archived labels in the Label Management editor. Select an archived label(s), and then click on the Restore label button (or use the context menu). The Restore label... dialog will be displayed. Click on the Yes button to restore the archived labels from the repository, and display them in the Label Management editor.

Using the label filter

Click on the Show filter bar button to display the filter bar at the bottom of the editor: . The user can limit the number of labels displayed in the editor by typing letters into the content-sensitive filter. For example, typing in the letter "B" will limit the display to those labels whose names begin with B.
