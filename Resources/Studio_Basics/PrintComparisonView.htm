Print Comparison View

The Print Comparison View is opened when the user selects the Print Comparison icon (On-Screen view) when a component has been selected within the Label Comparison View. The Print Comparison View enables the user to view, via a read only display, more information on the changes that have been made.

The Print Comparison View consists of a tool bar and a main area displaying the component details from the components selected by the user in the Label Comparison View.

The Print Comparison View tool bar allows the user to define what is displayed in the main area of the view. The user can choose to show one version or both:

Display only the 'From' version

Display only the 'To' version

Display both versions

The Print Comparison View main area will display both the From and To versions selected by the user in the Label Comparison View by default.

The main area of the Print Comparison View consists of a tool bar and a read only display area.

The main area tool bar allows the user to customise the view in the display area.

Save - saves the output document on the hard drive

Print - prints a hard copy of the output document

First Page - navigates to the first page

Previous Page - navigates to the previous page

Next Page - navigates to the next page

Last Page - navigates to the last page

Go to page - navigates to a chosen page number

Actual Size - zooms the document to its actual size

Fit Page - zooms the document to fit in the preview area

Fit Width - zooms the document to fit the width of the preview area

Zoom In - zooms in the document to the next incremental value (e.g. 50%, 75%, etc.)

Zoom Out - zooms out the document to the next incremental value (e.g. 50%, 75%, etc.)

Zoom Ratio - drop down list allows the user to choose a specific size of the preview

The display area is read only.

At the bottom of the Print Comparison View there is information regarding the component revision being displayed and the Area in which the component sits.
