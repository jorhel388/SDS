Plugins Overview

The Tools>Plugins option allows users to install plugins into the studio.

Once a plugin has been created and certified, in order for it to be used in the design studio, it must be installed using the Plugins dialog.

Plugins Dialog

The Plugins dialog allows users to install plugins into the design studio; update downloaded plugins; view, activate and deactivate installed plugins and change plugin settings.

The Plugins dialog consists of the following tabs:

Updates - Use this tab to check for updates to installed plugins.

Available Plugins - Use this tab to check for and install available plugins.

Downloaded - Use this tab to install downloaded plugins.

Installed - Use this tab to view, activate and deactivate installed plugins.

Settings - Use this tab to view and change settings for all plugins.

Install a Plugin

Use the Downloaded tab of the Plugins dialog to install a plugin into the studio.

To Install a plugin

  1. Open the Plugins dialog by selecting Tools>Plugins from the main menu bar.
  2. Select the Downloaded tab.
  3. Click Add Plugins...
  4. Use the Windows explorer dialog to locate the plugin(s) you want to install.
    5.   Only .nbm files can be installed.
  5. Click OK.
  6. The selected plugins appear on the left side of the Plugins dialog.
  7. Select the plugins to be installed and click Install.
  8. The Plugin Installer wizard appears.
  9. On the Installer wizard Welcome screen, verify that the plugin(s) you want to install are listed. Click Next to proceed or Back to return to the Plugins dialog.
  10. The second screen of the wizard is the License Agreement.
  11. Check the "I accept the terms in all of the license agreements" selection box. The Install button will become available.
  12. Click Install to proceed.
  13. The Validate screen appears. The progress bar indicates when validation is complete.
  14. If you are installing an unsigned plugin(s), the Validation Warning screen appears. To proceed with the installation, click Continue.
  15. Once validation is complete, the Installation completed successfully screen appears and lists the plugins that have been installed.
  16. Click Finish to close the wizard.
  17. Restart the studio.
