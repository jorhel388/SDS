Working with Byte Array Physical Data Models

Toolbar

The Byte Array Physical Data Model editor's tool bar is used to alter the contents of the Physical Data Model.

Recalculates Offsets - recalculates the offsets for each characteristic in the data model and amends it as required.

Recalculates Lengths - reapplies the default style sheet just on the physical length column and recalculates the lengths of each characteristic in the data model and amends them as required.

Recalculates Lengths and Offsets - reapplies the default style sheet on the physical length column and then recalculates the offsets for each characteristic and amends the model as required.

Apply default style sheet - the settings defined in the default style sheet will be applied to this interface, overwriting/amending previous settings.

Synchronise Physical Data Model - when the Physical Data Model no longer matches the Logical Data Source or Logical Data Model from which it was created, selecting the Synchronize Physical Data Model on the tool bar will bring the model back into line.

Create

A Byte Array Physical Data Model can be created from the Explorer window from either a Logical Data Model or Logical Data Source.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.
  Byte Array Physical Data Models do not support dynamic data - so all arrays in the Logical Data Source must be defined with fixed lengths.

To create a byte array physical data model

  1. From the Explorer window, right click on the name of the Logical Data Model or Logical Data Source and select Add PDM followed by Byte Array.
  2. In the Create component dialog, enter the name of the Byte Array Physical Data Model.
  3. Select the Open new components in component editor checkbox.
  4. Click OK.
    The Physical Data Model editor - Byte Array will open allowing you to amend the model as required.
    The Byte Array Physical Data Model name will be listed in the Explorer under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the checkbox de-selected. From the Explorer Window, right click on the Byte Array Physical Data Model and select Open.

Edit

When a Physical Data Model for a Byte Array is created, the system automatically selects the data formats that have been defined in the Byte Array Style Sheet and automatically generates the physical names for each characteristic using the logical name for the characteristic. The user can modify the specific detail of a Physical Data Model if required.

To edit a Byte Array Physical Data Model

  1. With the Physical Data Model for a Byte Array open you can alter the specific detail for the data model.

    To change the Physical Data type for the characteristic

  2. Select the characteristic you require, then in the Physical Type column, from the drop down list select the type you require.

    For more information on the individual numeric types (integer, float, decimal) see the topic Numeric Physical Data Types for more information on the individual string types see the topic String Physical Data Types .

    To recalculate the offsets for all the characteristics

  3. Click on the following icon

    To recalculate the length of all the characteristics

  4. Click on the following icon

    To recalculate the length and offset for all characteristics

  5. Click on the following icon

    To change the order of a characteristic

  6. Select the row number of the characteristic you wish to move.
    A green arrow will be displayed . Drag and drop this to the position you require in the model.

The Physical Data Model can now be validated.

Validate

Validate checks the Byte Array Physical Data Model to ensure that it matches the Logical Data Model or Logical Data Source that it references. Valid means the component is complete, that each logical characteristic in the Logical Data Model is mapped appropriately to a physical characteristic.

To validate a Byte Array Physical Data Model

  1. With the Byte Array Physical Data Model editor open, click on the Validate icon
  2. The system will check the validity of the Physical Data Model and display information on areas of the Physical Data Model that are invalid in the Validation Results window.
  3. The Description column contains details of the validation.

To fix the model, the user could reapply the default settings, select Synchronise or continue editing the Physical Data Model.
