Physical Data Types

String

When creating a byte array physical data model, the correct format must be selected for the data. Should the user not know what string format is required then the user can assign "Dynamic" as the format type. The format type for this field will need to be defined at runtime in the Decision Agent properties file.

The following string data format types are supported:

  • String Byte Character Encodings (ASCII)
  • Single Byte Character Encodings (EBCDIC)
  • Multi Byte Character Encodings (Unicode)
  • Double Byte Character Encodings
