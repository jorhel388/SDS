Boolean Expressions

A Boolean Expression is a condition that can be evaluated and will either be true or false. It may range in complexity from a simple condition involving a single characteristic to complex compounded conditions involving multiple characteristics. The boolean expression is used in a range of other components, for example process flows, scorecards, segmentation trees and report filters.

It is not possible to assign values using a boolean expression. For example, the value of a characteristic can not be changed as a result of executing a boolean expression.

Overview

Boolean expressions can be referenced within other boolean expressions.

The boolean expression is defined using the standard scripting editor, but without the If ... Then .. Else and other conditional templates provided (Operators and functions).

The script editor displays characteristic names, operators, command verbs, etc., in different colours.

The script editor has basic text manipulation such as selecting blocks of text to cut, copy, paste and delete.

As the script must follow certain syntax rules there is an option to check the syntax of the script. For guidelines on some of the script syntax rules see Guidelines on script syntax.

The script syntax must be valid before any testing can be carried out.

Edit

Editing a script involves entering the script content using the correct language and according to the correct syntax and grammar. Scripts can be edited, compiled and tested in a script editor.

See the topic Operators and functions for details of the operators, functions and statements that can be used in the script editor.

Boolean expressions consist of a rule/condition that returns "true" if the condition is met, or "false" if the condition is not met.

Create a boolean expression

A boolean expression can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a boolean expression

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Boolean Expression.
  3. In the Create component dialog enter the name of the boolean expression component.
  4. If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor tick box is selected.
  5. Click on the OK button.

    The Boolean Expression editor will open allowing you to script, compile and test the boolean expression.
    The boolean expression name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, de-select the tick box. From the Explorer window select the boolean expression and select Open.

  Boolean expressions can be created as embedded components from within other components for example scorecards or segmentation trees.

Define a Boolean Expression condition

A Boolean Expression is defined by a script, using operators, functions, characteristics and values/constants.

To define a Boolean Expression condition

  1. With the Boolean Expression editor open, add script freehand or use the required resources from the Palette and Resources window to create your Boolean Expression condition. For more information on using Segmentation functions see Adding Segmentation Functions to script.
    2.   Index Tables are not supported in Boolean Expressions.
  1. Click on the Compile icon in the tool bar to check the script syntax.

The system will provide you with information regarding the validity of the script. Details of any errors will be displayed to provide you with information so that you can correct them.

  You cannot test a boolean expression using Tester unless the script is valid.

The boolean expression will be ready for use within another component.

Related Topics

Test

Once the user has successfully created a boolean expression, the user will be able to test it using the Batch or Interactive Tester.

The user can test a boolean expression either by manually typing in data for the input characteristics referenced in the boolean expression or by performing a test against a known data source.

To perform an interactive test

To test a boolean expression manually by entering data into the relevant fields for the input characteristics, use the Interactive Tester.

To perform a batch test

To test a boolean expression using data from a .csv file, from the Explorer window, right click on the component and select New Test Project to use the Batch Tester.
