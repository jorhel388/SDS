Mappings Required

The output from each process must be mapped to specific characteristics in the Logical Data Source if results need to be returned. The type of process added affects the mappings required since at runtime each process will generate different values. When a process is added to a Process node one or more results Logical Data Models for that process will be created. The user then, if required, selects the most appropriate Logical Data Model for their requirements.

  The above mappings are available for all users. Additional mappings may be available depending upon access rights and plugins installed. For example, ACE plugins may introduce additional mappings.

The output from a Junction node can also be mapped to specific characteristics in the Logical Data Source if results need to be returned. The type of segmentation rule applied to a Junction node will affect the mappings required. When a segmentation rule is added to a junction node a results Logical Data Model for that segmentation rule will be created.
