Create performance profiles in Test Project

Test Project enables a unique feature when executing a test of a Decision Process Flow: the ability to create a set of performance profiles for test project scenarios, for ongoing monitoring and comparison. The performance profile includes the time taken to run the test data through the flow, and what percentage of the total time was taken to run through each process in the flow.

To create performance profiles

  1. Right click on the Decision Process Flow for which you want to create performance profiles, and select New Test Project.
  2. The Test Project editor opens; the editor includes the Profile options, which are available only when testing a Decision Process Flow:

  3. Click the Profile radio button, and enter a value for the number of times to execute each record during the warm up phase. The default value is 1. This will ensure that all objects and components used by the strategy you are profiling will have been executed at least once.
  4. Enter a value for the number of times to execute each record during the profiler phase. The default value is 1. The profiled records will be multiplied by the number entered. This will increase the size of your data file to a more representative sample of your live environment.
  5. Continue to run the Test Project as described in the Test Project help set.
  6. When the Test Project is executed, the Profile report is displayed in the Profile tab:

A link to the Profile file (DAprofile.txt) is displayed at the top of the tab window; click on the link to open the Profile text file in a new window.
