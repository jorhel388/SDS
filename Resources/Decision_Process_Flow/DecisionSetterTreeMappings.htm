Decision Setter Tree Mappings

The Decision Setter tree is a segmentation tree with an additional column. This column enables specific decision setter components to be attached to the leaf nodes/outcomes of the Decision Setter tree.

To ensure that results will be returned when this process is executed, the Component Tree, and either the Decision Setter minimum results, or the Decision Setter typical results logical data model needs to be added to a logical data source, depending on the user's requirements.
Should Test Group Set data need to be returned as well, then the Test Group Set results logical data model needs to be added to a logical data source too.

The following logical data models are created when a Decision Setter Tree process is attached to a process node.
