Change a process icon

The images used by components that have been assigned to processes can be changed. This enables the user to customize how the Decision Process Flow appears to the end user.

  You will only be able to change the image of a node that is fully configured.

To change the image used by a process

  1. With the Decision Process Flow editor open, select the process node for which another image is required.
  2. In the Properties window, scroll to the bottom and within the Visualisation Properties area, next to Image click on the button.
    The system will open a standard file chooser dialog.
  3. Locate the image you require and click the Open button.

The screen will close and the image you have selected will be applied to the process.

To reset the image used by a process

  1. With the Decision Process Flow editor open, select the process node whose image needs resetting.
  2. In the Properties window, scroll to the bottom and within the Visualisation Properties area, next to Image click on the button.
    The system will open a standard file chooser dialog.
  3. Click the Reset button.

The screen will close and the original image will be reassigned back to the process.

  The system will warn you if the image selected is bigger than 100 pixels x 100 pixels.
The large image can still be selected if required.
