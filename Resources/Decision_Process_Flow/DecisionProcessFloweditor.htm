Decision Process Flow editor

The Decision Process Flow editor enables the user to define the Decision Process Flow to be executed at runtime.

The Decision Process Flow editor consists of:

  • Decision Process Flow tool bar with options designed to assist the user in editing the Decision Process Flow.
  • Decision Process Flow definition area.

The Decision Process Flow editor is used to define the Decision Process Flow that will process the record at runtime.

The Decision Process Flow is made up of the following:

Toolbar

The Decision Process Flow tool bar is designed to assist the user in editing the Decision Process Flow.

Test - launches the tester for the Decision Process Flow

Copy component image to clipboard - select to copy the complete flow contained in the editor as an image to the clipboard from where you can paste this image into any appropriate application.

Zoom in and Zoom out - select to enlarge or reduce the size of the image seen in the editor

Zoom To Fit - resizes the image to fit the editor the user has open

Zoom Reset - resizes the image back to how it was displayed when the editor was first opened

Delete all selected nodes - removes all the selected objects from the image

Show Grid - the editor will display a grid which will help the user to align an image

Snap to Grid - when selected the editor will align an object the user is placing on the panel in line with the grid

Align Middle - will align all objects using the horizontal middle point for alignment

Align Vertical - will align all objects vertical middle point for alignment

Default Vertical - will re-align all the objects using the default alignment setting of the editor

Show all node annotation - will display any annotations that the user has applied

Hide all node annotations - will hide any annotations that the user has applied

Flow Data Capture - toggling this icon on will force transaction data to be collected for the whole Decision Process Flow for those processes/junctions that are able to capture data. To switch data capture off for the whole Decision Process Flow, toggle the icon off .
The data capture for each individual node can also be controlled using the Process Data Capture option available from the context menu accessed from the process node or junction.

Start Node - the point in the Decision Process Flow where processing starts. A Decision Process Flow must always have a start node.

Process Node - a point in the flow where no processes have been applied.

Junction Node - points in the Decision Process Flow where pathways can be defined. When a record is processed through a junction that has had a segmentation device such as a class set, boolean expression, matrix or segmentation tree applied to it, the junction is used to direct the record to the next relevant decision process depending on which pathway is triggered.

End Node - the point in the Decision Process Flow where processing ends. A Decision Process Flow must have one or more end nodes.

The process and junction nodes have three levels of configuration that help the user know the current definition state of the process node and/or the junction node. Using these the user can sketch, draw and paint their Decision Process Flow:

Sketch

- depicts a process node that has been added to the flow, but no processes have been assigned to it. Any process type can be applied to a sketch node.

- depicts a junction node has been added to the flow, but no segmentation devices have been assigned to it.

Draw

- depicts a process node that has had a process type assigned to it. Only processes of type can be applied to a process that is in draw mode.

- depicts a junction node that has had a segmentation device assigned to it.

Paint

- depicts that a fully defined process has been assigned to the process node.

- depicts that a fully defined segmentation device has been assigned to the junction node. When the junction node is fully configured, pathways will be displayed, graphically illustrating to the user all the possible outcomes produced by the segmentation device that has been assigned to the junction node.
