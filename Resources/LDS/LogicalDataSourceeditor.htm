Logical Data Source editor

The Logical Data Source editor enables the user to create groups of characteristics for use by other components.

The Logical Data Source editor consists of a set of fields which are used to define the properties of the characteristic.

Characteristic properties

Each characteristic has certain properties defined by the user when it is created. These properties consist of:

Name

Unique alphanumeric name

Type

String, Integer, Float, Decimal, Date, Semi Structured Data Definition, Embedded or referenced Logical Data Model Name(s)

Length

The number of digits or characters the field can hold (NB, this includes any decimal component).

Scale

The number of decimal places required

Array Size

The number of times a characteristic appears in an array.
If the characteristic is not an array this is set to 0.
