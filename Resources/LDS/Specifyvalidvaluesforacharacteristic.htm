Specify valid values for a characteristic

The user can assign a list of valid values to a logical characteristic. For example, the user can specify that a valid numeric characteristic can only be one of the following: 1, 3, 5, 7, 9; or that an alpha characteristic be one of the following: B, U, X, A, C.

To specify valid values for a characteristic

  1. With the Logical Data Source editor open, right click on a characteristic and select Show Details to display the Valid Values editor.
  2. Right click in the editor and select Add Row.
  3. Enter the first valid value in the Value column. Integer characteristic types will accept only numeric values, string characteristic types will accept either numeric or alpha values. The number of characters in the Value field can not exceed the length specified for the characteristic in the logical data source editor.
  4. Enter a name to identify the value in the Name column.
  5. Repeat steps 2, 3 and 4 until all valid values for the characteristic have been entered.

Click on the Save icon in the main tool bar to save the value assignments to the Logical Data Source.
