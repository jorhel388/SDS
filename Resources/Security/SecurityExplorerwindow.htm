Security Explorer window

The Security Explorer window allows a user to assign the Security Administrator Profile for viewing and managing:

  • security permissions and settings located in the Security Control Centre folder
  • entities located in the Units, Users, Groups, Security Profiles and Functional Roles folders.
 

A user with the Security Administrator Profile that has been assigned to a unit will have the same rights as a sysadmin. However, this user:

  • will only be able to view and manage entities (users, groups, security profiles, functional roles or domains) that have been assigned to the same unit as the user
  • will not be able to create or remove units
  • will only be able to edit the unit description.
 

A user with the Security Administrator Profile will not be able to create, modify or delete components.

When a user with the Security Administrator Profile has logged into the software, the Security Explorer window is displayed in the Explorer area of the user interface. It can also be initiated from the Main menu bar.

The Security Explorer window consists of the following folders:

  • Security Control Centre - configure the global security settings, observe and manage users' activities
  • Functional Roles - create and manage functional roles
  • Security Profiles - create and manage security profiles
  • Users - create and mange users
  • Groups - create and manage groups
  • Units - create and manage units.
 

A user without the Security Administrator profile assigned can open the My Profile editor located in the Security Explorer window from the Window option in the Main menu of the software. The user can view specific details about their account (read only) and Change the password.

 

The user can also open the Audit Trails editor located in the Security Explorer window. The user can view Audit Trails of their own activities with the option to filter for a date and time period.
To open an item in the Security Explorer window
  1. In the Security Explorer window, .
    • For users with Security Administrator Profile - Expand the required folder (Security Control Centre, Functional Roles, Security Profiles, Users and Groups) by clicking on the icon.
    • For users that do not have the Security Administrator Profile assigned - Select either My Profile or Audit Trails.
  2. Right click on the required item and select Open.
  3. The appropriate editor will be initiated and will be displayed in the Main editor area of the user interface.

You may now view or edit the selected security item.

  You can also open an item from the Security Explorer window by double-clicking on it.
Refresh the Security Explorer window

To display the changes to the content of the Security Explorer window refresh the view.

To refresh the Security Explorer window

  1. In the Security Explorer window, right click on any folder.
  2. Select Refresh.

The window will refresh.
