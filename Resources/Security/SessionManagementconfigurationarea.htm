Session Management configuration editor

The Session Management editor allows the user to manage session settings and to close any unnecessary user sessions. The editor can be found in the Security Control Centre folder from the Security Explorer window.

  Only users with the Security Administrator Profile will have access to the edit functions in the Security Explorer window.

The Session Management editor consists of the following tabs:

General

The General tab consists of the following:

  • Login enabled (default setting)- allows the user to disable the login option.
    •  

    If the Login option is disabled, no other users will be able to access the software. Only the sysadmin user will be able to log in.
  • Maximum concurrent sessions - allows the user to set the maximum number of concurrent sessions.
    •  

    The maximum number of users can be set to a positive integer if required or left at zero to allow unlimited concurrent sessions.
Sessions

The Sessions tab consists of the following:

Sessions - displays information relating to the current users and their sessions in the table columns, and allows the user to close any unnecessary user sessions using actions in the toolbar.

Toolbar:

  • Refresh - refresh the current view
  • Kill - close the selected user session
  • Kill & Refresh - close the selected user session and refresh the current view.

The latest refresh details (date and time) are displayed on the right of the toolbar.

Table columns:.

  • Select - allows the user to select which session to close
  • Session ID - displays the session ID.
  • Owner - displays the session user name.
  • Initiator - displays the initiator of the corresponding session. The initiator is the user who has started the session. Normally this field will contain a '-' (hyphen). However, this field will contain details when the session has been assigned to a job. In this case, the initiator is a special account named, for example, jsf-account. It initiates the session and impersonates as the job submitter.
  • Login Time - displays the session login date and time.
  When the Manage eviction of session checkbox has been selected in the Session Management area of the Global Security Settings editor, users will be able to kill their own active sessions should they need to.
