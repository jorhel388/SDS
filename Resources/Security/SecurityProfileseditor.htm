Security Profiles editor

The Security Profiles editor allows the system administrator (sysadmin) or a user assigned the Security Administrator Profile to view and manage security profile accounts. The editor is opened from the Security Profiles folder in the Security Explorer window. To open the editor, right click on a security profile account and select Open.

The Security Profiles editor consists of the following areas:

  • Profile Name - displays the security profile account name (read only)
  • Description - can be used for additional security profile information
  • Unit - displays the unit assigned to the security profile account (for example, France) or an empty value if the security profile has not been assigned to a unit
    •  

    The Unit drop down list is only available to the system administrator (sysadmin) or a user with the Security Administrator Profile that has not been assigned to a unit.

    A user with the Security Administrator Profile that has been assigned to a unit will only see a read only value.
     

    A security profile account that has been created by a user with the Security Administrator Profile and assigned to a unit will automatically inherit the unit that has been assigned to the user.
  • Profile Definition - displays table columns and allows the user to edit or configure a security profile (functional roles and access permissions). Each table column corresponds to the business scope or a functional role, while each row corresponds to a set of access permissions. The whole table defines the required security profile. The Profile Definition area consists of the following table columns and access permission icons:
    • Explorer - depending on the user security profile specific domains (including their content) located in the local repositories will be displayed.
      •  

      A user with the Security Administrator Profile that has been assigned to a unit can only view domains in the local repositories that have been assigned to the same unit as the user.
    • Business Scope - displays nodes in the repository that have permission applied and whether this node will be seen in the Explorer window
    • <Functional role account name> - displays the functional role account(s) that has been added to the security profile (drag and drop from the Palette window).

      • Shown below are the different access permission icons:

      No Access - the user will have no access to the corresponding node and any folders or components within it (unless specified directly). The repository or folders within will not be visible to the user in the Explorer window.
      Controlled Access - the user will have controlled access to the corresponding node and any folders and components within it (unless specified directly). The repository or folders within will be visible to the user in the Explorer window.
      Permissions not assigned here - the user will have no access to the corresponding node and any folders or components within (unless specified directly). The role is not applied.
      Permissions assigned here - the user will have full access to the corresponding node and any folders or components within (unless specified directly). The role is applied.
      Various permissions assigned below - the user will have partial access to the corresponding node and any folders or components within (unless specified directly) i.e., the user will have access to this area only to gain access to another one. Read permission is inherited.
