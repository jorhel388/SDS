Solution Administrator functional role

The functional role of Solution Administrator is predefined and the account can be found in the Functional Roles folder within the Security Explorer window. The pre-defined rights for this role cannot be changed.

Please see the Functional Roles Permissions help topic for further information on the permissions assigned to this role.

The Solution Administrator functional role can be merged with other functional roles in a security profile.

The Solution Administrator role enables a user, within all repositories, to import an exported solution and individual components and delete imported solutions and components, if required, from these repositories. Within the Solution repository they can also unlock components locked by other users. Within the Content and Reporting repositories only the Solution Administrator can create, update, delete, copy and paste solutions, domains and folders.
