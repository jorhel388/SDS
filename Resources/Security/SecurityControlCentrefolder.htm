Security Control Centre folder

The Security Control Centre folder allows the System Administrator to configure the global security settings, observe and manage users' activities. It is located in the Security Explorer window.

  Only users with the Security Administrator Profile will have access to the edit functions in the Security Explorer window.

The Security Control Centre folder consists of the following:

  • Global Security Settings - configure the global security settings
  • Session Management - manage the session settings and to close any unnecessary user sessions
  • Audit Trails - monitor users' activities.
 

Global security permissions and settings defined within the Security Explorer window can be exported using the Export Security Repository functionality. This functionality has been implemented to be used only within the Experian cloud deployment platform.

Export Security Repository

The Export Security Repository functionality allows users with administration rights to export their global security permissions and settings in an .xml file. The exported .xml file is used for repository provisioning management within the Experian cloud deployment platform.

To export a security repository
  1. From the Security Explorer window, right click on the Security Control Centre and select Export Security Repository.
  2. Click OK in the Remote Job Notification dialog.
  3. In the Job Submission Console:
    1. Click on the row named Security Export Job to display the Output files area.
    2. Right click on the export .xml file and select Save selected file.
  4. In the Save window:
    1. Navigate to the specific destination where the export file will be saved.
      2.   $USECASENAME$_security_<date>.xml is the default export file name, whereby <date> is represented as yyyyMMdd-HHmm.
    2. Type in a meaningful name to replace $USECASENAME$ in the File Name: field.
    3. Click Save.

The exported .xml file can now be used for repository provisioning management.
