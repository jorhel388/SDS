Global Security Settings configuration area

The Global Security Settings area allows the user to configure the global security settings, such as setting the user name lengths, maximum login retry attempts, password strength, password change period and/or external LDAP mapping.

  Only users with the Security Administrator Profile will have access to the edit functions in the Security Explorer window.
 

Any changes made to a global user setting will only affect users that are created after the changes are applied. The changes will not affect already existing user accounts.

Any changes made to the Login settings or to the Password settings (except the default password change period) will also affect current users. This will come into effect the next time they are prompted to change their passwords from the login dialog.

The Global Security Settings editor consists of the following areas:

  • My Permissions- set a minimum and maximum user name length for all users
  • Login Settings - set a maximum login retry attempts for all users
  • Password Strength Settings - configure password settings for all users. The user can also specify the password to be different from the user name.
  • Password Change - set the default password change period and the password retention number. The password retention number prevents users from reusing previously used passwords. The number specified is the number of passwords that will be stored.
  • External Settings - change the LDAP mapping attribute using the drop down list
  • Security Principles
    •  

    For security reasons, it is not recommended to apply the soft separation of duties. The Open Web Application Security Project (OWASP) provides guidance on common security principles of separation of duties and least privilege. For more information, refer to the following resources:

    • https://www.owasp.org/index.php/Least_privilege
    • https://www.owasp.org/index.php/Separation_of_duties
    • https://www.pcisecuritystandards.org/documents/PCI_DSS_v3-2-1.pdf (see the Implement Strong Access Control Measures section)
    • Unchecked (default setting) - for backward compatibility and security reasons. The Security Administrator profile will take precedence over any other profiles assigned. Any privileges granted through other profiles will be ignored.
    • Checked (optional) - allows both Security Administrator and non-security profiles to be used in the same user account. For more information on this functionality, refer to Appendix B: Security Principles in the Security Administrator Getting Started Guide.
  • Session Management - determines whether all users can kill their active session. When the Manage eviction of sessions checkbox is selected, all users will be able to kill their active sessions without needing a user with Security Administrator access rights to carry this out for them.

  • Authorisation for Externally Authenticated Users - When users log into the PowerCurve Studios using external authentication, access permissions are controlled by the following methods:

    • Delegated to the External Identity Provider – User access is controlled entirely by their membership to groups of the external identity provider.

      • When this option is selected, additional security profiles and groups are not permitted on the user's account. Access is controlled entirely by security profiles in the groups used for external authentication.

    • Managed Internally by the Studio – User access is controlled entirely by their membership to internal studio groups.

      • When this option is selected, security profiles in the groups used for external authentication will be ignored and access is controlled entirely by groups and security profiles on the user's account.

    • A System Administrator can configure Authorisation for Externally Authenticated Users settings within the Global Security Settings. The selected option will apply to all users who log into the PowerCurve studio using external authentication.
