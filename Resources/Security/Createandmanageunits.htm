Create and manage units

This topic provides information on how to create and manage units located in the Security Explorer window.

 

A user with the Security Administrator Profile that has been assigned to a unit will have the same rights as a sysadmin. However, the user:

  • will only be able to view and manage entities (users, groups, security profiles, functional roles or domains) that have been assigned to the same unit as the user
  • will not be able to create or remove units
  • will only be able to edit the unit description.
To create a unit account in the Units folder
  1. From the Security Explorer window, right click on the Unit folder and select Add New.
  2. In the Create unit dialog, enter the unit name.
  3. Click OK.

The unit account has been created in the Units folder.

To add a description to a unit account
  1. From the Security Explorer window, right click (or double click) on the unit account that you want to edit and select Open.
  2. In the Unit editor, enter the unit description.
  3. Click the Save button located in the main menu bar (or Ctrl+S).

The description has been added to the unit account.

To remove a unit account from the Units folder
  1. From the Security Explorer window, right click on the unit account that you want to remove and select Delete.
  2. In the Confirm Object Deletion dialog, click Yes.
    3.  

    When deleting a unit, if the selected unit has been assigned to any entities (users, groups, security profiles, functional roles or domains), a warning will be displayed.

    The warning informs the user that the unit is already in use. To delete the unit, the user must first remove it from all entities that have been assigned to it (using the corresponding entity editor). Entities that are assigned to the selected unit are displayed in the Output window.

    In the case where multiple units are deleted at once, units that are not assigned to any entities will be removed. Otherwise, a warning will be displayed.

The unit account has been removed from the Units folder.

To assign a unit to an entity (user, group, functional role or security profile) in the Security Explorer window
  1. From the Security Explorer window, double click on an entity folder (for example, the User folder) to expand the entity account list.
  2. Right click on the entity account that you want to assign to a unit, and then select Open.
  3. In the entity editor, select the required unit name using the Unit drop down list.
    4.  

    To remove a unit that has been assigned to an entity, select the empty value using the Unit drop down list.
  4. Click the Save button located in the main menu bar (or Ctrl+S).

The entity (for example, User) has been assigned to the selected unit. To assign a unit to other entities, repeat steps 1 to 4.
