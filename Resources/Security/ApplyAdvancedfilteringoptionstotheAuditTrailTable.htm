Apply Advanced filtering options to the Audit Trail Table

The Audit Trails editor is an area in the Security Explorer window where a user can view user activity in the Audit Trails Table.

  Only users with Security Administrator Profile assigned will have access to the Audit Trails editor.

The user has the ability to apply advanced filter options to the Audit Trails Table.

The Audit Trails editor is an area in the Security Explorer window where a user can view user activity for a filtered date and time period. A user can also specify advanced filtering options to an audit trail from within the editor.

The user can initiate the Audit Trails editor from the Security Explorer window.

Only users with Security Administrator Profile assigned will have access to the Audit Trails editor.

To initiate the Audit Trails editor from the Security Explorer window

  1. In the Security Explorer window and in the Security Control Centre folder, right click on Audit Trails and select Open.

The Audit Trails editor will open in the main editor area of the user interface.

To Apply advanced filter options to the Audit Trails Table

  1. In the advanced filtering options area and in the Design Studio section, highlight the required studios. To highlight multiple studios, hold down the Ctrl button whilst selecting.
  2. In the Category section, highlight the required categories. To highlight multiple categories, hold down the Ctrl button whilst selecting.
  3. In the Event Type section, highlight the required event types. To highlight multiple event types, hold down the Ctrl button whilst selecting.
  4. Apply a Filter Period to the Audit Trails Table.
  5. Click on the Apply Filter button in the Filter Period area.

The filtered data will display in the Audit Trails Table.

The user can reset the filter at any time by clicking on the Reset Filter button in the Filter Period area.

  If there are no selections made in the Advanced filtering options area, the Audit Trails Table will display all audit detail using the Filter Period filter only.
