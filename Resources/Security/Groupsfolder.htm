Groups folder

The Groups folder is located in the Security Explorer window. It stores and displays any groups that have been set up. Groups simplify the role of the system administrator by enabling multi-use of functional roles and security profiles. Once a set of profiles have been assigned to a group to which a number of users have been added, the system administrator only needs to change the group rather than each separate user to make a change to each user. Once a group has been set up, users can be added to it.

 

A user with the Security Administrator Profile that has been assigned to a unit will have the same rights as a sysadmin. However, the user:

  • will only be able to view and manage entities (users, groups, security profiles, functional roles or domains) that have been assigned to the same unit as the user
  • will not be able to create or remove units
  • will only be able to edit the unit description.

Group accounts are stored within the Groups folder and are displayed with a group icon alongside each group account name.

A user assigned the Security Administrator Profile can:

  • add a group
  • view and edit groups
  • add a user to a group
  • assign a unit to a group
  • add a security profile to a group
  • delete a group from the Groups folder
  • match external groups from an active directory to internal groups to enable the single sign-on function.
