Users folder

Anyone who wishes to use the system is referred to as a user. All users must have a user account. Once a user account has been created, it will be displayed in the Users folder within the Security Explorer window.

 

A user with the Security Administrator Profile that has been assigned to a unit will have the same rights as a sysadmin. However, this user:

  • will only be able to view and manage entities (users, groups, security profiles, functional roles or domains) that have been assigned to the same unit as the user
  • will not be able to create or remove units
  • will only be able to edit the unit description.

User accounts are stored in the Users folder and are displayed with a user icon alongside each user account name. A locked user account will be displayed with the following icon , refer to the lock or unlock a user account topic for more information.

 

When a user has been authenticated through an external mapping (NTLM or LDAP), a user will be automatically created in the Users folder. This user will have reduced customisation options when compared to a manually created user.
 

When a user with external LDAP credentials logs into the studio for the first time, a new internal user account will be created automatically.

The internal user account will be displayed in the Users folder (for example, <LDAP server name> /<User Name>). The internal user account will inherit the unit assigned to the internal group that has been mapped to the LDAP group to which the LDAP user belongs. The unit assigned to the user is displayed in the User editor as read only. Since the unit assigned to the user has been inherited from the internal group, any saved changes (for example, reassigned to another unit or removed the assigned unit) made to the unit in the Group editor will be automatically inherited by the user account. The change will take effect the next time the LDAP user logs in.
 

NTLM - stands for NT LAN Manager. The NTLM authentication mode allows for authenticating users by using their Windows user accounts, without the need to specify a username and password. NTLM mode is used to facilitate the Single-Sign-On experience in the Decision Analytics Server environment.
 

LDAP - stands for Lightweight Directory Access Protocol, which is a protocol for communicating with directory servers such as Active Directory or OpenLDAP. The LDAP authentication mode allows for authenticating with the external user directory instead of the built-in security repository.

The following user accounts are predefined:

  • jsf-system - this user account is only permitted to carry out deployment work in the Job Submission Framework. The credentials of this user account enforce the security of the Job Submission Framework usage.
  • sysadmin - this is the system administrator user account that has been assigned the Security Administrator Profile. The sysadmin user is only permitted to edit the security settings of other users.

A user assigned the Security Administrator Profile can:

  • add a user or remove a user
  • set user password
  • close a user session from within the Users folder or within Session Management
  • edit the user details, such as the full name, email address and user information
  • assign, edit or remove a unit from a user
  • assign security profiles to a user and group accounts
  • configure users password expiry, account expiry and account status
  • match external users from an active directory to internal users to enable the Single Sign-On function.
