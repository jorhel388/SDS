Working with a solution

The studio is made up a number of features that enable the user to work with a solution, distribute it for use by others and to deploy it for execution at runtime.

The Job Submission Console is used to display the status and history of batch process jobs, that have been submitted or scheduled for execution. Job tasks that are submitted to the Job Submission Console include jobs created by:

  • Test Project (for batch testing)
  • Batch Process
  • Export/Import
  • Content management
  • Label deployment

Batch Process Flow - is a series of server side batch processes that are executed sequentially at runtime. Using the Batch Process Flow editor the user to define the Batch Process Flow and then submit the batch processing job for immediate execution or schedule the job for execution at a specified time. A wizard is used to capture any runtime options for each process in the flow.

Label Management - allows the user to define and tag a set of components that can then be acted upon as a group rather than individually. The label can be used to access the component set from the shared repository for export, check out, printing, deployment, etc. It is also used for versioning, to stamp a label onto a set of components or revisions to record the fact that they have been subjected to a specific action. Labels can be deployed repeatedly; different deployments are treated as different editions of the original label.

Deployment - the process of producing a file that contains all the components that need to be executed at runtime. This single deployment file is assigned a Label. It is this Label that is selected for deployment.

Content Management - enables users to create templates (generic reusable content) that can be distributed to other users and can be used for other projects.

Undo - allows the user to undo modifications made in the editor by clicking on the icon in the Main toolbar. The redo option is activated after the first undo action is performed.

Deleting - using a two step process the user can delete any component from the solution and also restore components that are in the Recycle Bin if required.

Printing - enables the user to produce printable documents for those components to which they have access.
