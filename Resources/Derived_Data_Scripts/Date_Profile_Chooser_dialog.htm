Date Profile Chooser dialog

The Date Profile Chooser dialog allows the user to select which Date Calculation Profile to use with either the DATEPDIFF or DATEPADD function.

There are two system profiles:

  • PowerCurve Standard Profile - existing Java based profile
  • SQL Server Standard Profile - counts the date boundaries
    •  

    For example, using the DATEPDIFF function, where:

    • startDate = DD/MM/YYYY
    • endDate = DD/MM/YYYY(04/09/2019)
    • datePeriod = DAYS, MONTHS or YEARS
    • calculationProfile = PowerCurve Standard Profile or SQL Server Standard Profile

    PowerCurve Standard Profile - 04/12/1966, 04/09/2019, YEARS, PowerCurve Standard Profile = 52

    SQL Server Standard Profile - 04/12/1966, 04/09/2019, YEARS, SQL Server Standard Profile = 53

Months Difference
  • Months definition: n day to n day of next month
  • Calculation: Count full months with exception around the end of the month
  • Count months boundaries:
    • If day is same or later in End_Month then include
      (e.g. 27/01 → 27/02 is 1 months difference)-27
    • If day is earlier in End_Month then exclude
      (e.g. 27/01→ 26/02 is 0 months difference)
    • UNLESS day is last day in End_Month, in which case include
      (e.g. 29/01/2018→ 28/02/2018, 30/01/2018→ 28/02/2018, 31/01/2018→ 28/02/2018 are all 1 months difference)
  • Months definition: n month to m month
  • Calculation: (YEAR2 - YEAR1) * 12 + (MONTH2 - MONTH1)
    •   The date element is ignored
