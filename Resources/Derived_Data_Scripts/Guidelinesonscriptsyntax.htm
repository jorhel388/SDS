Guidelines on script syntax

Invalid script syntax will prevent the component for which the script is written to be tested or processed correctly. The deployment validation will prevent this from happening.

  To make it easier to read the script and correct syntax errors, it is recommended that the Format Script icon is selected from the toolbar once your script is complete.

The following are some guidelines on entering script in the script editor.

  • A single space should be entered to separate each function, operator, characteristic or value entered.

  • A space must be added after a function/operator name (e.g., OR) but is not required after a symbol. However, spaces are recommended for readability.

  • A return should not be placed on the last line of the script.
  • To be able to use double quotes (or any non-alphanumeric characters) in string evaluations within a script, the user will need to use the escape character \ to differentiate between delimiters for the string and the contents of the string.
