Math functions

In all of the following, expr is a numeric value, numeric characteristic or expression that returns a numeric value.

Function Script Syntax Mathematical Representation/Note

Abs

Absolute Value

ABS( <expr> )

y = abs(expr)

Exec*

Execute

EXEC( "<class.method>" )

This provides the means to execute external Java code.

The parameter to the EXEC function is a string containing the fully qualified class name (i.e. including package) and method name. At runtime the class must be available on the classpath.

Please refer to the Decision Agent documentation for further information.

Power**

POWER( <expr>, <power> )

 

Raises a specified number by the power, e.g 52= 5 squared (25)

e.g 53= 5 cubed (125)

The power can be used inversely, so 250.5= square root of 25 (5)

Random***

RANDOM( <max>)

This produces a number from 0 up to the number you have defined. Any integer positive number can be entered.

e.g., RANDOM(999) would produce a number from 0 to 998, RANDOM(5) would produce a number from 0 to 4.

Remainder

REM( <expr>, <divisor> )

y = REM (expr, divisor)

Divides the value in the expr by the divisor and places the remainder (if any) into y

e.g. REM (7,2) represents 7/2 = 3 rem 1, therefore 1 would be placed in y

Round Nearest Down

 

 

 

 

 

 

 

ROUNDD( <expr>, <multiple> )

ROUNDU( <expr>, <multiple> )

ROUNDN( <expr>, <multiple> )

ROUNDND( <expr>,<multiple)

Where multiple is the value to be rounded to

 

 

 

Rounds a value Up/Down or to the Nearest multiple of <multiple>

When using round nearest, if the value is mid way between rounding up and rounding down, the default is to round up.  

When using round near down, if the value is mid way between rounding up and rounding down, the system will round down.

e.g. ROUNDU(34.4,1) rounds up to the nearest 1, i.e. Result =35

ROUNDU(34.4,2) rounds up to the nearest 2, i.e. Result =36

ROUNDU(34.4,10) rounds up to the nearest 10, i.e. Result =40

ROUNDD(35.4, 3.7) rounds down to the nearest multiple of 3.7, i.e. Result =33.3

ROUNDN(35.5, 0.2) rounds to the nearest multiple of 0.2, i.e. Result =35.6

ROUNDND(35.5, 0.2) round to the nearest multiple of 0.2, i.e. Result=35.4

  With regard to rounding, negative and positive numbers are treated in the same way.
  <multiple> must not be set to 0 as this causes a divide by zero error in the script.

To Numeric

Value converters

 
  
 *The Exec function only supports JavaScript.
 **When performing POWER calculations with Decimal characteristics the minimum and maximum value for the power is limited to the minimum and maximum Integer values in Java [ -2147483648 / 2147483647 ]. When a number larger than the Integer range is used for the power - precision will be lost. When the power value has a scale (e.g. 12.25) , if either the whole part (12), or the scale (.25) of the number exceeds the Integer range precision will be lost.

There may be a degradation in the speed of execution of the POWER function when it is applied to large Decimal characteristics. This could become particularly noticeable with a power of over 4 digits in length. The user should understand the solution’s requirements and balance the performance impact of using Decimal characteristic values and the required accuracy for the solution.

Even with Decimal characteristics, if a result overflows 30 digits in length, accuracy could be lost.

E.g. 3333.333 is equal to 3333.3331, which is equal to 3333.333(0.33+0.67) which is equal to 3333.3330.33 x 33333.3330.67. However because the result for each expression (3333.3330.33 and 33333.3330.67 ) overflows the 30 digit length supported, those expressions will not be equal in the software.
 

***The <min> value that can be used with the RANDOM function is 1 and the <max> value is the biggest Integer value in Java (2147483647). If the user provides a number that is less than 1, the function will return an error.

When the value supplied is bigger than the max Integer value in Java, the value will be cast to 2147483647 and the RANDOM function will return numbers between 0 and 2147483646.
E.g. RANDOM (1000000000000) will work with the same range as RANDOM (2147483647).
