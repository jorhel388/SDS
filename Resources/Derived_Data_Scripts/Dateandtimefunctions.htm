Date and time functions

Date and time functions manipulate date type characteristics or explicitly entered dates or time characteristics.

Date characteristics will be of the format supplied in the data. Time characteristics will return a STRING.

  The minimum date that can be used within any Date and Time function is 01 Jan 1000, the maximum is 31 Dec 9999.
Function Script Syntax Note

Date Change

DATE( <givendate>, <period> )

period is number of days as a constant, numeric characteristic or expression

givendate is a Logical Data Source date type

Returns a date relative to a given date by the number of days specified by <period>

e.g. enddate = DATE(startdate, 30 )

startdate = DATE(enddate, - 90 )
Change Date With Calculation Profile**

DATEPADD (<date>, <datePeriod>, <numberPeriods>, <calculationProfile>

Using a date calculation profile** this function returns a date that has been calculated by adding or subtracting a set number of periods from the original date.

e.g. date = DD/MM/YYYY, datePeriod = DAYS, MONTHS or YEARS, numberPeriods = 5 calculationProfile = PowerCurve Standard Profile or SQL Server Standard Profile

04/09/2019, MONTHS, 13, PowerCurve Standard Profile = 04/10/2019

04/09/2019, MONTHS, 13, SQL Server Standard Profile = 04/10/2020
Duration Between Two Dates**

DATEPDIFF (<startDate>, <endDate>, <datePeriod>, <calculationProfile>

Using a date calculation profile** this function returns a value that calculates the difference between two dates, using either DAYS, MONTHS or YEARS.

e.g. startDate = DD/MM/YYYY, endDate = DD/MM/YYYY(04/09/2019), datePeriod = DAYS, MONTHS or YEARS, calculationProfile = PowerCurve Standard Profile or SQL Server Standard Profile

04/12/1966, 04/09/2019, YEARS, PowerCurve Standard Profile = 52

04/12/1966, 04/09/2019, YEARS, SQL Server Standard Profile = 53

Day of Week

number = DAYOFWEEK( <date>)

This function returns the day of the week for a given date. Date is a Logical Data Source date type, whilst number is a Logical Data Source numeric characteristic.

e.g. 5 =DAYOFWEEK (TODATE("19640417"))

1=Monday, 7=Sunday therefore the above day is a Friday

Days Between

DAYS( <date1>, <date2> )

date1 and date2 are Logical Data Source date types or expressions that resolve to date types

Returns a numeric value representing the number of days between two dates

e.g. noofdays = DAYS( start, end )

Is Valid Date*

ISVALIDDATE( <char> or <year>, <month>, <day>)

char is a characteristic that equates to a string or an integer value that is to be tested.

Checks whether a single string or integer is a valid date in the CCYYMMDD format or alternatively it can be used to check whether 3 integers or 3 string data types form a valid date

e.g. ISVALIDDATE ('Applicant.DOB')
The result of this function will be a String where the outcome will be True or False.

"True" = the value of the <char> is a valid date in the CCYYMMDD format
"False" = the value of the <char> is not a valid date

Months Between

MONTHS( <date1>, <date2> )

date1 and date2 are Logical Data Source date types or expressions that resolve to date types

Returns the number of whole months between two dates; if the dates of the months are the same it returns 1
e.g.,
MONTHS (TODATE("20030701") , TODATE("20030314")) will return -3

MONTHS (TODATE("20030722") , TODATE("20030822")) will return 1

MONTHS (TODATE("20030722") , TODATE("20030821")) will return 0

System Date

SYSTEMDATE( <const>)

const is a: constant, numeric characteristic or expression

Returns a date relative to the current date by the number of days specified by <const>

e.g. SYSTEMDATE(0) is todays date

SYSTEMDATE(-1) is yesterday's date

System Date Time*

SYSTEMDATETIME("yyyyMMdd HH:mm:ss")

Returns the current date and time in the format

YYMMDD HH:MM:SS (24 hour clock) to a STRING. The STRING needs to be a length of 17.

e.g. 20080304 13.:24:15

System Time*

SYSTEMTIME("HH:mm:ss")

Returns the current time in the format HH:MM:SS (24 hour clock) to a STRING. The STRING needs to be a length of 8

e.g. 13:24:15

To Date

Value converters

 
  *The user has the choice of calling the function using a single parameter (<char>) or 3 parameters ( <year>, <month> and <day>).
 

*If the function is called using 3 parameters, then they all must be of the same data type: either 3 integers or 3 strings, i.e. a combination of integers and strings cannot be used.
 

*The format used in the SYSTEMDATETIME and SYSTEMTIME functions is the default, any SimpleDateFormat can be implemented. Refer to the Oracle documentation for more information.
 

**There are two Date Calculation Profiles that can be used in the DATEPADD and DATEPDIFF functions.

PowerCurve Standard Profile - existing PowerCurve java based profile

SQL Server Standard Profile - uses SQL based calculation, counting date boundaries for months and years
