Environment variable parameters

The following is a list of all parameters that can be passed to the GETENV function, and a list of the system permissions that can be used with the SystemPermission parameter. All of the calls to GETENV return values that are taken from the operational user’s account fields. GETENV always returns values of type STRING, regardless of the parameter used.

 

Note these known limitations:

1. Most of this information will not be available when external LDAP authentication is used, because in this case we don’t have access to the user account information.

2. When executing Screenless business process flows, the user does not select an active profile and group, so a GETENV call with the parameters UserActiveSecurityProfile or UserActiveGroup has no meaning.

3. In both of the above cases, if GETENV is used inappropriately it will simply yield an empty string and will not break the business process flow's execution.
