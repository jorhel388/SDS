EXEC_SCRIPT

External GroovyScript and JavaScript script files can be called at runtime using the EXEC_SCRIPT function in the Derived Data Script component.

The EXEC_SCRIPT function appears in the Derived Data Script component in the following way:

EXEC_SCRIPT( "<script.filename>" ) where the script is executed at runtime.

//EXEC_SCRIPT( "filename.groovy" )

//EXEC_SCRIPT( "filename.js" )

The EXEC_SCRIPT cannot execute characteristic names with spaces or fullstops as these are not valid identifiers in scripting languages. These are replaced with underscores when variables representing the characteristics are made available to the external script for execution.

 

'Application Data View.Last Name' replaced with 'Application_Data_View_Last_Name'

However, if a characteristic name contains underscores or is not a simple characteristic, but contains intermediate elements that are arrays, e.g. Application Data View.Address[1].Postcode then this simple replacement will not work. Duplicate names could be created and what was a characteristic that contained an array will be flattened and become impractical to use in the script.

The global variable "valueStore" object has been made available in the script runtime context to solve these issues.
Simple characteristics will still function as before in an EXEC_SCRIPT, but if the "valueStore" object is used with a suitable method call, then all characteristics can be accessed by the names as defined in the studio, since the full name will now be surrounded by quotes.

 

Groovy Script

valueStore.setString("Application Data View.LastName", "Jones");
valueStore.setString("Application Data View.Address[1].PostCode[1]", "360000");
  For the valueStore global variable to work it must be written in the EXEC_SCRIPT exactly as "valueStore"
Valid methods that can be used with valueStore
  • boolean isNameValid(String name);
    Determines if the value for a name is an array.
    @param name the name to check.
    @return true if the value for the name is an array, otherwise false.
    @throws ValueException if the name does not exist.
  • boolean isArray(String name) throws ValueException;
    Returns the array size if the value for a name is an array.
    @param name the name to check.
    @return the array size of the value, or 0 if it is not an array.
    @throws ValueException if the name does not exist.

  • int getArraySize(String name) throws ValueException;
    Gets the numeric value for the specified name in this value store.
    @param name the name of the value to return.
    @return a double representation of the value for that name,
    @throws ValueException if an error occurs reading the value.

  • double getNumber(String name) throws ValueException;
    Gets the string value for the specified name in this value store.
    @param name the name of the value to return.
    @return a String representation of the value for that name,
    @throws ValueException if an error occurs reading the value.

  • String getString(String name) throws ValueException;
    Gets the date value for the specified name in this value store.
    @param name the name of the value to return.
    @return a Date representation of the value for that name,
    @throws ValueException if an error occurs reading the value.

  • Date getDate(String name) throws ValueException;
    Gets the boolean value for the specified name in this value store.
