Date functions used in Filters (Strategy Monitoring only)

Date Functions

Function Script Syntax Note

System Date

SYSTEMDATE(<const>)

const is a: integer with positive or negative sign, or numeric characteristic.

Returns a date relative to the current date by the number of days specified by <const>

e.g.
'LDS.Characteristic'=SYSTEMDATE(0) is todays date
'LDS.Characteristic'=SYSTEMDATE(-1) is yesterdays date

Unsupported use of SYSTEMDATE in Reporting context:
SYSTEMDATE(1+5*('LDS.Characteristic')) // const is a arithmetic expression
SYSTEMDATE(ABS(expression)) // const is a function

To Date

TODATE(<const>)

const is a: positive integer or string

Can convert a numeric or string to a date. If a constant value is entered it must be a valid date in the format CCYYMMDD. A value in a different format will cause an error at runtime.

e.g.
'LDS.Characteristic' = TODATE(20131231)
'LDS.Characteristic'= TODATE("20131231")

Unsupported use of TODATE in Reporting context:
TODATE('LDS.Characteristic') // const is a logical data source characteristic
TODATE(ABS(expression)) // const is a function
TODATE(1 + 4 * (1245)) // const is arithmetic expression

Months Between*

MONTHS(<date1>,<date2>)

date1 and date2 are logical data source date types or expressions that resolve to date types

Returns the number of whole months between two dates; if the dates of the months are the same it returns 1.

e.g.
MONTHS (TODATE("20030701") , TODATE("20030314")) = -3
MONTHS (TODATE("20030722") , TODATE("20030822")) = 1
MONTHS (TODATE("20030722") , TODATE("20030821")) = 0
MONTHS ('Account.Close_Date' , 'Account.Open_Date') > 0

Unsupported use of MONTHS in Reporting context:
MONTHS (TODATE("20030701") , TODATE("20030314")) - MONTHS ('Account.Close_Date' , 'Account.Open_Date') > 0 // Multiple use of MONTHS in an expression separated by comparison operator.

Days Between

DAYS( <date1>, <date2> )

date1 and date2 are logical data source date types or expressions that resolve to date types

Returns a numeric value representing the number of days between two dates.

e.g. DAYS( start, end ) = 1
 
 * Months Between is not supported in a Filter used in Strategy Monitoring if the data-mart is running on an SQL Server. A runtime error will be thrown if this function is used.
