Filters

A Filter is used to control which records are included in a specific data population (applicable for reports, Assisted Design Projects, etc.). A filter must evaluate to be either TRUE or FALSE.

For an inclusion filter, records that are TRUE are included in the population; for an exclusion filter, records that are TRUE are excluded from the population.

  'Applicant.Age' >25' In this example - if the filter is an inclusion filter - it includes in the data population all records of the 'Applicant.Age' characteristic for which the value is greater than 25.
Overview

The user creates scripts by entering text (or dragging and dropping from the palette) into a script editor where mathematical, logical or string manipulation operations are applied to Logical Data Source characteristics.

The Filter editor displays characteristic names, operators, and functions, etc., in different colours.

The Filter editor has basic text manipulation such as selecting blocks of text to cut, copy, paste and delete.

The script syntax must be valid before any testing can be carried out.

Edit Filters

Editing a filter involves entering the script content using the script editor.

Create Filters

A filter can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a filter

  1. From the Explorer window right click at the required folder level and select Add a component.
  2. Select Filter.
  3. In the Create component dialog enter the name of the filter.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.

    The Filter editor will open allowing you to edit script the filter.

    The filter name will be listed in the Explorer under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window right click on the filter and select Open. The Filter editor will open allowing you to edit script the filter.

See the topic Operators and functions used in filters for details of the operators, functions and statements that can be used in the script editor.

    or by using the required resources from the Resources window you can:

Add a characteristic to a script

A script can be any of a derived data script, boolean expression, policy rule, filter or user defined function.

The script must be open for editing.

To add a characteristic to a script from the Resources window

  1. With the Filter editor open, in the Resources window, click on the Expand (+) button to display the contents of the logical data source.
  2. Drag the required logical data source and drop it onto the script at the required position.
  3. The Select Characteristic dialog opens.
  4. Locate the logical data source you require.
  5. Click on the Expand + button to list all the characteristics contained in the logical data source.
  6. Select the characteristic you require.
  7. Click on the OK button.

The Select Characteristic dialog closes and the characteristic you have selected is added.

To add a characteristic to a script freehand

  1. With the Filter editor open, enter the name of the characteristic into the script editor at the required position.

Characteristics must always be in single quotes (including the logical data source name).

Add an operator or function to a script

A script can be any of a derived data script, boolean expression, policy rule, filter or user defined function.

The script must be open for editing.

  Only operators or functions that are contained on the filter palette should be used in filter scripts, other functions/operators may pass filter script validation but fail to execute when used

To add an operator or function to a script from the Palette

  1. With the Filter editor open, click on the point in the script that you wish to add or insert the operator or function.
  2. In the Palette window, click on the Expand (+) button to expand either the Operators or the Functions.
  3. Drag the required function or operator and drop it onto the script at the required position.

The operator or function will be added to the script.

To add an operator or function to a script freehand

  1. With the Filter editor open, type the operator or function in upper or lower case.
  2. Where the operator or function is followed by script text, ensure there is a space after the function or operator.
  3. Where the operator or function is preceded by text, ensure there is a space before the function or operator.

The operator or function will be added to the script.
