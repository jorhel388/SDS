Reports

A report is a component stored in the repository. It is created by a user selecting a report template from those available in the solution, and then configuring the template using a set of parameters to create a report definition. Additional templates can be added to an existing reporting solution, allowing the range of reports to grow over time. A report definition is created in the studio by the user setting varying mandatory and optional parameters; when a report definition has been fully defined and validated it can be submitted. The report parameters can include:

  • Dates ranges and intervals
  • Other repository components (e.g., to segment by a class set)
  • Text for descriptions (up to 200 characters in length)
  • Static values
 

Strategy Monitoring Reports that are generated which include rounded values use the Half to Even Rounding method. As such, values on these reports might be different when compared with an Excel report, for example, that uses a different rounding method.

Most reports will use measures to define the calculations returned, and the user will specify these using the studio; they can be re-used across many report definitions. All reports allow the user to define filters to include or exclude records. Reports can also be sliced, where a separate sub-report is produced for each segment of the population defined using a class set or characteristic.

  The user wants to assess the stability of their applicants' ages over time. To do this, the user will create an Acquisition Population Stability Trend report where they define the time period over which to assess applications and the class set containing the age group intervals.
 

Class Sets that have been defined against Logical Data Models can only be used in scripting components.

Create a Report Definition

A report definition can be created from the Explorer Window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be created.

To create a report definition

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Report.
  3. In the Create component dialog enter the name of the report definition.
  If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor check box is selected.
  1. Click on the OK button. The report definition name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.
    The Report Template Chooser is displayed, allowing you to select the report template you want to configure.
  1. From the Report Template chooser, select the required template type from the Available Reports section.
  2. Click on the Expand (+) button to display the list of available report templates.
  3. Select the report template you want to configure.
  4. Click the Load button to load the report.

If you do not wish the editor to open, de-select the tick box. From the Explorer window select the report definition and select Open.

  You can also import or export the report definition you created but the physical data models will not be included. You need to import or export the physical data models separately. For more information on importing or exporting the report definition, please refer to Export/Import overview.
 

If a logo is assigned using the Report Configuration component, the Experian logo will still appear in the template preview.
