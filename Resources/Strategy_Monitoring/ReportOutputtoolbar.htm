Report Output toolbar

The Report Output tab toolbar is used to assist the user in viewing, saving and printing a report.

Save - Save the report to the required file type.

Print - Print the report.

Reload - Reloads the latest change from the Jasper Viewer tool. This function is not applicable for report output.

First Page - Go to the first page of the report.

Previous Page - Go to the previous page of the report.

Next Page - Go to the next page of the report.

Last Page - Go to the last page of the report.

Go To Page - Go to the particular page of the report.

Actual Size - To view the report's actual size.

Fit Page - To fit the report in the page size of the Report Output.

Fit Width - To fit the report in the width size of the Report Output.

Zoom In - To zoom in the report.

Zoom Out - To zoom out the report.

Zoom Ratio - Select the required zoom ratio to view the desired size of the report.
