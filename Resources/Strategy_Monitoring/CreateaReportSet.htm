Create a Report Set

A Report Set is created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be created.

To create a report set

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Report Set.
  3. In the Create component dialog enter the name of the Report Set.
  4. If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor tick box is selected.
  5. Click on the OK button.

    The Report Set window is displayed, allowing you to select the list of reports you want to submit or schedule for execution.
    The Report Set name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

    If you do not wish the editor to open, de-select the tick box. From the Explorer window select the Report Set and select Open.

You can now configure a Report Set.
