Report Configuration

All report definitions must reference a Report Configuration component. The Report Configuration component allows the studio to describe the database that is to be used for report generation. It also allows the user to specify which measures are to be used by the fixed measure reports.

  • The Mart tab defines the database connection name (ie, it references the database connection name contained in the reporting data mart section of the db_management_config.xml file).
  • The Table Joins tab defines the structure of the database tables, in XML.
  • The Fixed Measure(s) tab defines the measures for the fixed measures reports included in the solution.
Create a Report Configuration

A Report Configuration is created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be created.

To create a report configuration

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Report Configuration.
  3. In the Create component dialog enter the name of the report configuration.
  4. If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor tick box is selected.
  5. Click on the OK button.

    The Report Configuration window is displayed, allowing you to configure the required connection name, table joins and fixed measures.
    The report configuration name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, de-select the tick box. From the Explorer window select the report configuration and select Open.

Configure a Report Configuration

Report Configuration is a component that enables the user to configure the reporting functionality to define and generate reports on the reporting database from within the software.

To configure a report configuration

  1. In the Report Configuration editor, select the Mart tab.
  2. In the Connection Name field, type in the database Connection Name, exactly as it appears in the <business-name> field of the appropriate reporting data mart section of the db_management_config.xml file (found in the conf directory on the job server).
  3. Specify the length of the Customer Management processing cycle (whether customers are processed on a daily, monthly or quarterly basis).
  4. If desired, change the default report output folder for all reports by clicking the Browse button and locating the folder on your computer.
  5. If desired, customise the logo for the header and footer using the Browse buttons in the Header & Footer area. It is important to note the following:

    1. If a logo is too big or too small, it will automatically be resized to fit the allocated space. Users will see an information message notifying them of this.

      1. Headers will be resized to 75 (h) x 55 (w) pixels.
      2. Footers will be resized to 134 (h) x 168 (w) pixels.
    2. The maximum supported file size for a logo is 2048 KB.
    3. Only .png files can be uploaded.
    4. Once a logo has been selected, a preview of the logo will replace "Logo Preview" below the Report Header or Report Footer field as appropriate.
      Only one logo, which will be applied to all reports for the solution, can be selected for each the header and footer.
     

    To clear or export a customized logo, right click in either the Report Header or Report Footer field as appropriate and click Clear or Export as required.

  6. Select the Table Joins tab.
  7. Paste in the appropriate <tables> .xml file for this database.
  8. Select the Fixed Measure(s) tab.
  9. For each fixed measure, you can drag and drop from the Resources window into the Measure field the measure component to be used by the report template.
  10. Click on Save to save the report configuration.

The report configuration is now ready to be used in a report.
