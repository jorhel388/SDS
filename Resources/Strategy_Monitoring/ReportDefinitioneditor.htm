Report Definition editor

For every report definition the user creates, the Report Definition editor is used to define the report. Each report must be fully defined before the user can submit the report definition to be executed. The user can validate the report to identify whether the definition meets the validation criteria.

The reports are defined by filling in the information on a set of tabs. The number of tabs and the information required on each tab is described in detail for each report template; these can be found under Report Templates.

The Report Definition editor includes the following button on the tool bar:

Submit Report Definition - Submits the report definition to the job submission console for execution. For more information on submitting report definitions, please refer to Submit a Report Definition.
