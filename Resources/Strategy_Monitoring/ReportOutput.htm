Report Output

When a report definition is submitted it is sent to the Job Submission framework for execution. Assuming no errors are encountered, each report submission will create a Report Output component which will be stored in the reporting repository.

The Report Output is a read-only component which shows the report (tables and graphs) based on the data in the reporting data mart when the report was executed. The Report Output also holds log information, the parameters used and details of the SQL executed to create the report.

  The folder containing the report output is specified in the report set/report definition or report configuration (depending on what the user has specified).

See details for the various tabs:

Report Output tab

The Report Output displays the result of the generated report. It typically contains the following sections:

  • Report header
  • Slicing or Segmentation details
  • Tables
  • Graphs

In the Report Output tab, the user can use the integrated Jasper Viewer tool to view, print and save the report. The tool bars that the user see in the Report Output tab are from the Jasper Viewer tool. For information on the tool bar functionality, please refer to Report Output toolbar.

Report header

The report header section provides information about the report such as the report name, creation date, description, analysis period, filters and segmentations applied. Other information such as scorecard, benchmark and weighting will also appear, depending on the type of report that has been submitted.

Slicing or segmentation details

The slicing details section provides information about the slicing or segmentation methods used, if any. This includes information on the slicing or segmentation characteristic that was used to segment the population. This section will appear before each sub-report, indicating the slice that the subsequent table or graphs represent.

Tables

The tables section displays the measure calculations specific to each report type and definition.

Graphs

Reports will typically show graphs based on the measures shown in the table.

Report Log tab

The Report Log tab provides the log information of a particular report. This log can be used for traceability purposes including audit trails.

The following log information is provided:

  • The date and time the report was submitted for generation
  • The date and time the generation process began and ended
  • If the report was submitted as part of a report set, the set name and description will be shown
  • The user name of the user who generated the report
  • A list of warning messages, if any
SQL Details tab

The SQL Details tab provides the equivalent SQL queries used in obtaining the data used to generate the report. The SQL queries can be used for debugging purposes.

Report Parameters tab

The Report Parameters tab provides information about the criteria used in generating the report. This can be used to further understand how the report was generated and the type of data used in generating the report.

The information provided will be specific to the parameters required for each report template style and the specific values provided by the user for the submitted report definition.
