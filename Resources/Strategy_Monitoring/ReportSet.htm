Report Set

Report definitions can be grouped to create a batch Report Set. This allows multiple reports to be submitted or scheduled for submission in one go.

The user selects which reports to include within a Report Set. When the Report Set is submitted, each report will be executed.

  Only users with the Report set submission permission can submit a report set.

The Report Set consists of two tabs:

Properties tab

The Properties tab is made up of two areas:

  • Report Set Description - enables the business user to describe the set of reports being run. A maximum number of 200 characters can be entered in this field.
  • Report Output Folder - the radio button that is selected will determine where the generated reports will be saved.
    • Selecting the Follow Report Definition radio button will ensure that the report output generated as part of the report set is saved in the location defined in the report definition (which could vary with each report definition).
    • Selecting the Report Output Folder will allow the user to define a folder location where all the report outputs will be stored. The user can use the browse button to select a folder from the reporting repository.
    • The Auto Create Sub Folder in Report Output Folder check box can be used to store the report output in a sub-folder (whose parent is the selected Report Output Folder). If this check box is selected the system will automatically create a sub-folder in the Report Output Folder to store the new reports. This can be useful to manage the report output when a Report Set is scheduled for recurring execution.
    • The Prefix field enables the user to optionally define what text will be added to the name of the sub-folder (a suffix of date time will be added automatically). The reports will be created in this new sub-folder.

    When the Report Output Folder is selected for the first time the check box by default will not be selected.

Contents tab

The Contents tab is made up of a Report Definitions, a list of reports contained in the report set.

  The report definitions can be opened from within the Report Definitions area of the Contents tab by right clicking on the report and selecting Open.

Create a Report Set

A Report Set is created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be created.

To create a report set

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Report Set.
  3. In the Create component dialog enter the name of the Report Set.
  4. If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor tick box is selected.
  5. Click on the OK button.

    The Report Set window is displayed, allowing you to select the list of reports you want to submit or schedule for execution.
    The Report Set name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

    If you do not wish the editor to open, de-select the tick box. From the Explorer window select the Report Set and select Open.

Configure a report set

Once a report set has been created, it must contain at least one referenced report definition before it can be submitted or scheduled for submission.

To configure a report set

  1. From the Explorer window right click on the report set and select Open.
  2. Type a description in the Report Set Description area.
  3. Select either the Follow Report Definition or Report Output Folder radio button as required.
  4. Click on the Browse button to access the Reporting Repository.
    The system will open the Reporting Repository Browser dialog
    5.   The Reporting Repository Browser dialog will only open if the Reporting Repository is connected and a solution has been loaded.
  1. Select the folder where you wish the reports to be generated.
  2. Click on the OK button.
    The dialog will close and the full path will be listed.
  3. In the Report Set window, select the Contents tab.
  4. Drag the required report from the Resources window and drop it in the Report Definitions section.
  5. Repeat step 8 to add to the list of reports you want to submit.
  6. Save the report set.

The report set can be submitted or scheduled for execution.

Submit/Schedule a report set

Once a report set has been created, it must contain at least one referenced report definition before it can be scheduled for execution by the Job Submission Console.

To schedule a report set for execution at a future time

  1. In the Explorer window, right click on a report set and select Schedule; or from the Report Set window, click on the Submit Report Set icon.
  2. The Report Set Scheduling dialog is displayed.
  3. Click on the calendar icons to display the Start Date and End Date schedulers.
  4. From the schedulers, select the date and time for the start and end periods of the report executions.
  5. Select the schedule at which the report sets are to be executed (e.g., every other day; the first Tuesday of each month; etc.).
  6. Click OK to submit the report set to the Job Submission Console for scheduled execution.

Each report definition in the report set will be submitted to the Job Submission Console as a separate job.

The list of completed reports is listed in the Reporting solution of the Explorer window, and each report definition will create a separate report output in the reporting repository.

  If a report set is modified after it has been scheduled for future execution, the originally scheduled report execution jobs will remain in the Job Submission Console until they are manually removed from the console. See Remove a scheduled job submission for details on how to remove a schedule job from the console.

Exporting the report output

Using the Batch Process Flow the user can automate the export of the report output into various formats, including PDF (*.pdf), RTF (*.rtf), ODT (*odt), HTML (*.htm, *.html), Single sheet XLS (*.xls), Multiple sheets XLS (*.xls), CSV (*.csv), XML (*jrpxml, *.xml) and Embedded images XML (*.jrpxml, *.xml). For more information refer to the Batch Process Flow help set.
