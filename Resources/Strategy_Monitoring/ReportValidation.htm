Report Validation

Report validation ensures that the user has entered valid report definitions. Valid means that the report definition contains:

  • The relevant mandatory fields. For example, when the Development Sample option is selected in the Benchmarking tab of the Acquisition Population Stability (APS) report, the Scorecard Mapping field in the Population Definition tab needs to be configured.
  • The correct type. For example, the measure created for a report definition should have the correct measure type.
  • The correct value. For example, the user can only enter 0.01 to 0.99 values at the Stability Index section in the Advanced Settings tab.
  • Unique characteristics or components. In some cases, characteristics or components used should not be the same. For example, in the Population Segmentation tab, the user cannot define the same segmentation and slicing class set characteristics.

Validate a Report definition

Report validation ensures that the user has entered valid report definitions before the report is submitted.

To validate a report definition

  1. Right click on the report definition in the Explorer window; or, with the report definition open in the editor, click on the Validate icon in the main tool bar.
  2. The system will check the validity of the report and display any invalid areas of information in the Validation Results window.

Amend the Report as necessary from the information given.

Submit a Report

After a report definition is configured and validated, the user can submit the report for execution by the Job Submission Console.

  Only users with the report submission permission can submit a report.

There are three ways to submit a report definition:

  • Submit the report definition from the Report Definition editor.
  • Submit the report definition from the Explorer window.
  • Submit a batch of reports after creating a report set.

To submit a report definition from the Report definition editor

  1. With the report definition open in the Report Definition editor, click on the Submit Report Definition button.
  2. The report definition is validated, and the Remote Job Notification dialog box is displayed. Click on the OK button.
  3. While the report is executing, its progress can be monitored in the Job Submission Console.

Once the report has been successfully executed, it is listed in the Reporting solution of the Explorer window.

To submit a report definition from the Explorer window

  1. In the Explorer window, right click on a report definition.
  2. The report definition is validated, and the Remote Job Notification dialog box is displayed. Click on the OK button.
  3. While the report is executing, its progress can be monitored in the Job Submission Console.

Once the report has been successfully executed, it is listed in the Reporting repository of the Explorer window.
