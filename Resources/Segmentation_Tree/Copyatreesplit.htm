Copy a tree split

The Copy split functionality enables tree splits and any leaf node names and outcomes that have been assigned to them to be copied from a tree and pasted onto:

  • leaf nodes and split headers within the same tree
  • leaf nodes and split headers within another tree within the same solution

Copy Split can be accessed from any split header of a tree, however where it is pasted and the options that are available will affect what the tree editor pastes. When a split is copied and pasted between trees the user is given two options:

  • Paste Split - will paste the split, but no outcomes will be created. If you are pasting within the same tree, the existing outcome assignments will be maintained
  • Paste and Outcomes - will paste the split, create new outcomes and assign them in the tree

Copy and paste in the same tree

To copy a tree split and paste it onto a node in the same tree

  1. With the Tree editor open, right click on the split header that you wish to copy and select Copy Split.
  2. Right click onto a leaf node or split header and select Paste Split.
    If the leaf node you are pasting onto or the leaf nodes for the split header you are pasting onto have no outcomes assigned, the copied split will be pasted directly into the tree.
  3. If you choose to paste the split onto a node that already has an outcome or further segmentation assigned to it, you will enter the ‘Add’ or ‘Insert’ repair mode where you can decide how to repair the tree or whether you want to reassign the orphaned outcome or branch with its original outcomes assigned.
  4. You need to use the Insert a tree split to complete the paste.
  5. If you choose to paste the split onto a split header, where the split has outcomes or further segmentation assigned to the leaf nodes, you will enter the ‘Replace’ repair mode where you can decide if you want to reassign the orphaned outcomes or branches with their original outcomes assigned.
  6. You will need to use Replace a tree split to complete the paste.
  7. Repeat steps 1 to 6 as necessary.

The tree will be updated with the changes you have made and return to the Tree editor where you can now continue editing the tree.

Copy and paste in a different tree

To copy a tree split and use paste split

  1. With the tree editor open, right click on the split header that you wish to copy and select Copy Split.
  2. Within the Explorer window, right click on the component tree you wish to be paste the copied split into and select Open.
    The component tree editor will open.
  3. Right click on a leaf node or split header and select Paste Split.
    If the leaf node you are pasting onto or the leaf nodes for the split header you are pasting onto has no outcomes assigned, the copied split will be pasted directly into the tree.
  4. If you choose to paste the split onto a node that already has an outcome or further segmentation assigned to it, you will enter the ‘Add’ or ‘Insert’ repair mode where you can decide how to repair the tree or whether you want to reassign the orphaned outcome or branch with its original outcomes assigned.
  5. You need to use the Insert a tree split to complete the paste.
  6. If you choose to paste the split onto a split header, where the split has outcomes or further segmentation assigned to the leaf nodes, you will enter the ‘Replace’ repair mode where you can decide if you want to reassign the orphaned outcomes or branches with their original outcomes assigned.
  7. You will need to use Replace a tree split to complete the paste.
  8. Repeat steps 1 to 7 as necessary.
  9. In the Outcomes area, click on the outcome you wish to assign to the leaf nodes that do not have an Outcome assigned.
    The Assign outcome button on the tool bar will automatically become activated.
  10. In the Tree editor click on the outcome of the leaf node that you wish to assign the outcome.
  11. Repeat as necessary to assign an outcome to all of the unassigned leaf nodes.

The tree will be updated with the changes you have made and return to the Tree editor where you can now continue editing the tree.

To copy a tree split and use paste split and outcomes

  1. With the tree editor open, right click on the split header that you wish to copy and select Copy Split.
  2. Within the Explorer window, right click on the component tree you wish to be paste the copied split into and select Open.

    The component tree editor will open.

  3. Right click on a leaf node or split header and select Paste Split and Outcomes.
    If the leaf node you are pasting onto or the leaf nodes for the split header you are pasting onto has no outcomes assigned, the copied split and any assigned outcomes will be pasted directly into the tree. If the outcomes already exist in the Outcomes Table, they will be reused, if they do not then new outcomes will be created.
  4. If you choose to paste the split onto a node that already has an outcome or further segmentation assigned to it, you will enter the ‘Add’ or ‘Insert’ repair mode. In this mode the pasted split will be added to the node with its copied assignments, the system will not attempt to repair the tree for you, but you will have access to reassign any orphaned outcome or branch with its original outcomes assigned.
  5. You need to use the Insert a tree split to complete the paste.
  6. If you choose to paste the split onto a split header, where the split has outcomes or further segmentation assigned to the leaf nodes, you will enter the ‘Replace’ repair mode. In this mode the pasted split will be added to the tree with its copied assignments, the system will not attempt to repair the tree for you, but you will have access to reassign any orphaned outcomes or branches with their original outcomes assigned.
  7. You will need to use Replace a tree split to complete the paste.
  8. Click on the Confirm button if you wish the changes to be applied to the tree.
  9. Click on the Cancel button to stop the paste.

The tree will be updated with the changes you have made and return to the Tree editor where you can now continue editing.
