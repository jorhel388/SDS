Working with Nodes

Auto generation of leaf node names

Each leaf node of a tree should have a name. The leaf node name is a user defined description that identifies the action that will be applied to any record that is assigned to this leaf node. Auto Generate enables the user to automatically generate leaf node names in a tree.

Auto Generate enables the user to describe a series of leaf node names using an alphanumeric text pattern with a wildcard (*), a start value and an increment. Confirming the settings will assign the names according to the specific pattern, to all leaf node names subordinate to the selected split.

Auto Generate allows the user to choose between overwriting the existing leaf node name, to prefix the existing name or to suffix the existing name with the name that will be automatically generated using the Prefix, Suffix or Overwrite radio buttons. The only exception to this will be when the initial leaf node name <<Leaf Node Name>> exists, as this will always be overwritten regardless of whether Prefix of Suffix has been selected.

Auto Generate can be accessed by right clicking underneath the Leaf Node Name column from either the Starting Node or from any Split Headers in the Tree as shown in the example below.



Selecting Auto Generate from the Starting Node will assign the leaf node name to the whole tree, selecting Auto Generate from a Split Header will assign the name only to those leaf nodes below the selected Split Header.

To auto generate a leaf node name

  1. With the Tree editor open right click underneath the Leaf Node Name column in the tree editor and select Auto Generate.
    The system will display the Auto Generate dialog:
  2. Type the alphanumeric text either before or followed by the wildcard.
  1. In the Starting Value box, type a value.
  2. In the Increment box type the value that the starting value will be increased by within any subordinate nodes.
    3.  

    For the OK button to become activated:
    - Pattern must contain at least one "*" asterisk character
    - There is a character limit of 121 for the Pattern and this includes the "*"
    - Starting Value must be: numeric, positive, fit in the range between 1 and 9,999,999, and have a maximum value of 9,999,999
    - Increment must be: numeric, positive, fit in the range between 1 and 100 and have a maximum value of 100
  1. Choose either the Prefix, Suffix or Overwrite radio button.
  2. Click on the OK button.

The dialog will close and the Leaf Node Names will be automatically generated using the settings that you have provided.

Add an annotation

An annotation can be added to any node of the tree and is used to provide additional information to the user without affecting the functionality.

To add annotation to a node of the tree

  1. With the Tree editor open either click on the Add annotation icon on the tool bar and click on the node that you wish to annotate, or right click on the node and select Add Annotation.

    The system will open the annotation box.
  2. Type the information you require in this box.
  3. To close the box click anywhere on the main editor.

The node will now have annotation assigned to it. You can continue editing the tree.

Edit an annotation

Once an annotation has been added to a node in the tree the user can edit it as required.

To edit annotation in a tree

  1. With the Tree editor open right click on the node to which annotation has been assigned and select Edit Annotation.

    The system will open the annotation box.
  2. Amend the information contained in this box as required.
  3. To confirm the changes you have made, click anywhere on the Main editor to close the box.

    The annotation will be amended.

You can continue editing the tree.

Remove annotation from a node of a tree

Annotation can be removed from the node of a tree.

To remove annotation from a node of a tree

  1. With the Tree editor open, right click on the node that has annotation and select Remove Annotation

    The annotation will be removed.

You can continue editing your tree.

Update Leaf Node IDs

When a Segmentation Tree is created and tree splits are added to the tree, the Leaf Node IDs are given the number -1. Once the Segmentation Tree is saved unique leaf node ids are automatically created by the system. The user however may not wish to save the tree, but still wish to test it. Interactive Tester will not work unless the tree is valid and since the tree must have unique leaf node ids to be valid, the update leaf node ids option enables the user to alter the leaf node ids of the tree without having to save it.

The Update Leaf Node IDs option allows the user to update leaf nodes that currently contain -1 (blank leaf nodes) or renumber (overwrite) all of the leaf nodes in the whole tree using user defined increments. The system will not allow the user to use a number that has been used previously in the tree or is currently in use.

  For example, if you have a leaf node with 1 assigned, followed by blank leaf nodes and you choose to update these using an increment of 10, if the next number available is 2, the next three leaf node ids will be numbered 2, 12 and 22.

To update leaf node IDs

  1. With the Tree editor open, right click underneath the Leaf Node ID column in the Tree editor and select Update Leaf Node ID.

    The system will open the Update Leaf Node ID dialog.
    2.   To update the leaf node ids, click on the split header row underneath the Leaf Node ID column. This will update the ids in the sub tree below the selected split header.
  1. Select the Update blank leaf nodes radio button to update only leaf nodes ids that currently contain -1.
  2. Select the Renumber all leaf nodes radio button to renumber (overwrite) all the leaf node ids within the whole tree.
  3. Select from the Next Available Number drop-down box the number that you wish to use next.
  4. Select from the Increment drop-down box the increment number you wish to use.
  5. Click on the OK button.

The leaf nodes will be updated.

Display only the leaf nodes of the tree

To make it easier for the user to assign outcomes and components to a tree, the user can select to display only the leaf nodes of the tree in the Tree editor.

  By moving the cursor over the leaf nodes, full path to root information for each leaf node will be displayed.

To display only the leaf nodes of a tree

  1. With the Tree editor open, click the Table View icon.
    The system will update the view to display only the leaf nodes of your tree. An example can be seen below.
