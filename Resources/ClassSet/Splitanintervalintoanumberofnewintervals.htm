Split an interval into a number of new intervals

Where there is an interval that has a range of values, it is possible to split the interval into a number of new intervals. Each of the new intervals will represent the same fraction of the original range of values. This function will be performed as evenly as possible within the limitations of the interval properties.

  For example, if the interval >=10-<20 is split into 4 intervals this will create the following intervals:
>=10-<12.5
>=12.5-<15
>=15-<17.5
>=17.5-<20 - assuming that the decimal places are allowed.
If decimal places was set to 0 then the intervals would be as follows:
>=10-<13
>=13-<15
>=15-<18
>=18-<20

To split an interval into a number of new intervals

  1. Click in the range cell of the interval with a single range of values.
  2. Click in the split into n intervals icon on the toolbar.
  3. Enter the required number of new intervals:

    4.  
  4. Click on the OK button.

The Class Set editor uses the ranges of the original interval to produce the names for the new intervals.
