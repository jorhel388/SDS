Range Helper

Where a range is specified, the lower and upper bounds can be included or excluded from the range. By default, the lower bound is included and the upper bound is excluded. Each interval range is represented by an expression. When a simple range is typed (for example 10-20), the default expression is used (for example >=10-<20), where the default is not required the range can be entered in expression format. The lower and upper bound modifiers determine whether the values are included or excluded from the range.

Where an interval represents multiple non-contiguous ranges, each row added in the range helper represents a different range for values.

The following examples show how the ranges can be defined.

  Lower value included (>=) in the interval and Upper value excluded (<) from the interval (default for range).
For example
>=1 - < 5
values 1,2,3,4 will be included in the range.

 

 Both lower and upper bound values excluded (> - <).
For example
>1 - < 5
values 2,3 and 4 will be included in the range.

 

 Lower bound value excluded and upper bound value included (> - <=).
For example
> 1 - <= 5
values 2,3,4,5 will be included in the range.

 

 Both lower and upper bound values included (>= - <=).
For example
>= 1 - <= 5
values 1,2,3,4,5 will be included in the range.
  A single discrete value is also represented as an expression. A lower bound modifier of = is selected and a lower bound value entered. If = is selected, no upper bound value can be entered.
