Pattern matching for reason codes

Pattern matching in the reason code editor ensures that the reason codes that are created meet certain broadly or narrowly defined criteria.

By default, the pattern allows the user to create a code name using up to 10 characters or numbers, both upper and lower case. The pattern is displayed at the top of the editor, as follows:

By clicking on the Pattern button , the user can select a different pattern, or create a customized pattern:

The available pre-defined patterns are as follows:

Two letters (upper or lower case) followed by four numbers

One letter (upper or lower case) followed by three numbers

Two letters (upper or lower case) followed by two numbers

One letter (upper or lower case) followed by four numbers

Two letters (upper or lower case) followed by three numbers

One to three letters (upper or lower case) followed by one to three numbers

Any combination of between one and ten letters (upper or lower case) or numbers

User defined . . .

will open the Edit Code Table Pattern dialog

Free Format

Select to allow non-latin characters to be entered in the code column. These codes will not be subject to the regular expression matching mechanism.
Maximum number of characters that can be entered is 10

Selecting User defined from the menu displays the Edit Code Table Pattern dialog:

The Edit Code Table Pattern dialog allows the user to construct a customised pattern using the following rules:

[a-z]

Use lower case letters, from the first letter to the second letter

[A-Z]

Use upper case letters, from the first letter to the second letter

\d

Use numbers

\w

Use letters (upper or lower case) or numbers

{2}

Use exactly this number of letters or numbers

{1,3}

Use between x number of letters or numbers and x number
 

Use any two capital letters from A to F, followed by any four numbers.

Use any two lower case letters from a to c.
