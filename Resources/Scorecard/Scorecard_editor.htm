Scorecard Editor

The Scorecard editor is made up of two tabs:

Scoring Elements tab

The Scoring Elements tab provides all the scoring rules for the Scorecard.

The Scoring Elements tab consists of:

Scoring Elements Toolbar with options designed to assist you in defining the Scorecard.

  • Input Data Transformation (optional) - This field is used to apply input data transformation script to the Scorecard. If an input data transformation script has been applied to the Scorecard it will be executed prior to the Scorecard being executed.
  • Initial Score - This field can either have a constant value, a characteristic or an embedded or referenced scoring function. All other score values will be added to this initial score value. Embedded or referenced scoring function can be created for this score.
  • Scoring Element - A component with a number of outcomes. Each outcome is assigned a score. Scoring Elements can be created as embedded or referenced.
  • Score - This is the score value that is assigned to the outcome of an element. Scores can be reset to a default value (typically 0) by right clicking and selecting Clear.
  • Expected Score - This column is related to Adverse Reason Code Processing. If Adverse Reason Code Processing is disabled, this column will be hidden. The expected score can be set for all outcomes of a scoring element at the element level. If any of the scoring elements have an expected score, all of the scoring elements should also have an expected score.
  • Adverse Reason Code - This column is related to Adverse Reason Code Processing. If Adverse Reason Code Processing is disabled, this column will be hidden. The adverse reason code is selected at outcome level by right clicking and selecting Assign Adverse Reason Code. Expected score can be set for all outcomes of a scoring element at the element level. If an adverse reason code has been assigned a scoring element, all of the scoring element outcomes should also have an expected score assigned.
  • Final Transformation (optional) - This field is used to apply a function that will transform the score accumulated from the initial score and the scoring elements. The score may need to be recalculated to match other similar Scorecards or be used to present the score in a different way.
Graded Score Result tab

The graded score result tab is used to classify the final score into ranges and then assign an index number to each range. The graded score will be deployed and validated as part of the scorecard only if the Activate Graded Score has been selected in the Scoring Elements tab.

To learn how to define the graded score index see Define the graded score index topic.

Index - a 2 digit numeric index value used to grade a range of score values.

Range - a set of score values defined by entering a lower and upper value for the range. Operators can be used to define whether the range is inclusive or exclusive.

Range Helper - clicking on this icon will enable the Range Helper dialog that will assist the user in defining the range and operators to make the values inclusive or exclusive.

Others - a specific index value assigned when the final score does not fall into any range specified for any other index.
