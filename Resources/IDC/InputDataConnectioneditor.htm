Input Data Connection editor

The Input Data Connection editor enables the user to configure the details of data storage, and to configure a set of logical to physical relationships between the published Logical Data Sources and physical data names taken from the defined data source.

By default, the characteristics metadata in all tables or trees on this screen are limited to name only; by clicking on the Column display button, the user can display other columns as well. The choice of columns presented depends on the table or tree; the following example is for Logical Characteristics:

  In the case of the Physical Characteristics table the type, length and scale columns will only be present for CSV file data source types with associated ESV files.

Horizontal Scroll - select to enable/disable horizontal scrolling for the selected table or tree. Horizontal scrolling is useful when multiple columns are displayed.

Pack All Columns - select to resize each displayed column to accommodate the contents of its longest row (i.e, the contents of each column entry is displayed in full).

Pack Selected Column - select to resize the selected column to accommodate the contents of its longest row (i.e, the contents of each entry in the selected column is displayed in full). To select a column, click on any column entry. Note that this does not work for all tables.

The Input Data Connection editor consists of:

Data source selection

Data Location – click on Select to identify the data source type, and to locate and select the file or database table to use as the data source.

Logical characteristics selection

Logical Characteristics – logical characteristics tree/table displays all the logical data sources that are published to the node in the system composition where the input data connection component has been created. Use the filters to identify the logical data source characteristics to map to the physical characteristics in the data file or database table.

Select Logical Data Sources – select to open the Logical Data Source Select dialog from where the user can limit the number of Logical Data Sources displayed. The Select Logical Data Sources icon will indicate when the number of Logical Data Sources displayed has been reduced.

Show Table View – toggle display of logical characteristics between tree or table view. The table view shows the full characteristic name, including path name:

Physical characteristics selection

Physical Characteristics – physical characteristics table displays all the physical characteristics in the data file or database table. Use the filter to identify the physical characteristics to map to the logical data source characteristics.

Mapped characteristics selection

Mapped Characteristics - use the mapping buttons to map the logical data characteristics to the physical characteristics.

Automap – automatically tries to map characteristics from the Logical Data Sources to the set of physical characteristics in the data file or database table.

Map – map characteristics from the Logical Data Sources to the set of physical characteristics manually.

Unmap – unmap mapped characteristics individually.

Unmap All – unmap all mapped characteristics.

Valid - a validation warning/error will be shown if the logical and physical data types are not compatible.
