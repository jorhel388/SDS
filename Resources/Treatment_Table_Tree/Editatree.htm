Edit a tree

A tree consists of:

  • tree splits that form the graphical representation of the segmentation rules which together form the tree. Tree splits contain the information used to group those records which are to be treated in the same way.
  • leaf nodes, the end points of the tree.
  • outcomes, which are used to describe the expected treatment, actions, values and classification that will be applied to each record falling into a given outcome.
  • attachment, the component that will be processed when a record falls into a given leaf node.

An outcome can be associated with one or more leaf nodes so the same outcome and associated component can be applied to multiple leaf nodes.

To edit a tree

Add a referenced component to a leaf node

Segmentation components or segmentation rules can be added to any of the leaf nodes of the tree to form tree splits. Components added from the Resources window are referenced by the tree and other components that use them.

To add a referenced component to a leaf node

  1. With the Tree editor open click on the Resources window. The valid component types will be listed.
  2. Expand the component type list to display all the available components of that type. For example:
  3. Drag and drop the required component onto the leaf node you require.
  4. The new tree split will be added to the tree. The new tree split will provide alternate pathways for records that satisfy the criteria defined in this new segmentation rule.
  5. Repeat steps 2 and 3 until all the rules you require have been added to the tree.

You can now go on to define leaf node names and outcomes to your tree.

or

Insert an embedded component onto a leaf node in a tree.

Components can be referenced from within the tree (this means that they can be changed from outside of the tree and may be shared by other components). Alternatively, a component can be created from within the Tree editor and will be embedded into the tree. This means the component details are only used by this tree and can only be edited from within the tree.

  Only Class Set, Matrix, Boolean Expression and Segmentation Tree are supported for this version.

To add an embedded tree component onto a leaf node

  1. With the Tree editor open right click on a particular leaf node and select Insert Embedded. The Insert Embedded Component dialog is displayed.
  2. Overtype New Tree Element with a unique name (within the tree) for the component and then select the required component type.
  3. Click on the OK button to confirm the selection and close the dialog.
    The system will open the editor for the component you have chosen.
  4. You will now need to edit the embedded component. See the relevant topics within Class Set, Matrix, Boolean Expression and Segmentation Tree.
  5. Once you have finished editing the component click on the Close Internal Editor button.
    The component will be added to the tree as a new split. The new tree split will provide alternate pathways for records that satisfy the criteria defined in this new segmentation rule.
  6. Repeat steps 1 and 5 until all the embedded segmentation rules you require have been added to the tree.

You can now go on to define leaf node names and outcomes to your tree.

Convert an embedded or referenced segmentation component

Segmentation components, such as Boolean Expressions, Class Sets, Matrices and Segmentation Trees can be referenced from within the tree (this means that they can be changed from outside of the tree and may be shared by other components). Alternatively these segmentation components can be created from within the Tree editor and will be embedded into the tree. This means the component details are only used by this tree and can only be edited from within the tree.

Should the user wish to change an embedded segmentation component to a referenced segmentation component or a referenced segmentation component to an embedded segmentation component, in the Tree editor there is a Convert option.

To convert a segmentation component

  1. Within the Tree editor open, on any of the tree splits, right click and select Convert.


    The system will open the Convert Component dialog.
  2. Type the name you require in the Convert To box.
    3.   When you are converting an embedded component into a referenced component, the system will not allow you to use a name that already exists in the folder that is listed in the Reference component's folder path.
    Either change the name or click on the Change button and select a different folder.
  1. Click on the OK button.
    The system will convert the component.

If you have converted an embedded component to a referenced component the new referenced component will appear in the Resources window and be available for use in other components. If you have converted a referenced component, the referenced component will still exist in the Resources window, but a new embedded component will exist in the editor.

Create an outcome for a tree.

Outcomes are assigned to the leaf nodes of a tree. Leaf nodes assigned the same outcome will have the same action/Treatment applied to them.

To create an outcome for a tree

  1. With the Tree editor open, right click in the Outcomes area and select Add Outcome.

    An outcome will be created with a new colour and a default name.
  2. Replace the default name with a new unique name for the outcome.
  3. Double click on the outcome colour to change an outcome colour (if desired) and select a new colour from the Pick a Colour screen.
  4. Repeat for all the outcomes required.

You will now have the outcomes you require for the tree.

Assign a Treatment Table Design to a Treatment tree

A Treatment Tree can be created using Add Component from the Explorer window.

When Add Component is used to create a Treatment Tree no Treatment Table Design will be assigned to the tree. A Treatment Table Design will need to be assigned to the Treatment Tree in order that Treatments can be assigned to the outcomes of the tree.

To assign a Treatment Table Design to a Treatment Tree

  1. With the Treatment Tree editor open click on the Resources window, and expand the Treatment Table Design list to display all the available Treatment Table Designs.
  2. Drag and drop the required Treatment Table Design onto the Treatment column within the Outcomes area.



    The Treatment Table Design will be assigned to the Treatment Tree.

Treatments from the Treatment Table created using this Treatment Table Design can now be assigned to outcomes in the tree.

Assign a Treatment to an outcome

In order for a Treatment Tree to be deployed all the leaf nodes must have an outcome assigned to them. An outcome contains a description of the Treatment that is to be carried out at the leaf node, a colour and a component. It is the component that is assigned to the outcome that will be processed at runtime if a record falls down a particular leaf node.

To assign a Treatment to an outcome

  1. With the Treatment Tree editor open click on the Resources window.
  2. Click on the Expand + button next to Treatment Tables to display the Treatment Tables.
  3. Drag and drop the Treatment Table onto the outcome you require
    4.   If the Treatment Table you have selected is not using the same Treatment Table Design as the tree the system will display the following message.
    Selected Treatment Table is not compatible with the Treatment Tree.
  1. Click on the OK button to close the message dialog and repeat step 3 to select an appropriate Treatment Table.
    The system will open the Select Treatment dialog.
  2. In the Search field type the word or part of a word that makes up the name of the Treatment you require.
    The Select Treatment dialog will focus in on a particular Treatment or Treatment Tables that match this word.
    3.   If the Select Treatment dialog is displaying the Treatments in a tree view the Treatment Tables will need to be fully expanded to see all the Treatments that match the word(s).
  1. Select the Treatment you require.
    2.   Treatments can be assigned from different tables provided the Treatments are based on the same Treatment Design.
  1. Click on the OK button.
    The Select Treatment dialog closes and the Treatment you have selected is added to the outcome.
  2. Repeat steps 1 and 6 until all the outcomes you require have had Treatments assigned.
  3. From the Select Treatment dialog you can select a number of Treatments.
  4. Select all the Treatments you require using your Ctrl key and your Shift key on your keyboard.
  5. Click on the OK button.
    The Select Treatment dialog will close and all the Treatments that you have selected will be assigned to the Outcomes area as individual outcomes.

You can now go on to assign outcomes to your tree.

Clear a Treatment Table Design from a Treatment Tree

A Treatment Table Design will need to be assigned to the Treatment Tree in order that Treatments can be assigned to the outcomes of the tree. Treatment Table Designs can be removed from Treatment Trees.

To clear a Treatment Table Design from a Treatment Table

  1. With the Treatment Tree editor open, within the Outcomes area, right click on the Treatment column and select Clear Treatment Table Design.

    The Treatment Table Design will be removed from the Treatment Tree.
    2.   If you clear the Treatment Table Design from the Outcomes area, (the column heading) all the assigned Treatments will also be removed.

For Treatments to be assigned to the outcomes of a tree another Treatment Table Design will need to be assigned to the tree.

Assign an outcome to a leaf node

In order for a tree to be deployed all the leaf nodes must have an outcome assigned to them. An outcome contains a description of the action/Treatment that is to be carried out at the leaf node, a colour and a component. It is the component that is assigned to the outcome that will be processed at runtime if a record is assigned to a particular leaf node. An outcome can be assigned to one or more leaf nodes. Leaf nodes assigned the same outcome will have the same action/Treatment applied to them. In a Segmentation Tree you can have unassigned outcomes. In the outcomes area these are displayed with the following icon.

The user can determine how the outcomes are displayed in the tree by right clicking on an outcome in the tree and selecting Outcome Display followed by Text, Colour or Mixed.

  Text - will display only the names of the outcome assigned to the leaf node
Colour - will display only the colour of the outcome assigned to the leaf node
Mixed - will display both the colour of the cell and the outcome name assigned to it

To assign an outcome to a leaf node

  1. With the Tree editor open and in the Outcomes area, click on the outcome you wish to assign.
    The Assign outcome button on the tool bar will automatically become activated.
    2.   You must already have created the outcome(s) and the leaf nodes to which they are to be assigned.
  1. In the Tree editor click on the outcome of the leaf node that you wish to assign the outcome. The same outcome will be assigned to any leaf nodes you select until you select another outcome in the Outcomes area.
  2. Repeat as necessary to assign an outcome to all of the leaf nodes.
  3. Select how the colour and the text is to be displayed by right clicking on any outcome name in the Tree editor and selecting Outcome Display followed by Text, Colour or Mixed.

Each outcome should now have an outcome assigned. Those leaf nodes that have not had an outcome assigned will have <<Unassigned>> displayed in the Outcome column, <<Undefined>> displayed in the component type column and the following blue question mark icon displayed on the leaf node itself.

Define a leaf node name

Each leaf node of a Segmentation Tree should have a leaf node name. The leaf node name is a user defined description that identifies the action that will be applied to any record that has been assigned to this leaf node.

To define a leaf node name

  1. With the Tree editor open left click on the first <<Leaf Node Name>> that needs defining and type a description.

Repeat until all the leaf nodes that need to have a description given to them have been completed. Auto Generate that is access by right clicking underneath the Leaf Node Name column in the Tree editor enables the user to automatically generate leaf node names in a tree if required.

The tree will now be ready for use within other components.
