Strategy Design Studio Help System overview

 

The functionality of using the F1 key to display an associated Help topic acts inconsistently within Internet Explorer and Microsoft Edge if the browser is already open. If this is not the Help topic you expected to have displayed:

  • use the Search or Table of Contents in the Help to locate the required topic
  • close the browser and reselect the F1 key
  • change the browser used to display the help using the Tools > Options and select the General Tab

This comprehensive Help System has been designed and written with all types of user in mind, from system designers and builders to system users. The aim of the help system is to enable the user to use the system effectively and confidently. Use of this help system will aid user performance giving a sense of satisfaction and understanding.

The Help System provides the user with informative overviews, instructive help procedures, examples, notes, tips and screen information.

Information Notices

The help system provides the user with information notices. These notices are iconised and highlighted pieces of information intended to provide the user with extra information.

There are 4 types of Information Notices used within the help system:

Information Notices Example
Note:

This information notice provides the user with extra information.
  Only users assigned the Security Administrator profile will have access to the Security Explorer window to edit security permissions.

Tip:

This information notice provides the user with information to speed up the process or to make it easier
  The BC uses 'IP' as a marker to indicate that the user specifies an IP address other than the default. The marker is not case sensitive, 'ip' or 'Ip' can be used as well.

Caution:

This information notice provides the user with information on the consequence of an action or the consequence of the lack of an action.
  The SIA displays errors and discontinues working if the user does not specify any of the above mentioned attributes.
Example:

This information notice provides the user with an example of a concept or instruction that has just been explained.
  A sample suite contains two child suites: Test and Production. The Production child suite contains one child suite: Scorecard. Executing 'Sample' causes the server to run all the reports in all the four suites. Executing 'Production' causes the server to run all of the reports in the 'Production' and 'Scorecard' suites. Executing 'Scorecard' runs only the reports in the 'Scorecard' suite. Executing 'Test' runs only the reports in the 'Test' suite.
