Results Data Definitions

The Results Data Definition allows users to control which characteristics are written to the results CSV file.

 

Even if a characteristic is not specified in the input file, if it is specified in the results data definition it will also appear in the Results file. So if that characteristic is populated in the execution of the test, it will be assigned values in the results file. Characteristics that are included in the results data definition but are not populated during the test execution are included in the results file, but are assigned the \0 Null value as having no associated value.
Define
Create a results data definition

A results data definition can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a results data definition

  1. From the Explorer window, right click at the required folder level and select Add component.
  2. Select Results Data Definition.
  3. In the Create component dialog enter the name of the results data definition.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.

    The Results Data Definition editor will open allowing you to edit a results data definition.
    The results data definition name will be listed in the Explorer window. The component is identified by the icon. If you do not wish the editor to open, keep the check box de-selected.

To define the Results Data Definition

  1. Click the Filter for Data Types button to limit the number of characteristics displayed in the Logical Characteristics table:


    The Filter for Data Types icon will indicate when the range of characteristic types displayed has been narrowed down.
  • Execution Input: Filters for those characteristics identified as inputs to the component being tested
  • Execution Results: Filters for those characteristics identified as outputs of the component being tested.
  • Input Data Connection: Filters for those characteristics included in the Input Data Connection

  1. Drag the required characteristics in the Selected Characteristics field, then save and close the embedded results data definition.

Re-ordering characteristics in the Result Data Definition editor

The Results Data Definition editor allows users to control which characteristics are written to the results CSV file.

Once a large number of characteristics have been added to the Results Data Definition, the Select All and Copy and Paste icons can be used to re-order the characteristics contained in the Result Data Definition editor.

To re-order characteristics in the Results Data Definition editor

  1. With the Results Data Definition editor open and the characteristics you require added to the editor.
  2. Click on the Select All and Copy icon. All the characteristic in the Selected Characteristics field will be copied.
  3. Open Excel (or Notepad) and paste into this application.
  4. Re-order the characteristics as required in this application.
  5. Copy the whole characteristic table.
  6. Select the first cell in the Selected Characteristics field and click on the Paste icon.
    The characteristics will be added to the Selected Characteristic field in the order that was defined.

The Results Data Definition is now ready for use.

The results data definition is now complete.
