Convert sub-components between embedded and by-reference types

The user can convert by-reference input data connection and results data definitions to embedded versions, and vice versa. Using this facility, a user can quickly create an embedded results data definition, for example, that is filtered narrowly by execution results; then convert this to a by-reference component that can be used and modified within a different test project.

To convert an embedded component to a by-reference component

  1. With the Test Project editor open, right click on the embedded input data component or results data definition, and select Convert from the context menu.
  2. The Convert Component Connectivity dialog is displayed:

  3. Enter a name for the new component in the Convert To field, and click on the OK button.

The new by-reference component name appears in place of the previous embedded component in the editor, and the component is listed in the Resources window.

  The component created as a result of the conversion must be of a type allowed for the folder in which it is being created.

To convert a by-reference component to an embedded component

  1. With the Test Project editor open, right click on the by-reference input data component or results data definition in the editor, and select Convert from the context menu.
  2. The Convert Component Connectivity dialog is displayed:

  3. Enter a name for the new component in the Convert To field, and click on the OK button.

The new embedded component name appears in place of the previous embedded component in the editor.
