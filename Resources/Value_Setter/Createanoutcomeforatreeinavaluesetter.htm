Working with Outcomes in Value Setters

Outcomes are assigned to the leaf nodes of a tree in a value setter. Leaf nodes assigned the same outcome will have the same result characteristic and associated value or value characteristic applied to them.

Generate outcomes automatically

Once all the leaf nodes that need to have a description given to them have been completed, the user can use the Generate Outcomes option to automatically generate outcomes for the Outcomes area. The system will use the leaf node names that have been defined as the outcome names.

To auto generate an outcome name for a tree in a value setter

  1. With the Value Setter editor open right click underneath the Outcome column in the Value Setter editor and select Generate Outcomes.


  2. The outcome names and colours will be automatically generated using the descriptions you have provided (in the Leaf Node Name column of the segmentation tree editor). These will be added to the Outcomes area and assigned to the leaf nodes of the tree.

Those leaf nodes that have not had a description assigned to them will remain <<Unassigned>>.
The original outcome name that was created when the tree was created will not be assigned to any leaf node. The following icon in the Outcomes area will indicate that this outcome name is inactive.

An Output column and an output characteristic and a output value characteristic or value characteristic need to be assigned to these new outcome names in the Outcome area.

Assign an outcome to multiple leaf nodes

In addition to being able to assign an outcome to individual leaf nodes it is possible to assign the same outcome to all the leaf nodes of the tree in the value setter or all the unassigned leaf nodes.

To assign an outcome to multiple leaf nodes in a value setter

  1. With the Value Setter editor open and in the Outcome table click on the outcome you wish to assign.
    The assign outcome button on the tool bar will automatically become activated.
  2. Click underneath the Outcome column in the Value Setter editor.
    The system will display the following dialog box.


     To overwrite the outcomes click on the split header row underneath the Outcome column. This will update the outcomes in the sub tree below the selected split header.
     
  3. Select All to overwrite all the outcomes in the value setter's segmentation tree with the new colour.
  4. Select Unassigned only to assign the new colour to those leaf nodes in the tree that are currently <<Unassigned>>.

The outcomes of the tree will be updated.

Copy and paste outcome values

To ease definition of the Outcome area in Value Setter the user can use Copy (Ctrl+C) and Paste (Ctrl +V) to define the content of the Outcomes area.

To copy the contents of the outcomes area into Excel

  1. With the Value Setter editor open, in the Outcomes area, select all the cells that you wish to copy.


    2.   In the above example "Do Nothing" and the value characteristic "Credit Card Balances" have been added to illustrate the functionality.
  1. Using your keyboard copy the contents using the Ctrl+C keys.
  2. With Excel open, use Ctrl+V on your keyboard to paste the contents of the Outcomes area into Excel.

Using the above example the following will be pasted:

  • Outcome Name - the contents will match what has been entered
  • Colour - the colour code will be pasted
  • Active - True will be pasted into Excel where the outcome is being used, False where the outcome is not being used in the Value Setter
  • Value - will match the value entered in the cell
  • Value Characteristic - fully qualified name of the characteristic will be pasted as string into the cell. The underlying characteristic reference is lost as this is pasted as a simple text string

The contents of the Outcome area can now be amended as required in excel.

To paste content from excel into the outcomes area

  1. With Excel open, select the cells that you wish to copy.
  2. Using standard Excel functionality copy these cells.
  3. With your Value Setter open, ensure that the number of outcomes match the number that you are copying (the number of rows in Excel match the number of Outcome Names).
  4. Select all the cells, then, from your keyboard use Ctrl+ V to paste the contents from your clipboard into the Outcomes area of Value Setter.

The contents of the copied cells from Excel will be pasted.

The following validation issues will need to be corrected:

  • Where a duplicate colour exists
  • Where the characteristic value entered is a string, but the output header type is not a string
  Where a characteristic is being assigned, the pasted text fully qualified name would need to be replaced with the actual characteristic reference (for example by dragging the Logical Data Source from the Select Characteristic area of the Value Setter).
Change an outcome colour

Outcomes are colour coded. A leaf node in the value setter's segmentation tree is coloured according to the outcome assigned to it making it easier to view and identify leaf nodes that have been assigned the same outcome. The colours are selected from a palette of colours. A default colour is used when first defining the outcomes. It is possible for the user to change the colour for an outcome at any time. The system will not allow the user to assign the same colour to more than one outcome.

To change the colour of an outcome

  1. In the Outcome area double click on the outcome colour you wish to change.

    A palette of colours will be displayed in the Pick a Colour screen.
  2. Select the required colour from the palette and click on the OK button.

    The outcome colour will be changed to the new colour.

Any leaf nodes that have already been assigned the outcome will change to the new colour.

Unassign

The user can unassign an outcome from within the Outcomes area. When an outcome that has been assigned to a leaf node is unassigned, <<Unassigned>> and <<Undefined>> will be displayed next to the leaf node, and the leaf node will be displayed with the following icon.
The outcome in the Outcomes area will be displayed as inactive .

To unassign an outcome in the Outcomes area

  1. In the Outcomes area of the Value Setter editor, right click on an Outcome Name that has been assigned to some leaf nodes and select Unassign Outcomes.

The Outcomes area will be updated and the leaf nodes will be updated with <<Unassigned>> and <<Undefined>>.

Clear an outcome and associated output value

The user can clear outcomes and associated result characteristics and associated value or value characteristics that have been assigned to leaf nodes.

To clear an outcome from a leaf node

  1. With the Value Setter editor open, right click on the outcome and select Clear Outcomes or select the Clear Outcomes icon from the tool bar and click on the outcome you wish to clear.

The outcome will be removed from the leaf node and the outcome will be reassigned with <<Unassigned>> and <<Undefined>>. The leaf node will be displayed with the following icon.

Merge

Two or more outcomes can be merged together to form one outcome in the Outcomes area of the value setter.

To merge an outcome

  1. In the Outcomes area select the outcomes you wish to merge, with your cursor over the outcome you want to keep, right click and select Merge Outcomes.
  2. In the Merge outcomes dialog, click on the OK button to confirm the merge.

The outcomes will be merged; all leaf nodes will be updated.

Delete

Outcomes can be deleted from the Outcomes area of the Value Setter editor. If an outcome that is assigned to a leaf node is deleted, the leaf node will have the outcome and the output values or value characteristics removed and <<Unassigned>>and <<Undefined>> displayed in its place.

To delete an outcome

  1. In the Outcomes area right click on the outcome you wish to delete and select Delete Outcomes.
  2. In the Delete outcomes dialog, click on the OK button to confirm deletion.

The outcome will be deleted from the list. Any leaf nodes already assigned the outcome will be reassigned with <<Unassigned>>and <<Undefined>>, the leaf node will be displayed with the following icon.
