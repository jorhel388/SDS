Value Setter editor

The Value Setter editor enables the user to create a tree using tree splits to define segmentation levels (leaf nodes) to which an output characteristic and an associated value or value characteristic can be applied.

The value setter editor consists of:

Toolbar

The Value Setter editor's toolbar is used to alter the view of the tree seen in the value setter editor and to assist the user in defining a tree.

Test - launches the Tester for the value setter.

Copy component image to clipboard - select to copy the complete tree, including the column headers contained in the editor, as an image to the clipboard from where you can paste this image into any appropriate application.

  Selections made using the Column Display icon will not change (reduce) the number of columns included in the image created using the Copy component image to clipboard functionality.

Assign outcome - adds the outcome colour that the user has selected in the Outcome table to the chosen leaf node.

Clear outcome - removes the outcome colour from the selected leaf node and sets the outcome to <<Unassigned>>

Add bookmark - allows the user to bookmark specific split headers in the value setter's tree. When the contents of a value setter are displayed in the Navigator window the bookmarks are displayed separately. Clicking on a bookmark in the Navigator window will open the tree in the value setter editor at that point in the tree, giving the user quick access to a specific split header in the tree.

Add annotation - select to add annotation to any node of the value setter's tree. Once some annotation has been added, the user can choose to display, edit, remove, hide all or show all annotations by using options selected from the right click menu accessed from any node.

Tree Table View - select to display only the leaf nodes of the value setter's tree. This view has been designed to make it easier for the user to assign outcomes.

Validate - select to check the tree used in the value setter and ensure that every component that the value setter's tree references or uses is valid. Valid means the component is complete, it is of the correct 'format', any links to other components (where applicable) are valid and the root node ids have been configured. If the tree is invalid information will be provided in the Output window.

Tree editor - is the area of the Value Setter editor where the tree splits, (the graphical representation of the segmentation rules) are applied together to form the tree. Tree splits contain the information used to group those records which are to be treated in the same way. Leaf nodes are the end points of these splits where an output characteristic and associated value or value characteristic are assigned to the outcome. The leaf node name is a user defined description that identifies the action that will be applied to any record that falls into this leaf node.

Outcomes area - is the area of the Value Setter editor where the names of outcomes are created, their colour defined and the output characteristic and value are assigned. Outcomes are linked to the output characteristic(s) and associated value(s) or value characteristic(s) that will be assigned to a record that falls into a specific leaf node. There is no limit to the number of output characteristic columns and their associated values that can be assigned to an outcome in the Outcomes area. Outcomes are assigned to leaf nodes in the tree editor. Every leaf node must have an outcome assigned to it in order for the tree to be valid. An outcome can be assigned to more than one leaf node.

Select Characteristic - is the area of the Value Setter editor where the user can locate the characteristic they wish to use as the output characteristic(s) or value characteristic(s). By typing in a word or part of a word the Select Characteristic dialog will find all the instances of characteristics that have that word in the name. The user then drags the characteristic they require into the outcome table.

- the Filter for Data Types icons allows the user to limit the display of logical data characteristics to one or more types. The Filter for Data Types icon will indicate when the range of characteristic types displayed has been narrowed down.

Display or hide columns

When the value setter is first opened the five columns used in the value setter editor will always be displayed. The user can hide these columns if required.

To display or hide a column in the value setter tree display

  1. In the Value Setter editor, click on the Column Display icon.

  2. From the list of columns, ensure that the column you wish to hide is no longer selected. (It will not have a tick displayed next to it).
  3. To display a column, from the list of columns ensure that the column you wish to show has a tick displayed next to it.

The tree display will be updated.

  Copy to Clipboard in the tree editor creates a copy of the complete tree including all the column headers contained in the editor. The selections made using the Column Display icon will not change (reduce) the number of columns included in this image.
 

This view is currently not saved with the value setter when the value setter is saved and closed.
Currently when you re-open your value setter the five columns will open as before.
