Building a solution

A solution is built using Decision Process Flows that are deployed into the runtime environment. Each Decision Process Flow contains a number of linked processes that are executed in turn. The type of processes assigned and configured in the Decision Process Flow editor determines how a record is processed.

For more information on building and defining a Decision Process Flow refer to the Decision Process Flow overview.

For ease the processes that can be used in a Decision Process Flow have been grouped into the following groups:

  • Trees - groups all the tree type processes that can be assigned to a Decision Process Flow which enable users to assign specific component types to the leaf node/outcomes of the trees together, e.g. Decision Setter Tree, Index Tree for example.
  • Processes that manipulate values - groups the processes that can be used in a Decision Process Flow to alter values in a record into one group.
  • Models - groups those process that are used in a Decision Process Flow to apply different models.
  • Treatments - groups the Treatment Tables process that can be used in a Decision Process Flow.

Once your solution has been built it should be tested and, finally, deployed to the runtime environment.
