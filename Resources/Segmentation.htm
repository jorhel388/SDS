Segmentation

Within the Studio, segmentation devices are used to group items such as applicants/customers together.

There are five methods of segmenting your portfolio. A single characteristic can be:

  • used to create a boolean expression resulting in a 'true' or 'false' result - Boolean Expression
  • classed into intervals - Class Set
  • combined with another characteristic to enable outcomes to be assigned to individual cells - Matrix
  • used as input to a table that sets one or more output values - Index Table
  • Boolean Expressions, Class Sets and Matrices can be combined to form a Segmentation Tree
  • segmented to use a sample population to which a 'control' group is applied or an alternative treatment is applied using a Test Group Set. The 'control' group is referred to as the Champion and any alternative test groups that are evaluated against the Champion are referred to as the Challengers. Hence the term Champion/Challenger - the ability to segment against different test groups.

Class Sets, Matrices and Index Tables can be created using Logical Data Sources as well as Logical Data Models. Defining these components using a Logical Data Model enables these components to be used in User Defined Functions and other scripting components and so increases their usability, since they can be used by multiple instances of characteristics.

 

Class Sets, Matrices and Index Tables which have been defined against Logical Data Models can only be used in scripting components.
