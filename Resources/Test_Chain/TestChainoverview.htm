Test Chains

Chaining is the process of linking together (or 'chaining') two or more Decision Process Flows, such that control can be passed from one Decision Process Flow to another within a single execution call to the Decision Agent. The chaining takes place at the conclusion of the processing of the current flow, if the Decision Agent detects that a request has been made to chain on to another Decision Process Flow.

  Test Chain will only be able to test Decision Process Flows that belong to the same Solution.
Overview

In order to be able to use chaining a Logical Data Source characteristic containing the Decision Process Flow's 'Alias' and 'Signature', needs to be defined.

To trigger chaining, the 'Alias' and 'Signature' characteristics need to be set to indicate the identity of the next Decision Process Flow to be processed. Note that these settings don't take effect until the end of the flow currently being processed. The recommended way to manage the setting of these key system fields is to configure a Value Setter to allow the Alias combinations to be defined as outcomes.

For more information on adding a signature and setting an alias see the topics Add a signature to a solution and Set the alias for the Decision Process Flow.

Create Test Chain

A Test Chain can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a Test Chain

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Test Chain.
  3. In the Create component dialog enter the name of the Test Chain.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.

    The Test Chain editor will open allowing you to create the test chain you require.

    The Test Chain name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window right click on the Test Chain and select Open.

To define a Test Chain

  1. With the Test Chain editor open, click on the Resources window and expand the Decision Process Flow list to display all the available decision process flows.
  2. Drag and drop the required decision process flow onto the first row in the Test Chain editor.
  3. Repeat step 2 until all the Decision Process Flows that are required for the chaining have been added to the Test Chain editor.
  4. Type a value for the Chaining Limit in the Chaining Limit field.

    The default value is 10.
  5. Next to the Signature characteristic field, click on the Browse button.

    The Select Characteristic dialog will open.
  6. In the Search field type the word or part of a word that makes up the name of the characteristic.
    The Select Characteristic dialog will focus in on a particular characteristic or set of characteristics that match this word.
    7.   If the Select Characteristic dialog is displaying the characteristics in a tree view, the logical data source will need to be fully expanded to see all the characteristics that match the word(s).
     
  7. Select the characteristic you require.
  8. Click on the OK button.
  9. The Select Characteristic dialog closes and the characteristic you have selected is added to the Signature characteristic field
  10. Next to the Alias characteristic field, click on the Browse button and repeat steps 6 to 9 to select the characteristic that holds the alias value
  11. Within the Start column, select the radio button next to the decision process flow from where you wish the execution to start.

The Test Chain is ready to be tested.

Test a Test Chain

Once the user has successfully created a Test Chain component, the user will be able to test it using the Batch or Interactive Tester.

The user can test a Test Chain either by manually typing in data for the input characteristics referenced in the Test Chain or by performing a test against a known data source.

To perform an interactive test

To test a Test Chain manually by entering data into the relevant fields for the input characteristics, use the Interactive Tester.

To perform a batch test

To test a Test Chain using data from a .csv file, from the Explorer window, right click on the component and select New Test Project to use the Batch Tester.
