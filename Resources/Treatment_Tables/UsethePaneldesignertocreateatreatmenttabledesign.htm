Use the Panel designer to create a Treatment Table Design

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the Treatment Table Design will form a column in the Treatment Table.

The Panel Designer is used to create a Treatment Panel; a Panel from which Treatments can be created. Treatments are created by selecting the required controls and arranging them on the Panel Designer.

  Once a control has been added to the Treatment Panel the user will be prevented from using the table to create Treatments. They will not be able to enter data directly into the table. Instead they will need to use the Treatment Panel. This is to ensure that the validation script is not by-passed.
Create Treatment Table Design

A Treatment Table Design can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a treatment table design

  1. From the Explorer window right click at the required folder level and select Add a component.
  2. Select Treatment Table Design from the list of available components.
  3. In the Create component dialog enter the name of the Treatment Table Design.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.
    The Treatment Table Design editor will open allowing you to edit the Treatment Table Design.
    The Treatment Table Design name will be listed in the Explorer under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window right click on the Treatment Table Design and select Open.

Creating the Panel Design

To create a Treatment Panel Design

With the Treatment Table Design editor open click on the icon to display the Panel Designer.

Add a control

A Treatment Panel Design is created by selecting the required controls and adding them on the panel.

When a Control is added to a panel the Add Form Control dialog is automatically activated. It is from this dialog that you can set whether the control is for Panel use only or will be linked to a column name that has been already created in the Column View Table. Linking a control to a column name ensures that the values that are selected or entered are returned to the column name and the characteristic that has been mapped to it.

Controls can be used for:

  • Panel use only
  • Assigned to a column name that has been mapped to a Logical Data Source characteristic (values returned at runtime)
  • Assigned to a column name that has been mapped to a 'local' characteristic (required to perform calculations, but not returned at runtime)

To add a control

  1. With the Treatment Table Design editor open and with the Panel Designer in view, in the Palette locate the Form Control category.
  2. Expand the Form Control category to display all the available controls that can be used in the Panel.
  3. Drag and drop the required Control onto the panel.
    The system will open the Add Form Control dialog.
  4. From the drop down box select the column name you require.
    5.  

    To assign a control to a column name, the column name must already exist in the Column View Table.

    You will not be able to assign a control to a column name once it has been applied to the panel.
  1. To move this Control to another position on the panel, click on the border and then drag it to another position on the form.
    2.  

    If a Container control is moved, then all contained controls will also be moved.

    To select a Control that is inside a Container control, make sure that the Container control is 'at the back', using the Send to Back right click option.

    You cannot reposition the Container 1 since this is the Panel Design itself
  1. Repeat this process to add all the Controls that are required to create the form.
  You will not be able to select a column name that has already been assigned to a control, since this column name will be removed from the drop down list that is displayed in the Add Form Control dialog.

Every Control once it has been positioned on the form will need the values that can be selected or entered in it configured. This is carried out by accessing the properties for each control.

Configuring a control

Every control used within a Treatment Table Design will need the values that can be selected or entered in it configured. This is carried out by accessing the properties for each control. The Properties window can be accessed by selecting Properties from the Window menu.

To configure a control

  1. With the Treatment Table Design editor open,
    either:
    - click on the row you require;
    or:
    - once a control has been added to the Panel Designer, select it.
    The Properties window for the control type that has been selected will be displayed in the Properties window.
  2. In the field next to the property description specify the property and enter the information that you require.
    3.   From where you select the control affects the property that is listed in the Properties Window.

There are eight different types of Control that can be configured. The Control you select will affect what needs to be configured. To learn more about the common and unique properties of Controls see the topic Control Properties.

Icon Control Additional Information

Container

Container adds a Container to the treatment panel design. A container allows the nesting (one inside the other) of other controls.

Container 1is the Panel design itself.

Check box

Check box adds text and a check box to the panel design. This allows the user to select or deselect it by clicking on it. Within a panel design the user can select more than one checkbox.

Drop Down box

Drop Down box adds either a 'combination' text list/edit box or a 'combination' numeric list/edit box to the panel design depending on the data type of the column to which the control has been assigned. This allows the user, depending on how this box has been configured, to select from a drop-down box either a list of pre-entered values or from an external list of values or enter values themselves.

Label

Label adds text to the panel design

List box

List box adds either a text list box or a numeric list box to the panel design depending on the data type of the column to which the control has been assigned. This allows the user to select from a list of pre-entered values or select from an external list of values and use the values contained in the file.

Radio button

Radio button adds text and a radio button to the panel design. Radio buttons are typically grouped together. This allows the user to select one, causing another to be deselected.

Slider

Slider adds a slider control to the panel design. This allows the user to use a slide rule to easily select a value within a defined range.

When a slider is added to the panel design only columns of integer data type will be available for selection.

Text Box

Text box adds a text edit box to the panel design. This allows the user to key in some text.

Move a Control

A Treatment Table is designed by selecting the required controls and arranging them on the panel. Once a control has been added to the panel it can be moved.

To move a control

  1. With the Treatment Table Designer editor open and the Panel Designer active,
    either:
    click on the Control that needs moving. The control will be selected.
  2. Drag it to the position you require.
    or:
  3. Within the Properties Window type new values for the x and y position of the control.
    or:
  4. Using the arrow keys on your keyboard you can move the control to the position you require.

The control will be moved.

  If a container control is moved, then all controls held in the container will also be moved. You cannot reposition Container 1 since this is the Panel design itself.
Resize a control

A treatment table is designed by selecting the required controls and arranging them on the panel. Once a control has been added to the panel the control can be resized.

To resize a control

  1. With the Treatment Table Designer editor open and the Panel Designer active,
    either:
    click on the Control that needs resizing. The control will be selected.
  2. Click on the black box nearest to the resizing that you wish to make.
  3. Drag the black box until the control is the size you require.
    or:
  4. Within the Properties window type new values for the Height (px) and Width (px) values.

The control will be resized.

  Resizing is not possible if multiple controls are selected.
Rename a Control

When a control is added to the Panel and assigned to Panel Use Only it will be given a unique name by the system. To help identify the different controls within the panel and within the Resources window it is recommended that they are renamed.

To rename a control using the Properties window

  1. With Treatment Table Design editor open and the Panel Designer in view select the control to activate the Properties window.
  2. In the Properties window, next to the Control Name, either type directly into the field or click on the button to open the Default Data dialog to and type the name you require.
    3.   When a control has been assigned to a column, the name of the control cannot be amended.

The system will check to ensure that this name is unique within the treatment table design and update the name of the control in the Properties window and Resources window.

Delete a Control

A Treatment Table is designed by selecting the required controls and arranging them on the panel. Once a control has been added to the panel the control it can be deleted.

To delete a control

  1. With the Treatment Table Designer editor open and the Panel Designer active,
    either:
    right click on the Control on the panel and select Delete.
    or:
    select the Control and press the Delete key on the keyboard.

The Control you have selected will be deleted.

  If the control you have selected to delete is a Container control, all the controls held within the container will also be deleted.
  If you delete a control that is referenced in any of the scripts for the treatment, the script(s) will no longer work. You must amend the relevant scripts
Ordering the controls on the panel

A Treatment Table is designed by selecting the required controls and arranging them on the panel. When controls are placed near to each other one control may obscure another. When controls are put inside a Container control of these controls may no longer be selectable, since the Container itself may be obscuring them. Both of these problems are caused by the order in which the controls have been placed on the panels and whether they are placed at the back or the front of the panel in relation to each other. By using the Send to Back and Bring to Front options, controls can be ordered so that labels are no longer hidden by the edges of other controls and controls located inside a Container can be selected.

To send a control to the back of the panel

  1. With the Treatment Table Design editor open and the Panel Designer in view, right click on the Control and select Send to Back.

The control will be sent to the back of the panel, and be displayed behind any controls that exist near to it.

  Send to Back will not send the control behind Container 1, the Panel design itself

To bring a control to the front of the panel

  1. With the Treatment Table Design editor open and the Panel Designer in view, right click on the Control and select Bring to Front.

The control will be brought to the front of the panel, and be displayed in front of any controls that exist near to it.

Define the tabbing order

To help the user create Treatments more easily the designer can define the tabbing order of the Treatment. Once this order has been set the Tab key on the keyboard can be used by the user to move the focus within the Treatment Table to the next field that requires an entry, so speeding up the inputting process.

It will only be possible to define the tabbing order when those controls that require values applied or selections made to them have been added to the Panel Designer. To learn more about adding controls to the Treatment Table Design refer to the section, Add a control.

To ensure that the right controls are ordered correctly it is recommended that prior to defining the tabbing order the controls are given unique descriptions.

To define the tabbing order

  1. With the Treatment Table Design editor open and the Panel Designer active, ensure that the Panel View Table view is active by selecting the following icon:

    The names of all the controls that have been added to the panel will be listed. They will be listed in the order in which they were added to the panel. The order in which they are listed will be the tabbing order.
  2. In the table, select the name of a control that you wish to move.

  3. Drag and drop this to the position you require.
  4. Repeat step 2 to 3 until all the controls are listed in the correct order.

The tabbing order will have been changed

Creating Treatment Table script

Treatment Table script is created by dragging the names of controls, column names or Logical Data Characteristics from the Resources window to the specific tab where they are going to be used and adding script by freehand or by dragging and dropping functions from the Palette. To find out more about using Script see the Derived Data Script overview.

  User Defined Functions are not currently supported in Treatment Table script.

The tab to which the object is being dragged will affect whether the script is automatically converted into valid script or whether the Add Form Property dialog is activated so that the appropriate command can be selected. Once dropped onto the script area the system converts the information into valid script. The following lists the commands that can be chosen and how these commands appear in the script area once they have been dragged there.

Command Script Additional Information

Value

Used in all tabs.

Appropriate operators and values need to be added to the script. A space needs to be added to either side of the operator. Double quote marks need to be added to the value.

Visible

Used in the Control Script Tab

Once dropped onto the script area the system converts the information into valid script. .visible = 1 ensures that the control will be displayed

Not Visible

Used in the Control Script Tab

Once dropped onto the script area the system converts the information into valid script. .visible = 0 ensures that the control will be hidden from the user.

Enable

Used in the Control Script Tab

Once dropped onto the script area the system converts the information into valid script. .enable = 1 ensures that the control will be available for use by the user.

Not Enable

Once dropped onto the script area the system converts the information into valid script. .enable = 0 prevents the user from being able to activate the control. The control will be greyed out.

To create Treatment Table script

  1. With the Treatment Table Design editor open and the appropriate script tab activated you can drag and drop the appropriate names of controls, column names or Logical Data Characteristics to the script, add script freehand or using the required resources from the Palette you can:
  2. Add an operator or function to a script
  3. Click on the Compile Script button to check the script.

Once your script is valid you will be able to test it.

Define the Validation script

Within the Treatment Table Design script area there are three tabs. The Validation Script for a Treatment Table is written in the first tab and will produce error message(s) to prompt users that they have entered information into the tables incorrectly. The user will not be able create a Treatment by selecting the Update button unless the correction is made.

It will only be possible to write Validation script when those controls that require Validation script applied to them have been added to the Panel Designer.

 

In this example, if the Cash Card check box is selected and the Daily Limit List box is set to 0 then an error is displayed.

To define a Treatment Table Validation script

  1. With the Treatment Table Design editor open.
  2. Click on the following icon to open and select the Validation Script tab for the Treatment Table.
  3. Add script freehand or use the required resources from the Palette and Resources window to create your Table execution script.
  Use the following icon to display in the Resources window either the Logical Data Sources that are available or the columns and controls created for the table in the Column View and the Panel View.

    2. The system will provide you with information regarding the validity of the script. Details of any errors will be displayed to provide you with information so that you can correct them.

Define the Control script

Within the Treatment Table Design script area there are three tabs. The Control Script for a treatment table is written in the second tab and specifies what is shown or hidden on the form depending on the selections made by the user as well as how the Treatment is initialised.

It will only be possible to write Control script when those controls that require Control script applied to them have been added to the panel designer.

 

For a Treatment Table the contents of the Card Type container should only be shown to the user who is creating Treatments when the Assign Card radio button is selected, otherwise these controls should be hidden.

To define a Treatment Table Control script

  1. With the Treatment Table Design editor open.
  2. Click on the following icon to open and select the Control Script tab for the Treatment Table.
  3. Add script freehand or use the required resources from the Palette and Resources window to create your Table execution script.
  Use the following icon to display in the Resources window either the Logical Data Sources that are available or the columns and controls created for the table in the Column View and the Panel View.
  1. Click on the Compile icon in the tool bar to check the script syntax.

The system will provide you with information regarding the validity of the script. Details of any errors will be displayed to provide you with information so that you can correct them.

  You cannot test a Table execution script using Tester unless the script is valid.
Define the Execution script

Within the Treatment Table Design script area there are three tabs. The Execution Script for a treatment table is written in the third tab and enables calculations to be performed using characteristics located in the Logical Data Source and column names that refer to values returned to 'local' characteristics (characteristics created specifically for use in the panel), enabling values from one or more controls and/or characteristics to be used in an equation to generate an output that will be returned to the Logical Data Source Characteristic.

The Treatment Table Execution script tab is the only tab where Segmentation functions can be used. For more information on using Segmentation functions see Adding Segmentation Functions to script.

It will only be possible to write Execution script when those controls that require Execution script applied to them have been added to the panel designer.
