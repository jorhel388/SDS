Define a Treatment Table Column using the Column View

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the Treatment Table Design will form a column in the Treatment Table. Each collection of column names in the Column View will represent a Treatment in the Treatment Table.

Create Treatment Table Design

A Treatment Table Design can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a treatment table design

  1. From the Explorer window right click at the required folder level and select Add a component.
  2. Select Treatment Table Design from the list of available components.
  3. In the Create component dialog enter the name of the Treatment Table Design.
  4. Select the Open new components in component editor check box.
  5. Click OK.
    The Treatment Table Design editor will open allowing you to edit the Treatment Table Design.
    The Treatment Table Design name will be listed in the Explorer under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window right click on the treatment table design and select Open.

Define a column name

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the Treatment Table Design will form a column in the Treatment Table. Each name in the column name column will represent a Treatment in the Treatment Table.

To define a column name - the name for each Treatment

  1. With the Treatment Table Design editor open, in the Column Name column, type the name of the column.
  2. Press Enter

The name will be applied and used as the name of the column of the Treatment in the Treatment Table.

Assign a Characteristic Mapping to a row

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the Treatment Table Design will form a column in the Treatment Table. Each name in the column name column will represent a Treatment in the Treatment Table.

How you wish the column to be executed/used will effect the type of characteristic mapped to the row. There are two types of characteristic:

  • Logical Data Source characteristic - values created or entered in the Treatment Table will be returned to this characteristic at runtime
  • Local characteristic - values assigned to this characteristic are used in Execution script to enable calculations to be performed whose results will eventually be returned to an additional local characteristic using the script defined in the Execution Script tab. It is the local characteristic that will hold the initial value when the execution script for the Treatment is executed at runtime

To assign a Characteristic Mapping to a row

  1. With the Treatment Table Design editor open, in the Characteristic Mapping column, right click and select Assign Characteristic.

    The Select Characteristic dialog will open.
  2. In the Search field type the word or part of a word that makes up the name of the characteristic.
    The Select Characteristic dialog will focus in on a particular characteristic or set of characteristics that match this word.
    3.   If the Select Characteristic dialog is displaying the characteristics in a tree view, the Logical Data Source will need to be fully expanded to see all the characteristics that match the word(s).
  1. Select the characteristic you require.
  2. Click OK.
  3. The Select Characteristic dialog closes and the characteristics you have selected will be added to the column.

    Either String or Numeric will be assigned to the Data Type column depending on the characteristic chosen.

It is this characteristic that the values will be returned to when the Treatment is processed.

To assign a local characteristic to a row

  1. With the Treatment Table Design editor open, in the Characteristic Mapping column, right click and select Assign for 'Local' use.

  2. Since the characteristic will not have a predefined type, from the Data Type drop down box, select either String, Integer, Float, Decimal or Date.
  3. Define the other properties for this characteristic as required.
    4.   In order to assign a specific row to a Slider control the data type selected must be integer.

It is this characteristic that the values will be returned.

Select the Control Type for the Column

The Treatment Table Design - Column Table View editor enables the user to name the Treatment and define the rules for how the values entered in each Treatment will be processed at runtime.

Using the Control Type column the user can define whether a combo box or a text box will be set for the Treatment and the properties for this Control and which data type these controls will support.

To define a string combo box control

  1. With the Treatment Table Design editor open, click in the Control Type column and select Combo box from the drop down list.

    The Properties window will change to correspond to the control type you have selected and the data type of characteristic that has been mapped to this field.



    Within the Properties window, for the String Combo box the following information will be taken from the row itself, so cannot be configured:
    • Column Name - name entered in the Column Name cell for the selected row.
    • Data Type - data type chosen from the Data Type column for the selected row.
    • Control Type - type of control selected from the Control Type column for the selected row.
    • Tool tip - displays the tool tip for the selected row.
    • Panel Mapping (Name)
  2. Within the Properties window, for the String Combo box the following information will either be taken from the logical data characteristic assigned to the row, or will need to be configured:
    • Field Size - if a local characteristic has been mapped to the row, either type directly into the field or click on the button to open the Default Data dialog and enter the value you require.
      - if a logical data source characteristic has been mapped to the row the field size displayed will correspond to the length defined in the logical data source.
    • Mandatory Field - select to force the user of the Treatment table to select a value.
    • Default Data - either type directly into the field or click on the button to open the Default Data dialog to define the value that is to be seen in this column when the user first accesses the treatment.
    • Allow free text - select to allow the user to enter a value. (The default for a combo box is that the user will not be allowed to enter values).

The Treatment table will use a combo box using the properties you have defined to display the values.

Adding the values to column

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the treatment table design will form a column in the Treatment Table.

Values can be entered into this column. When valid values exist, the user can delete valid values from the list, but not add any additional ones. Values can be populated into this cell using an external file.

To add values to a column

  1. With the Treatment Table Design editor open, in the Value column, type the values that the user will select when they define the treatment.
    Individual values should be separated with a semi-colon. For example:
    Yes;No
    18;24;36

The values that have been entered will be available for selection by the user of the Treatment Table.

Values that are added using an external file will not be listed in the Column View Table or Panel Designer. They will be available for selection from the Treatment Table either from the Column view or the Panel view.

Adding a list file to a column view table row

Treatment Tables are designed using the Treatment Table Design component.

When the Treatment Table Design editor is opened the Column View Table will be displayed. Each row created in the treatment table design will form a column in the Treatment Table.

In the Treatment Table a list of values can be presented to the user from which they can choose a particular value. These values can be manually entered into the Treatment Table Design or can be populated from an external lookup file. If the row in the Treatment Table Design is mapped to a logical data source characteristic which is assigned valid values, then the user cannot specify values that are outside of these valid values.

To add a list file to a column view table row

  1. With the Treatment Table Design editor open, and the cell in the Value column selected, within the Properties window click on the Use File check box.
  2. Next to the List File Name field, click on the button and locate the external list file.
  3. Click OK.
    The full path and file name will be listed in the List File Name field and the values will be displayed in the List Value field and the Value cell in the Column View Table.
    4.  

    The system provides a layer of security by preventing users from having access to files and folders they are not permitted to.

    The List File Name value is only visible to the current user if the specified path is either the Shared directory or the user’s directory.

The values that have been entered will be available for selection by the user of the Treatment Table.

Adding a tooltip to a treatment

Treatment Tables are designed using the Treatment Table Design component.

For each column a Tooltip can be created that will be displayed to assist the user when they hover their mouse over a column in the Treatment Table. Once a tool tip has been assigned in the Treatment Table Design editor the following icon will be displayed in the column.

To add a tooltip to a treatment

  1. With the Treatment Table Design editor open, click in the "Tooltip" column.
    The Tooltip Text dialog will be opened.
  2. Type a suitable tool tip, for example:
    In order to enter a Bad Debt Provisioning Percentage of 5% enter 5 not 0.05
  3. Click OK.
    The Tooltip Text dialog will close.

The following icon will be displayed in the column to indicate that a tool tip has been defined.

  If rules need to be created to define how the values entered in each treatment will be processed or additional calculations need to be performed further definition needs to be carried out in the Treatment Table Design - Script Panel of the Treatment Table Design.

Now that the Treatment Table Design is complete it can be used to create a Treatment Table.
