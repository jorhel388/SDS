Control Properties

There are eight different types of Control that need to be configured. The Control you select will affect what needs to be configured. Where you select the Control will also affect what needs to be configured, since a drop down box selected from within the Panel Designer will have different properties to a drop down box selected from within the Column Table View. Taking this into consideration, there are a number of properties that are common within all controls that are used in the Panel Designer and Column Table View and others that are unique to specific controls.

Panel Designer Control Properties

Common Properties

Properties Allows the designer to:

Control Name

Once a Control is added to the Panel Designer the system will give it a unique name. To help identify the different controls within the treatment design it is recommended that they are renamed.

If a control is mapped to a column the Column Name property will be read only as it will match the name given to the column name.

Control Type

Type of Control that has been added to the panel.

Enable

Define whether this control is available to the user when they first access the treatment table.

Visible

Determine if the control is visible when the user first accesses the treatment table.

Tooltip

Type a message that will provide assistance to the user on the purpose of this field in the treatment table. This field can be left blank.

X-Position

Taking a point in the control that is at the centre/left most edge, this property enables the user to accurately alter the position of this control by typing in a value. A property that can be used to line up adjacent controls.

Y-Position

Taking a point in the control that is at the centre/middle of the control, this property enables the user to accurately alter the position of this control by typing in a value. A property that can be used to line up adjacent controls.

Width (px)

The width in pixels of the control can be changed by typing a number in this field. The number contained in this field will dynamically update as the width of the control is changed on the panel itself.

Height (px)

The height in pixels of the control can be altered by typing a number in this field. The number contained in this field will dynamically update as the width of the control is changed on the panel itself.

Properties that are unique to Check boxes, Drop Down boxes, Containers, List boxes, Radio Buttons, Text boxes and Sliders

Properties Allows the designer to:

Column Mapping

If the values in this control are not going to be passed back to a column - Panel Use will be displayed in this field, otherwise the column name to which the control was mapped when it was added to the panel will be displayed in this field.

This field is Read Only.

Data Type

If the control has been mapped to a column name, the data type of the characteristic that was assigned to this column name will be displayed in this field. This field will be Read Only.

Otherwise, use the drop down list accessed from this field to select the data type required. Choose from String, Integer, Float, Decimal and Date.

Field Size

If the control has been mapped to a column name, the length of the characteristic that was assigned to this column name will be displayed in this field as the field size. This field will be Read Only.

Otherwise, type a length for the data field. The length needs to be the length of the longest entry in the list.

Properties that are unique to Check boxes, Drop Down boxes, List boxes, Radio Buttons, Text boxes and Sliders

Properties Allows the designer to:

Mandatory

N/A in this release of the software.

Properties that are unique to Drop Down boxes, List boxes, Text boxes and Sliders

Properties Allows the designer to:

Default Data

Define the value that is to be seen in this field when the user first accesses the treatment table.

Properties that are unique to Drop Down boxes and List boxes

Properties Allows the designer to:

Use File

Decide whether to invoke the use of an external file or not.

When checked the external file is used, when not checked the values listed in the List Value field will be used.

List File Name

Define the file name and the full path for the file that contains the external list of values. The user will be able to select from the values contained in this file.

Microsoft Excel files should be saved as .CSV file.

List Value

If the control has been mapped to a column name, the values entered in the List Value field will be displayed in the Value column. Values can be entered directly to the Value column field if required.

The user will be able to select from within the treatment table.

Property that is unique to numeric Drop Down boxes, List boxes and Sliders

Properties Allows the designer to:

Range

Define the minimum value and the maximum value that will be accepted for this control, e.g. 0-2000.

Property that is unique to Labels, Check boxes, and Radio buttons

Properties Allows the designer to:

Text Label

Type the text that is to be displayed on the finished panel next to this control within the Properties window.

Double click on a black box of the control to edit the Text Label in the panel view itself.

Property that is unique to Check boxes, and Radio buttons

Properties Allows the designer to:

Selected Value

Define the value that will be returned when the control is selected. For example, Y or 1.

Property that is unique to Check boxes

Properties Allows the designer to:

Default State

Determine which state the control should be in when the user first accesses the treatment table.

Unselected Value

Define the value that will be returned when the control is de-selected. For example, Y or 1.

Property that is unique to numeric Drop Down boxes

Properties Allows the designer to:

Allows free text

Decide whether to allow the user to enter a value when they are creating treatments.

Property that is unique to Labels

Properties Allows the designer to:

Picture

Define the file name and the full path for the picture that you wish to be added to the panel design.

Properties that are unique to a Container

Properties Allows the designer to:

Border Title

Decide what text will be displayed at the border of the container. This can be left blank if required.

Border Colour

Click on the button to access the Pick a Colour screen from where you can chooser a colour to be used as the colour for the border.

Border Display

Choose whether to have a border displayed or not.

Border Style

Choose whether the border will be a solid line border or an etched border.

Properties that are unique to a Slider

Properties Allows the designer to:

Max Value

Define the highest value that will be returned when the user moves the pointer to this value.

Min value

Define the lowest value that will be returned when the user moves the pointer to this value.

Is Vertical

Decide whether the slider is to be vertically or horizontally orientated on the treatment table.

Major Tick Spacing

Define the size of the space between the larger 'ticks' on the scale.

Minor Tick Spacing

Define the size of the space between the smaller 'ticks' on the scale.

Show Values

Ensure that the 'values' are visible on the slider.

Show Ticks

Ensure that the 'tick' marks are visible on the slider.

Snap to Ticks

Activate 'Snap to Ticks', so deciding whether the user will be able to move the pointer to a value located between any of the ticks or not.

Column View Tables Control Properties

Common Properties

Common Properties Allows the designer to:

Column Name

The name of the column to which this control refers.

This field will be Read Only.

Data Type

The data type that has been picked up from the mapped characteristic or selected from the drop down list accessed from Data Type column in the Column View Table will be listed here.

The field is Read Only.

Field Size

Taken from the length of the characteristic that is assigned to the column name. This field will be Read Only.

Otherwise, type a length for the data field. The length needs to be the length of the longest entry in the list.

Mandatory

N/A in this release of the software.

Default Data

Define the value that is to be seen in this field when the user first accesses the treatment table.

Control Type

Type of Control, either drop down box or text box that will be available for the user when entering data directly into the Treatment Table.

Tooltip

Message that has been typed into the column view table to provide assistance to the user on the purpose of this field in the treatment table.

This field is Read Only.

This field can be left blank if required.

Panel Mapping (Name)

Will either list the column name to which this control refers or display 'Table Use' to indicate that it this control is only for use in the Panel View Table.

Property that is unique to a Drop Down box

Properties Allows the designer to:

Allows free text

Decide whether to allow the user to enter a value when they are creating treatments.

Property that is unique to numeric Drop Down boxes and Text boxes

Properties Allows the designer to:

Range

Define the minimum value and the maximum value that will be accepted for this control, e.g. 0-2000.
