Create treatments using a Treatment Table

Treatment Tables provide business users with a user configurable mechanism for defining templated Treatments that can be used to address specific business objectives, such as credit limit assignment, loan pricing terms, collections action path assignment, and campaign/promotion code assignment.
Treatment Tables are created from Treatment Table Designs. Each row/entry in the Treatment Table is used to define an individual treatment that can be allocated to a particular group of customers using a Treatment Tree.

Create a Treatment Table

Once the Treatment Table Design has been created it is used to create one or more Treatment Tables since multiple tables can be created from a single design. Each row/entry in the Treatment Table is used to define an individual treatment that can be allocated to a particular group of customers using a Treatment Tree.

A Treatment Table can be created from the Explorer window.

  You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a Treatment Table

  1. From the Explorer window right click at the required folder level and select Add a component.
  2. Select Treatment Table from the list of available components
  3. In the Create component dialog enter the name of the Treatment Table.
  4. Select the Open new components in component editor check box.
  5. Click on the OK button.
    The Treatment Table editor will open allowing you to define individual treatments; see define treatments using a Treatment Table and Define treatments using a treatment panel.
    The Treatment Table name will be listed in the Explorer under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, keep the check box de-selected. From the Explorer window right click on the treatment table and select Open.

To create a treatment using a Treatment Table

  1. With the Treatment Table editor open, in the Resources window expand the Treatment Table Design category.
    The treatment table designs that have been published to your current folder or exist in the folder will be listed.
  2. Drag and drop the Treatment Table design you require for the Treatment Table into the Treatment Table editor.
    The editor will be updated to display as columns all the rows that were defined in the Treatment Table Design editor.
  The Show Treatment Panel icon will not be available within the Treatment Table if a panel has not been created.
  1. In the Treatment Name column type a name for your treatment and select Enter.
  2. Enter values for the treatment directly into the table.
    The system will check to ensure that the value you have added/selected is valid.
    3.   Once a control has been added to the Treatment Panel the user will be prevented from using the table to create treatments. They will not be able to enter data directly into the table. Instead they will need to use the Treatment Panel. This is to ensure that the validation script is not by-passed.
  Should you need an explanation regarding a particular column, in the table move your cursor over the cell to display any tool tips.
  1. Repeat step 4 as required until all the treatments are defined for this table.

You will now be able to assign the treatments you have created in Treatment Tree.

  In order to test a Treatment Table, users must select the row within the Treatment Table they wish to test before launching the Interactive Tester. If no row is selected, the first row will be tested by default.
Test a Treatment Table

Once the user has successfully created a Treatment Table, the user can test it using the Interactive Tester.

The user can test a Treatment Table either by manually typing in data for the input characteristics referenced in the Treatment Table or by performing a test against a known data source.

To perform an interactive test

To test a Treatment Table, manually enter data into the relevant fields for the input characteristics. Please refer to the Interactive Tester editor for more information.
