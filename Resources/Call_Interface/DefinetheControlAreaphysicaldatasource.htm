Define the Control Area physical data source

Depending on your requirements the Control Area must be manually created for either a byte array format or for the java object format. The following details the rules governing the formatting of the Control Area in either format.

Byte Array Data Format

The Control Area must have a physical layout name of BCONTROL, a length of 540 and always be the first data area in the concatenated array.

For the Control Area, the logical data source must always include the following fields:
