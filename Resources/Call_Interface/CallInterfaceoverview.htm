Call Interface overview

The Call Interface is used to link specific instances of physical data models to specific instances of logical data sources together with a layout name to produce a physical data source.

Each call interface defines a collection of physical data sources of a single type, either byte array or java object. The type of the interface is determined by the type of the first physical data source assigned to the Call Interface editor.

For compatibility with the Decision Agent a specific physical data source with the layout name BCONTROL must be created. This physical data source contains a series of standard characteristics that are used by the Decision Agent at runtime. For more information on how to create the BCONTROL physical data source see Defining the Control Areas physical data source.

Create a call interface

A call interface can be created from the Explorer window.

 

You will only be able to add a component type that has been allowed for the selected folder. If it is not allowed it will not be listed and therefore cannot be selected.

To create a call interface

  1. From the Explorer window right click at the required folder level and select Add component.
  2. Select Call Interface.
  3. In the Create component dialog enter the name of the call interface.
  4. If you wish to have the new component display in the Main editor on creation, ensure that the Open new components in component editor tick box is selected.
  5. Click on the OK button.

    The Call Interface editor will open allowing you to define the call interface required.
    The call interface name will be listed in the Explorer window under the selected folder level. The component is identified by the icon.

If you do not wish the editor to open, de-select the tick box. From the Explorer window select the call interface and select Open.

Edit a byte array interface

The call interface allows the user to link specific instances of physical data models to specific instances of logical data sources together with a layout name to produce a physical data source.

To edit a byte array interface

  1. With the call interface open, in the Layout column, double click in the first cell and type the name for the Layout.

    2.   The maximum length for the byte array layout name is 8 characters.
     
  2. Click on the Resources window. The valid component types will be listed.
  3. Expand the Logical Data Source list to display all the available logical data sources.
  4. Drag and drop the required logical data source onto the Logical Data Source column's cell next to the appropriate layout name.
  5. Expand the Byte Array Physical Data Model list to display all the available byte array physical data models.
  6. Drag and drop the required physical data model onto the Physical Data Model column's cell next to the appropriate logical data source.
    A physical data source containing a logical data source, physical data model and a layout name will have been created.
    The Interface Type field will be updated to display Byte Array.
    7.  Once the call interface type has been determined by the type of the first physical data model that has been assigned, this will be the type of the call interface.
     
  7. Repeat steps 1 to 6 to create all the physical data sources you require.

The call interface can now be used within a deployment.

Edit a Java object interface

The call interface allows the user to link specific instances of physical data models to specific instances of logical data sources together with a layout name to produce a physical data source.

To edit a Java object interface specification

  1. With the call interface open, in the Layout column, double click in the first cell and type the name for the Layout.
  2. Click on the Resources window. The valid component types will be listed.
  3. Expand the Logical Data Source list to display all the available logical data sources.
  4. Drag and drop the required logical data source onto the Logical Data Source column's cell next to the appropriate layout name.
  5. Expand the Java Object Physical Data Model list to display all the available java object physical data models.
  6. Drag and drop the required physical data model onto the Physical Data Model column's cell next to the appropriate logical data source.
    A physical data source containing a logical data source, physical data model and a layout name will have been created.
    The Interface Type field will be updated to display Java Object.
    7.   Once the call interface type has been determined by the type of the first physical data model that has been assigned, this will be the type of the call interface.
  7. Repeat steps 1 to 6 to create all the physical data sources you require.

The call interface can now be used within a deployment.
