Index Table editor

The Index Table editor enables the user to define the values and characteristics associated with the Index Table.

An Index Table can be thought of as a ‘lookup table’. A value is passed into the table which looks up a matching value on the input column and outputs the value(s) on the matched row. When no match is found then the value(s) on the default row are output.

The Index Table editor screen consists of:

Index Table toolbar with options designed to assist the user in copying and pasting from and to Excel.

Input column - the user assigns either a Logical Data Source characteristic or Logical Data Model characteristic or array characteristic as the input characteristic to this column and then enters unique values.

Output column(s) - once a characteristic has been assigned to the Input Column of the Index Table, the Output column will displayed in the editor. The user must add the required output characteristic(s) to this column. The user will be able to add either a Logical Data Source characteristic or a Logical Data Model characteristic or array element depending on the type of characteristic assigned to the Input Column. The user can insert up to 99 Output Columns and then assign output characteristics to each of these. Non-unique values are then entered into these cells.

Default cell - the default cell is automatically created; the values in the cells adjacent to this will be returned if no value is found for the input characteristic.

Test - Launches the interactive tester for the Index Table.
